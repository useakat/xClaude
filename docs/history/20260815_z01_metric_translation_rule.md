## よーん *(09:04 JST)*

この小惑星に探査機を当てると、なんで周期が縮むのが成功条件になるの？

### Claude *(09:05 JST)*

いい質問です。核心はこの実験の「的の選び方」にあります。

**なぜ「周期が縮む＝成功」なのか**

1. **狙ったのは、単独の小惑星ではなく「連星」の小さい方**
今回ぶつけた岩（ディモルフォス）は、もっと大きい相棒の岩（ディディモス）の周りを、約12時間で1周しながら回っていました。2つでコマのように回りあう「連星小惑星」です。

2. **軌道を変えられたかを"測れる"ようにするため**
本来の目的は「岩の進む向きを変えられるか」。でも太陽を回る単独の小惑星だと、わずかな進路変化は地球から測るのが極めて難しい（変化が小さく、確認に何年もかかる）。
そこで**相棒を回る12時間周期**に注目しました。地球から見ると、小さい岩が相棒の手前・裏を通るたびに明るさがわずかに変わる（食）。この明滅を測れば、周期を秒単位で正確に読めます。

3. **ぶつける＝減速させる＝周期が縮む、という物理**
探査機を、岩が公転する進行方向に**正面から**当てると、岩はほんの少し減速します。回る速度が落ちた衛星は**内側の小さい軌道に落ち込み**、軌道が小さくなると**1周にかかる時間（周期）も短くなる**。
つまり「周期が縮んだ」は、**確かに岩の運動を変えられた**という、地球から観測できる直接の証拠になるわけです。

4. **73秒という合格ライン**
「これだけ縮めば、技術が本物だと確実に言える」という最低ラインが**73秒**の短縮でした。結果は**32分（約1920秒）**＝基準の25倍以上。狙いを大きく超えたので「大成功」となります。

**まとめ:** 周期を縮めること自体が目的なのではなく、「岩の進路を変えられた」ことを地球から**秒単位で確認できる形にした指標**が周期です。だから周期の短縮が成功条件になります。

（補足：この「連星の周期を測る」という測定の巧みさこそ、この話のもう一つの見どころです。140字では入りきらないので、掘り下げるなら昇格先の note（W002）/ ワンポイント解説（W003）向きの要素です。）
