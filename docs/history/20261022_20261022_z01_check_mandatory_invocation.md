## Layer 1 — spec の明文化（必須・低コスト・すぐ効く）

## Layer 2 — 証跡の義務化（中コスト・監査可能にする）
下書き本文に `[チェック証跡]` ブロックを必須化：
```
[チェック証跡]
check-reader: 実行/判定一行/改稿有無
check-fact:   実行/…
check-critic: 実行/…
check-brand:  実行/…
check-yohn:   実行/…
[/チェック証跡]
```
チェックを実起動しないと埋める中身（各役の返答）が存在しないので、**空欄＝未実行が一目で分かる**。STEP 7 完了報告にも同じ5行を出す。これだけで「省略したか」が後から機械チェックできます。

## Layer 3 — hook による機械ゲート（高コスト・最も確実）

- 各 `/check-*` スキルの冒頭に「起動時に scratchpad のフロー別ディレクトリへマーカーを書く」を1行追加
- STEP 1（フロー開始）でマーカーをクリア
- hook は下書き作成直前にマーカー5つを確認 → 欠けていれば「check-◯◯ が未実行。実起動してから下書きを作れ」と stop

これなら自己検品での省略が**物理的にできなくなります**（git_guard と同じ発想の、創作判断に踏み込まない機械ゲート）。
