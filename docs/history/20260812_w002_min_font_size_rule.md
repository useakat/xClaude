## よーん *(11:04 JST)*

サムネ含め、作成する図の文字サイズはかならず 36px 以上になるようにしたい（スマホでも読めるように）んだけど、どうするのがいいかな？

### Claude *(11:05 JST)*

いい着眼点です。ただ「36px」は**キャンバス幅と一緒に決めないと意味が変わります**。

## なぜ px だけでは決まらないか

note の画像はスマホでは**画面幅（約390px）に縮小表示**されます。実際の見た目の大きさは：

```
スマホでの見かけの文字サイズ ＝ 文字px × (390 ÷ 画像の幅px)
```

| 画像の幅 | 文字36px | スマホでの見え方 |
|---|---|---|
| 1280px | 36px | **約11pt**（読める） |
| 1600px | 36px | 約8.8pt（**小さすぎる**） |
| 1920px | 36px | 約7.3pt（読めない） |

つまり、先ほど作った2枚組（1600×900）の36pxは、①の図解（1280×720）の36pxより**2割小さく見えます**。

## 提案するルール

**1. 図解・サムネのキャンバスは 1280px 幅に統一する**
→ 幅が固定なら「36px以上」がそのまま使えます

**2. 最小文字サイズ ＝ 画像幅の 2.8%（1280pxなら36px）**
→ スマホで約11pt を確保できる下限です

| 用途 | 1280px幅での推奨 |
|---|---|
| タイトル | 64px以上 |
| 見出しラベル・キャプション | 40px以上 |
| 補足・注記（**最小**） | **36px** |
| クレジット（例外） | 20px前後（読めなくてよい情報） |

**3. 生成スクリプトで自動的に下限を守る**
→ `MIN = round(幅 × 0.028)` を計算し、指定サイズがそれ未満なら自動で引き上げる。うっかり小さい指定をしても破れません

**4. `image/brand.md` と `thumbnail/brand.md` に明記**
→ 今後の記事すべてに適用されます

## よーん *(11:35 JST)*

1600幅で 36px だと、1280幅でいくつ相当になる？

### Claude *(11:35 JST)*

**28.8px（約29px）相当**です。

計算：36px × (1280 ÷ 1600) = 28.8px

つまり比率で見ると、
- 1600幅の36px ＝ 幅の **2.25%**
- 1280幅の28.8px ＝ 幅の **2.25%**（同じ）

**現状の各図の比較（1280幅換算）**

| 図 | 実サイズ | 1280幅換算 | スマホでの見え方 |
|---|---|---|---|
| ④ 2枚組（1600幅・キャプション36px） | 36px | **28.8px** | 約8.8pt |
| ① 構造図（1280幅・見出し35px） | 35px | 35px | 約10.7pt |
| ① 構造図（1280幅・補足28px） | 28px | 28px | 約8.5pt |
| ⑥ 軌跡マップ（1280幅・出来事26px） | 26px | 26px | 約7.9pt |

**④のキャプションは、①の補足（28px）とほぼ同じ大きさに見えている**ということです。先ほど「36pxに拡大した」つもりでも、1600幅のせいで①の見出し（35px）より小さく見えています。

これを踏まえると、④を①と同じ見やすさにするには **1600幅で44〜45px** が必要です（35 × 1600/1280 = 43.75）。

どうしますか？
1. ④を**1600幅のまま45pxに拡大**する
2. ④を**1280幅で作り直し**、36pxにする（他の図と幅を統一できる）

## 決めたルール（`image/brand.md`・`thumbnail_template/brand.md` に明記）

**最小文字サイズ ＝ 画像幅の 2.19%**（1280px 幅なら **28px**）

| 画像の幅 | 最小 | 見出し級（2.7%） | タイトル級（5%） |
|---|---|---|---|
| 1280px | **28px** | 35px | 64px |
| 1600px | **35px** | 44px | 80px |
| 1920px | **42px** | 52px | 96px |

- **例外**：出典クレジット等の但し書きのみ下限を適用しない
- 図解・サムネのキャンバスは **1280px 幅を基本**とする（幅が固定なら「28px以上」で判断できる）
- スクリプトでは `MIN = round(画像幅 × 0.0219)` を計算し、**指定が下限を下回ったら自動で引き上げる**

## 適用結果

| 図 | 対応 |
|---|---|
| ① 構造図（1280幅） | 補足28px＝ちょうど下限。スクリプトに自動引き上げを組み込み済み |
| ⑥ 軌跡マップ（1280幅） | **出来事26px → 28px に修正して再生成**（お送りした画像） |
| ④ 2枚組（1600幅） | 下限35px に対し、キャプション36px・ラベル36px で**基準を満たしています** |

これで今後作るサムネイル・図解も、自動的にこの下限が守られます。
