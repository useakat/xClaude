## 差分の分析

**① フックの型：演出過多 → 素朴な事実**
- 初稿:「あなたの心臓が60回打つあいだに…たった2回」（brand.md の5軸を全部載せた比較構文）
- 最終:「シロナガスクジラは深く潜る時、心拍数が1分間に2回にまで落ちる」（主語＝クジラの単純宣言）
- 原因: 5軸評価を**満たしにいく**あまり、フックを作り込みすぎた。よーんの選択は前回（はちみつ）も今回も「実は、〇〇は△△だ」の**素朴な事実型**。5軸は「満たすべき制約」ではなく「事実がもともと持つ強さの確認」に使うべきだった。

**② 論理の飛躍を含む主張の混入 → 削除**
- 初稿:「この心臓は、もう限界まで働いている」「大きくなれない天井」
- これは (a) 限界なのは実は浮上時の高心拍なのに徐脈の直後に置いて因果が逆に読める、(b) 研究チームの仮説を断定調で書いた、の二重の問題。よーんの「なんで？」に本文内で答えられない主張だった。
- 原因: **「本文内で"なぜ"に答えきれない主張は入れない」というゲートがなかった。**

**③ 因果の中間リンク欠落 → 補完**
- 初稿:「ゆっくり打つほど、ためこんだ酸素が長くもつ」（なぜ？が飛んでいる）
- 最終:「心臓がゆっくり打てば、**体が酸素を使うペースも落ちる**。潜る前にためこんだ息が、長くもつ」
- 原因: 執筆前に因果チェーンを1段ずつ書き出していなかった。

**④ 数値の代表値と極値の混同 → 原典で層別**
- 初稿: 2回/分を代表値のように使用。最終: 海面25〜37回 → 通常4〜8回 → 最低2回、と層別。比較の基準も「人の脈」から「**クジラ自身の海面時**」に変更。深度も「数百メートル」→ 実測184mに基づく180m。
- 原因: 執筆前のファクト確認が二次情報止まりで、**原典の数値表（typical / minimum / 条件）を作ってから書く**工程がなかった。

**⑤ 締め：思弁 → 事実に根ざした情景**
- 初稿: 仮説ベースの余韻。最終:「深さ180メートルの闇を、鼓動をひそめたまま沈んでいく」（実測値だけでできた情景）
- ＋往復問題（クジラ→人→クジラ→人）も途中で発生。**視点の切替は1回**が正解だった。

## 最初から近づけるための執筆前ルール（案）

1. **ファクト表が先、本文が後**: 原典から「代表値／極値／測定条件」を表にしてから書く。極値をフックに使うときは本文で代表値を必ず併記
2. **why チェーン検査**: 本文中のすべての「なぜ？」に、本文内の1〜2文で答えられるか。答えられない主張（今回のネタB）は面白くても落とす。研究者の仮説は「かもしれない」以前に、原則不採用
3. **フックは素朴な事実型を第一候補に**: 5軸は生成の型ではなく検収に使う
4. **数値比較は同一主体の Before/After を優先**（海面↔潜水）。異種比較（人間）は「読者の体との接続」1箇所だけに限定
5. **視点切替は1回・片方向**。締めは思弁ではなく、確認済みの数値だけで組んだ情景

## 「検収に使う」とは

順序の問題です。

- **生成の型として使う（初稿でやったこと）**: 5軸を「埋めるべきテンプレート」として、体接続動詞・読者代名詞・比較数字…を**全部盛り込みながらフックを組み立てる**。→ 今回の「あなたの心臓が60回打つあいだに…」のような、演出過多で不自然なフックになりがち
- **検収に使う（提案）**: まず「実は、〇〇は△△だ」の素朴な形で**事実をそのまま書く**。書いた後で5軸に照らして「比較数字はあるか」「パワーワードはあるか」を**点検**し、欠けが致命的なときだけ直す。→ 事実が持つ強さがそのまま出る

つまり「5軸で作る」のではなく「作ってから5軸で確かめる」。今回の最終フック「シロナガスクジラは深く潜る時、心拍数が1分間に2回にまで落ちる」は、5軸で組み立てたものではありませんが、点検すると具体数字・意外性は満たしています。

## 修正版ルール（3項目）

1. **ファクト表が先、本文が後**: 原典から「代表値／極値／測定条件」を表にしてから書く。極値をフックに使うときは本文で代表値を必ず併記する
2. **why チェーン検査**: 本文中のすべての「なぜ？」に、本文内の1〜2文で答えられるか確認する。答えられない主張は面白くても落とす。研究者の仮説は原則不採用
3. **フックは素朴な事実型を第一候補に**: 「実は、〇〇は△△だ」で事実をそのまま書き、5軸は書いた後の点検に使う（5軸を埋めにいってフックを作り込まない）
