**理由：心臓は大きくするほど、速く打てなくなる**
心臓が1回打つには「血をためる → 電気信号が伝わる → 収縮して押し出す → ゆるむ」という工程が要ります。心臓が大きいほど、この工程にかかる**物理的な最短時間が長くなる**。だから体を大きくして心臓も大きくすると、速度の天井が下がってしまいます。

**筋肉を厚くして「力」を強くしてもダメ**
押し出す力は強くできても、**血をためる時間は短縮できない**からです。満たされる前に次の収縮が始まると、1回に送れる量がかえって減ります。

**そしてクジラはすでに天井に達している**
- 体重70〜190トンから予測される安静時心拍は約15回/分
- 浮上時の実測は25〜37回/分 = 心臓の大きさと電気の伝わる速さから計算される**理論上の上限（約33〜37回/分）とほぼ一致**
- 息継ぎできるのは**4分未満**。その短時間に、潜水中にためた酸素の借金を返しきる必要がある

もっと大きい体だと、必要な酸素を短い息継ぎで取り戻せず、生きられない——という話でした。

なお、「これが体の大きさの上限を決めている」は**研究チームの有力な仮説**で、確定ではありません（オキアミの密度など生態的な制約も絡む）。「かもしれない」という締めは適切です。

## 心拍出量（1分あたりに送れる血液量）

| | 1回拍出量 | 心拍数 | 心拍出量（毎分） |
|---|---|---|---|
| **シロナガスクジラ 浮上時** | 約227L（浴槽1杯分） | 37回/分 | **約8,400L** |
| **同 潜水時** | 約227L | 2回/分 | 約454L |
| **人間 安静時** | 約0.07L(70mL) | 約70回/分 | 約5L |
| **人間 全力運動時** | 約0.1L | 約190回/分 | 約20〜25L |

浮上時で人間の安静時の**約1,700倍**です。

**注意**：心拍出量の「毎分◯L」という数値はソースに直接の記載がなく、上記は 227L × 心拍数 の単純計算です（ノートもそう明示していました）。1回拍出量227Lも、心臓の内容積を約500Lとする別記述があり、文献間でばらつきがあります。

## トレードオフの上限について

理論の骨格はご指摘のとおりです。整理すると：

- 1回拍出量は体重にほぼ**比例**（M¹）して増やせる
- 心拍数は体重が増えるほど**下がる**（哺乳類でM^-0.25、鯨類で約M^-0.22）
- 掛け算すると心拍出量は **M^0.75〜0.78** でしか増えない ＝ 体重の増え方に届かない

平常時ならこれで釣り合います（代謝要求もM^0.75）。**問題は息継ぎです。** 4分未満で酸素の借金を返すには、平常の何倍もの心拍出量を短時間に出す必要がある。そのためにクジラは浮上時に心拍を**理論上限（約33〜37回/分）まで**上げていて、もう伸びしろがない——という構図です。

なお「毎分◯L が絶対的な理論最大値」という数字はソースにありませんでした。上限として明示されているのは**心拍数の上限（33〜37回/分）**の方です。
