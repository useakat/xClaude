## 高反応W001投稿の文体特徴（8本から抽出）

### 1. フックは「口火型＋温度形容」がほぼ独占（6/8本）
「これ、ヤバすぎる話なんだけど聞いてくれ——」「これ、震える話なんだけど聞いてほしい！」「これ、かなり痺れる話なんだけど聞いてほしい！」——**「これ、＋[温度形容]な話＋聞いてほしい」の一つの型**に集中しています。残り2本も「90日で終わると思ってた探査車、15年生き延びた話がヤバすぎる」（数字落差＋ヤバすぎる）と「もう使い道がないと思われていた衛星が、人類初の彗星遭遇をやってのけた」（逆説）。hook-patterns.md の5型のうち、実績が出ているのは**⑤口火型と①逆説型だけ**です。

### 2. 落差を数字ペアで最初に叩き込む
「90日 → 15年」「8年 vs 木星5年」「175年に一度」「たった4ワット」「1万通りの軌道」「月スイングバイ5回」。**Before/Afterの数字対比が冒頭2〜3文以内**に置かれています。

### 3. 「なぜか？」の自問自答で駆動する
「なぜか？」「じゃあなぜ8年もかかるのか？」と問いを立て、直後に自分で答える。科学解説はすべてこの問答の形で挿入され、講義口調にならない。

### 4. 転換は1行の「合図」で切る
「──ところが。」「結果──」「信号ロスト。」「ここからが熱すぎる。」「だが、代償があった。」——転換点は接続詞や体言止めの**超短行を1行だけ置いて改行**。段落の中で転換しない。

### 5. 語り手の「合いの手」が山場に入る
「これが『覚悟』だ。」「土壇場の底力、半端ない。」「完全に無理ゲー。」「静かな反逆だった。」——**中の人が思わず漏らした一言**が、山場に1〜2回だけ入る。現在の原稿群（淡々と描写を積む文体）との最大の違いはここです。

### 6. 口語スパイスを少量だけ
「無理ゲー」「ヤバすぎる」「熱いブレーキ芸」「荒業」「こいつ」——1投稿あたり1〜3語。全体は常体の真面目な語りで、口語は**落差を作るスパイス**として効かせている。

### 7. 機械の擬人化に感情を乗せる
「バッテリーが切れそうだよ。あたりが暗くなってきたんだ…」「身を削りながら」「生き残るための、孤独な撤退」。探査機を「彼ら」として扱い、最後の教訓につなぐ。

### 8. 締めは抽象化した断定1〜2文
「宇宙を切り拓くのは、最後の1ワットまでを捧げ続ける、探査機の執念なのだ。」「静かに熱い逆転劇だった。」——固有名詞を離れて一般命題に持ち上げて終わる。今回の「失敗したら終わりじゃない。そこからが勝負だ。」はまさにこの型です。

### 9. 【重要データ】字数は spec より長い
8本の字数は **526 / 657 / 666 / 667 / 823 / 825 / 926 / 1079字**。半数が spec の許容上限700字を超え、伸びた投稿ほど長い傾向があります（中央値 ~745字）。「600字に収める」現行ルールは、実績データと矛盾している可能性があります。

### Claude *(15:02 JST)*

「投稿そのもののIMP」ではなく「**その時期のふだんの数字に対して何倍だったか**」で評価する、という意味です。

## なぜ必要か

生のIMPは時期で桁が動きます。同じ600字帯でも2〜6月は中央値142,069、7〜8月は5,080でした。この状態で「800字帯 vs 600字帯」を比べると、実際には「2〜6月に投稿されたか、7〜8月だったか」を比べていることになります。字数の効果が時期の効果に埋もれる。

そこで各投稿を、**その直前の期間のふだんの水準で割って**、倍率に変換します。

## 具体的な計算

例：8/15の投稿（676字、61,100 IMP）

その直前5本の実績が仮に 1,796 / 5,080 / 983 / 2,006 / 2,300 だとすると、中央値は 2,006。

```
正規化スコア = 61,100 ÷ 2,006 = 30.5倍
```

一方、3/11の投稿（657字、880,994 IMP）の直前5本の中央値が仮に 130,000 なら、

```
正規化スコア = 880,994 ÷ 130,000 = 6.8倍
```

生の数字では 880,994 ≫ 61,100 で3月の勝ちですが、**その時期の基準に対する伸び方**では8/15の方が上、と判定が変わります。ベースラインが割り算で消えるので、時期をまたいで公平に比べられます。

## 分母に何を使うか — こちらは修正が要ります

前回「直近5本」とだけ言いましたが、**分母をW001の直近5本にすると問題があります**。分母側の投稿にも600字帯・800字帯が混ざっているので、測りたいもの（字数の効果）が分母にも入り込んでしまう。

正しくは **分母を「同時期の非W001投稿（z01・W003など）の中央値」にします**。これらは字数テストの対象外なので、アカウント全体の到達力だけを表す純粋なベースラインになります。分子（W001の字数テスト）と分母（それ以外）が独立するので、割り算で残るのが字数の効果だけになります。

ただしこの方法にも限界があって、W001長文とz01短文では投稿の性質が違うため「同じ地合いを共有している」という前提が完全には成り立ちません。それでも、生のIMPをそのまま比べるよりは交絡がかなり落ちます。

## 正規化した結果 — 結論が反転しました

分母を「同時期の非W001・非リプライ投稿 直近5本の中央値」にして、各W001投稿を倍率に変換しました。

| 期間 | 600字帯(<700) | 800字帯(≥700) | 比 |
|---|---|---|---|
| 全期間 | n=16 中央値 **79.2倍** | n=9 中央値 **16.3倍** | 0.21 |
| 2〜6月 | n=11 **96.6倍** | n=6 **71.9倍** | 0.74 |
| 7〜8月 | n=5 **7.3倍** | n=3 **1.7倍** | 0.24 |

**生IMPでは2〜6月だけ800字帯が優位（1.34倍）に見えていましたが、正規化すると同じ2〜6月でも600字帯の方が上（0.74倍）になります。** つまりあの優位は、長い投稿がたまたま地合いの良い日に当たっていたことの反映で、字数の効果ではありませんでした。3期間すべてで符号が揃い、短い方が優位です。

字数を3分割しても単調に下がります：

- 〜649字：n=8 → **98.8倍**
- 650〜749字：n=9 → **27.5倍**
- 750字〜：n=8 → **16.5倍**

ただし順位相関は **Spearman ρ = −0.201**。弱い負の相関で、n=25では統計的に有意とは言えません（この規模だと有意水準5%に届くのは概ね |ρ|>0.4）。

**現行の600字ルールは維持します。** 当初「実績は長い」という私の見立ては、正規化で否定されました。8本の高反応投稿が長めだったのは、それらが2〜6月に集中していたためです。
