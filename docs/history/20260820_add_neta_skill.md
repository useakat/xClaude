## 使い方

```
/add-neta https://sorae.info/...（URL）
/add-neta 〇〇という考えを思いついた（テキスト）
```

## 動作

1. **内容把握** — URL なら WebFetch で本文取得（数値・機関名・発表日を正確に抽出、一次情報 URL も控える）
2. **シート判定** — 上から順に適用:

| 順 | シート | 条件 |
|---|---|---|
| 1 | thoughts | 科学の事実でなく、よーん自身の考え・思想 |
| 2 | noteNeta | 主人公・危機・逆転・人間ドラマが**揃っている**物語の材料 |
| 3 | newsTopics | 時事性のあるニュース（概ね1年以内） |
| 4 | onePointNeta | 時事性のない普遍的トリビア（日常接続あり） |

3. **重複チェック** — ソース URL・同一事象の既存行があれば追加せず報告
4. **追記** — No は最大値+1 で採番（過去の重複採番対策）、ステータス=未使用、追加日=当日

**迷い方のルール**も今日までの実例から固定してあります：
- 「ニュースだが物語の芽もある」→ newsTopics に入れて「noteNeta 昇格候補」と付記（ボイジャー省電力化のケース）
- 「進行中で結末未確定」→ newsTopics（noteNeta は逆転が確定した話のみ。スウィフト救出のケース）
- 両シートに同等に強く該当するときだけ質問、それ以外は自動判定

完了報告には判定理由・類似ネタ・制作時の留意点（結末未確定など）を添えます。次にネタを渡すときは `/add-neta <URL>` だけで今日と同じ処理が走ります。
