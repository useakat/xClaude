**`scripts/send_note_draft.py` に入れたい修正（3点）**

```python
# ① figure に figcaption を必ず入れる（404の直接原因）＋ note と同じ data-align を付ける
- f'<figure name="{uid}" id="{uid}">'
- f'<img src="{info["src"]}" alt="{alt}"{size}>'
- f"</figure>"
+ f'<figure name="{uid}" id="{uid}" data-align="center">'
+ f'<img src="{info["src"]}" alt="{alt}"{size}>'
+ f"<figcaption></figcaption></figure>"

# ② URL に ")" を含む Markdown リンクが壊れるのを修正
#    現状: [Opportunity (rover) - Wikipedia](https://…/Opportunity_(rover)) が
#          href="https://…/Opportunity_(rover" ＋ 本文に ")" が漏れる（参考情報の Wikipedia 4件が該当）
- r"\[([^\]]+)\]\(([^)]+)\)"
+ r"\[([^\]]+)\]\(((?:[^()\s]|\([^()\s]*\))+)\)"    # 括弧1段のネストを許す

# ③ HTML コメント行（<!-- ハッシュタグ --> など）を本文に出力しない
+ if line.strip().startswith("<!--"): continue
```
