1. **「Always allow」クリックが git 差分になる**。このファイルは Claude Code 自身が書き込むファイルです。追跡対象にすると、どこかの環境でクリックするたびに working tree が汚れ、`commit_and_sync.sh` は全ファイルをステージするので、**次の routine のコミットに許可追加が黙って同乗**します。よーん一人のリポジトリなので致命的ではありませんが、「レビューなしで許可ルールがリポジトリに増えていく」経路ができる点は認識しておくべきです。
