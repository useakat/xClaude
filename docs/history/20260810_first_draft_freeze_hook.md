## 推奨案：hook で機械的に凍結する（＋共通仕様ファイル）

**なぜ hook を推すか。** spec.md に「first-draft.md にコピーする」と手順を書く方式だと、実行するのは毎回わたし（モデル）です。ケプラー記事とクジラ投稿の初稿→最終稿の差分分析は、すでに2回とも変更ログに残る改善につながっていますが、その分析の土台になる初稿が「手順を忘れて消えていた」では意味がありません。ここは仕組みで担保すべきところだと考えます。

具体的にはこうなります。

```
PostToolUse: matcher = Write|Edit
  → scripts/freeze_first_draft.sh
     対象パスが projects/w00[123]/*/draft/draft.md のときだけ
     cp -n draft.md first-draft.md   # -n なので初回のみ・以後は絶対に上書きしない
```

`cp -n`（no-clobber）が肝で、**最初の1回だけ作られ、その後どれだけ draft.md が書き換わっても first-draft.md は動きません**。z01 は `draft/` を持たないのでパス条件から自然に外れます。

**共通仕様の置き場**は `projects/CLAUDE.md` を新設するのが素直です。`projects/` 配下で作業する限り Claude Code が自動で読むので、w001/w002/w003 の spec.md に3重で書く必要がなくなります。ここには「初稿は `draft/first-draft.md` として凍結される（hook が自動実行）」「first-draft.md は編集・削除しない」の2行を書けば足ります。

## 代替案：spec.md に手順として書くだけ

hook を増やしたくない場合は、3つの spec.md に「執筆直後に `cp draft/draft.md draft/first-draft.md` を実行する」を1行ずつ足す形でも成立します。実装は5分ですが、上に書いたとおり実行漏れのリスクが残ります。
