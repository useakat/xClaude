## 補足

- URL 末尾の `20261119` は投稿別にクリックを数えるキーです。別の日に投稿するならその日付に変えてください（`tpost.usephys.net/<記事ID>/<キー>` の形式。転送側でパラメータを付けるので加工不要）

- プロフへの誘導は、ブランド定義の反応誘導禁止（「フォローしてね」等）に当たらない形で 1 行にしています
