Wiki で空行なしの改行が反映されるように直しました。まだ commit も push もしていません。

**原因**: Wiki は Starlight（Astro）で作られています。Markdown の標準仕様では、単一の改行は表示上スペースになり、空行を入れないと改行されません。

**対処**: `remark-breaks` プラグインを入れて、単一の改行をそのまま `<br>` にしました。変更は次の 3 ファイルです。
- `starlight/astro.config.mjs`: プラグインを登録（4 行追加）
- `starlight/package.json`: 依存に `remark-breaks` を追加
- `starlight/package-lock.json`: 上記に合わせて更新（CI の `npm ci` が通るように）

**確認**: 週報 W33 など 3 ページを実際にビルドして確かめました。空行なしの全角スペース入れ子が、そのまま改行されて出力されます。全 800 ページのビルドは、このマシンのメモリ不足（空き約 500MB）で終了してしまい試せていません。最終確認は push 後の GitHub Actions になります。

**影響**:
- 空行や全角スペースで回避していた既存ページは、今までどおり表示されます。
- 幅に合わせて途中で折り返して書いている文章は、折り返した位置で改行されます。該当は約 185 ファイルで、`docs/history/` の会話貼り付けが中心です。
- `reporter-daily` などのスキルにある「箇条書き間は空行にする」というルールは、不要になるはずです。ただしスキルの記述はまだ変えていません。

master に commit して push しますか？push するとすぐデプロイされます。変更を `/record` で記録するかも合わせてお知らせください。
