画面には、種類の表示名がそのまま出ます。

| 画面 | 表示 |
|---|---|
| カレンダーのチップ | `20時 リライト（短文）`。長いと末尾が省略されます。 |
| 今月の予約一覧 | 種類の列に `リライト（長文）`、横に小さく `(W001r)` と出ます。 |
| 編集フォームの「種類」 | 選択肢に `リライト（短文）（z01r）`、`リライト（ワンポイント）（W003r）`、`リライト（長文）（W001r）` が並びます。 |

**対応関係**
- 短文は z01r、ワンポイントは W003r、長文は W001r で、元投稿の what_id に r を付けたものです。
- 選択肢は既存の種類の後ろ（販促の次）に並びます。

**色について**
- リライト専用の色はありません。色は状態で決まります。下書きは点線枠、予約は青、投稿済みは緑です。
- そのため、カレンダー上でリライトを見分けるには、チップの文字を読む必要があります。

**注意**
- 種類名に「リライト」が付くので、チップの文字は他より長くなります。
- 特にスマホ幅では、`20時 リライト（ワンポイント）` が途中で切れます。切れても、タップすれば編集画面で全文を確認できます。

見分けやすくしたければ、リライトだけ色を変えることもできます。必要なら言ってください。
