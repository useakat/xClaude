# note 導線 改善施策レジストリ

X / Threads から note 到達、購入までの導線をどう直すかの順位付きリスト。施策ごとに検証方法を実施前に固定し、週次の判定をここに積む。

## 運用ルール

- このファイルが施策定義・検証方法・判定履歴の**単一の正**。週次運用振り返り（`/reporter-weekly-ops` の「⑧ note 導線 施策の検証」）はここからの転記
- 状態は 未着手 → 実施中（実施日を記入）→ 判定済み（支持／反証）。途中で 中止／保留 にできる
- 判定条件は実施日より前に固定し、以後は変えない。変えたいときは新しい ID で登録し直す
- 比較の原則：生 IMP を期間をまたいで比べない。率と中央値で比べる。W001 は地力 IMP（直前 14 日の非 W001 親ポストの IMP 中央値）を併記する。転送サイトのビーコンと X アナリティクスのリンククリックは定義が違うので混ぜない（期間をまたぐ比較は X リンククリックを主、ビーコンを副）
- 週次更新：`scripts/note_funnel_measures.py` が施策ごとの数値を出し、`/reporter-weekly-ops` STEP 5.7 が判定して「判定履歴」に 1 行追記する。数値の推測はしない
- 順位・条件の見直しはよーんが行う。見直したら日付付きで注記する
- CVR は必ず価格付きで書く（例：CVR¥300 ＝ ¥300 で売っていた期間の 購入 ÷ 同期間の PV。`note価格履歴` の区間、`article_price_cvr.csv`）。価格をまたぐ累計 CVR は判定に使わない（2026-10-21）

## 段階の定義（共通）

| 段階 | 意味 | データ（CSV・列 / シート） |
|---|---|---|
| S1 露出 | 本体ポストの IMP、週の総インプ、Threads views | `funnel_posts` 本体IMP、`funnel_weekly` インプ |
| S2 プロフ | プロフアクセス（X のみ） | `funnel_weekly`（X bio）リンク到達 ＝ 日次記録「プロフ」の週合計 |
| S3 リンク到達 | note リンクを貼ったセルフリプの IMP / views | `funnel_posts` リンク到達 |
| S4 クリック | X リンククリック（主）、転送サイトのビーコン（副） | `funnel_posts` Xリンククリック・クリック、`click_detail` クリック |
| S5 記事到達 | note 側で数えた到達、記事 PV | `funnel_weekly` note到達、`note_referrers`、シート `note記事日次` PV |
| S6 購入 | 購入数、価格区間ごとの CVR¥ | `articles` 購入数、`article_price_cvr`（記事 × 価格区間の PV・購入・CVR¥）、シート `note購入記録`・`note価格履歴` |

CSV は `scripts/note_funnel_export.py` が発信記録シートから書き出す（ヘルパーが実行のたびに最新を作る）。
