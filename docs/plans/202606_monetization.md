## 2. note 計画（¥980で売り抜く施策）

### 必要販売数

```
¥10,000 ÷ ¥980 = 10.2部/月
```

### 実績ベースライン

| 指標 | 実測値（2026/03〜05） |
|---|---|
| 価格別実績 | ¥490: 4部 / ¥200: 3部 / ¥100: 11部 / **¥980: 0部** |
| 3ヶ月合計 | 18部・¥3,660（月平均 ¥1,220） |
| リンクCTR（IMP→クリック） | 0.23% |
| 購入CVR（クリック→購入） | 0.7% |

**¥980 での販売実績はゼロ**。価格を維持して目標達成するには、CVR を下げない差別化施策が必須。

### 施策1：コンテンツ差別化

| 項目 | 既存 ¥100-490 | 新 ¥980 仕様 |
|---|---|---|
| 文字数 | 2,000-4,000字 | **8,000-12,000字** |
| 章構成 | 1-2章 | **3-4章＋エピローグ** |
| 図解 | なし or 1点 | **インフォグラフィック 2-3点**（visual_infographic 活用） |
| 独自要素 | Xの延長 | **原文資料の直訳・関係者証言・当時の年表** |
| 位置づけ | 続き | **「決定版」「完全版」** |

### 施策2：販売導線の強化

**A. 無料部分の最適化**
- 冒頭 2,000-3,000字 を無料公開
- 課金壁は **物語のクライマックス直前** に置く

**B. X タッチポイント増加（1記事あたり3-4回）**
1. W001 本編投稿 → セルフリプで note URL（既存）
2. 翌日：note の感想引用ポスト
3. 3-4日後：note 内の別エピソードを W001 化
4. 週末：購入者のスキ・コメントを引用RT

### 施策3：4本の検証設計（全 ¥980）

価格は4本とも ¥980 で固定し、コンテンツ・テーマ・導線の改善で CTR/CVR を引き上げる。

| 週 | 公開 note | 価格 | 目的 |
|---|---|---|---|
| W1 (6/1-7) | #1 完全版 | ¥980 | ¥980差別化版の初検証 |
| W2 (6/8-14) | #2 完全版 | ¥980 | 横展開・再現性確認 |
| W3 (6/15-21) | #3 完全版 | ¥980 | テーマ別の反応比較 |
| W4 (6/22-28) | #4 改善版 | ¥980 | W1-3の学びを反映・月末判断 |

### 期待売上シナリオ

W001 全8本に note 誘導（800K IMP/月）前提：

**推計式**

```
売上 = note 誘導IMP × リンクCTR × 購入CVR × 単価
     = 800,000 × 0.23% × CVR × ¥980
     = 1,840クリック × CVR × ¥980
```

- **note 誘導IMP 800K**：W001 月8本 × 想定10万IMP（うち note 誘導分）
- **リンクCTR 0.23%**：3〜5月実績の固定値 → 800,000 × 0.0023 = 1,840クリック/月
- **購入CVR**：シナリオごとに変動（楽観＝実績維持0.5% / 現実＝半減0.35% / 悲観＝1/4の0.18%）
- **単価 ¥980**：¥980 note を対象

| シナリオ | CTR | CVR | 部数 | 売上 |
|---|---|---|---|---|
| 楽観（CVR維持） | 0.23% | 0.5% | 9.2部 | **¥9,016** |
| 現実（CVR 半減） | 0.23% | 0.35% | 6.4部 | **¥6,272** |
| 悲観（CVR 1/4） | 0.23% | 0.18% | 3.3部 | **¥3,234** |

**CTR が実績の 0.23% のままだと楽観でも ¥9,016 で未達**。CTR を 0.26% に引き上げれば 10.4部・¥10,192 で達成できる（→ KPI 参照）。

### 補強案

| 補強 | 効果 |
|---|---|
| 過去 ¥100 note を ¥980「完全版」にリメイク販売 | 既存資産活用 |
| 6月末に「6月の note 4本セット ¥2,980」マガジン化 | クロスセル |

## 3. 6月 実行スケジュール

- **毎朝 6時**：W003（ワンポイント解説）

### 誘導モデル（クロス週）

note は金曜に公開し、**翌週の月・木 W001 から誘導する**。W001 投稿時点で note が公開済みのため、本編のセルフリプで note URL を直接貼れる。

```
金 note公開  →  翌週 月・木 W001（公開済みnoteへ誘導）
```

| 週 | 月日 | note 公開 | 価格 | 誘導するW001 |
|---|---|---|---|---|
| W1 | 6/1-7 | 金 18:00 #1 完全版 | ¥980 | 6/9・6/12 |
| W2 | 6/8-14 | 金 18:00 #2 完全版 | ¥980 | 6/16・6/19 |
| W3 | 6/15-21 | 金 18:00 #3 完全版 | ¥980 | 6/23・6/26 |
| W4 | 6/22-28 | 金 18:00 #4 改善版 | ¥980 | 6/30・7/3 |

- 初週 6/2・6/5 の W001 は、前月の人気 note へ誘導（or 純バズ狙い）。
- #4 note の誘導 W001 は一部 7 月にずれる。
