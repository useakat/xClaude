## 2. note 計画（¥980で売り抜く施策）

### 必要販売数

```
¥10,000 ÷ ¥980 = 10.2部/月
```

### 実績ベースライン

| 指標 | 実測値（2026/03〜05） |
|---|---|
| 価格別実績 | ¥490: 4部 / ¥200: 3部 / ¥100: 11部 / **¥980: 0部** |
| 3ヶ月合計 | 18部・¥3,660（月平均 ¥1,220） |
| リンクCTR（IMP→クリック） | 0.23% |
| 購入CVR（クリック→購入） | 0.7% |

**¥980 での販売実績はゼロ**。価格を維持して目標達成するには、CVR を下げない差別化施策が必須。

### 施策1：コンテンツ差別化

| 項目 | 既存 ¥100-490 | 新 ¥980 仕様 |
|---|---|---|
| 文字数 | 2,000-4,000字 | **8,000-12,000字** |
| 章構成 | 1-2章 | **3-4章＋エピローグ** |
| 図解 | なし or 1点 | **インフォグラフィック 2-3点**（visual_infographic 活用） |
| 独自要素 | Xの延長 | **原文資料の直訳・関係者証言・当時の年表** |
| 位置づけ | 続き | **「決定版」「完全版」** |

### 施策2：販売導線の強化

**A. 無料部分の最適化**
- 冒頭 2,000-3,000字 を無料公開
- 課金壁は **物語のクライマックス直前** に置く

**B. X タッチポイント増加（1記事あたり3-4回）**
1. W001 本編投稿 → セルフリプで note URL（既存）
2. 翌日：note の感想引用ポスト
3. 3-4日後：note 内の別エピソードを W001 化
4. 週末：購入者のスキ・コメントを引用RT

**C. 早期割引**
- 公開初日のみ ¥490 → 2日目以降 ¥980
- 初日に部数を稼ぎ、社会的証明（スキ・評価）を作る

### 施策3：A/B テスト（4本の価格設計）

| 週 | 公開 note | 価格設定 | 目的 |
|---|---|---|---|
| W1 (6/1-7) | #1 完全版 | ¥980 | 差別化版の単発検証 |
| W2 (6/8-14) | #2 既存型 | ¥490 | 比較対照 |
| W3 (6/15-21) | #3 早期割引 | 初日¥490 / 以後¥980 | 早期割引の効果検証 |
| W4 (6/22-28) | #4 改善版 | ¥980 | W1の改善版・月末判断 |

### 期待売上シナリオ

W001 全8本に note 誘導（800K IMP/月）前提：

| シナリオ | CTR | CVR | 部数 | 売上 |
|---|---|---|---|---|
| 楽観（CVR維持） | 0.23% | 0.5% | 9.2部 | **¥9,016** |
| 現実（CVR 半減） | 0.23% | 0.35% | 6.4部 | **¥6,272** |
| 悲観（CVR 1/4） | 0.23% | 0.18% | 3.3部 | **¥3,234** |

**¥10,000 は楽観シナリオでもギリギリ届かない**。早期割引や補強案で積み上げる必要あり。

### 補強案

| 補強 | 効果 |
|---|---|
| 過去 ¥100 note を ¥980「完全版」にリメイク販売 | 既存資産活用 |
| 6月末に「6月の note 4本セット ¥2,980」マガジン化 | クロスセル |
