## 概要

身近な科学・宇宙の驚く事実をワンポイントで解説する X 投稿を作成する。

## 使い方

```
/writer-xonepoint
/writer-xonepoint 宇宙エレベーター
```

引数なしの場合、`database/onePointNeta.csv` から未使用ネタを自動選定する。

## 出力

- **タイトル案** 10個（意外性のあるタイトル候補）
- **本文** 140〜300字

## 投稿の構造（4段構成）

1. **冒頭** — 「実は、〇〇は△△だ。」形式で常識を裏切る
2. **対比** — 「地球では〜 / 一方〜」で意外さを強調
3. **仕組み** — 平易な言葉で簡潔に説明
4. **締め** — 読者の日常生活につながる1文で終わる

## 文体

詳細は `style/style-xonepoint.md` を参照。  
基本は言い切り調（「〜だ」）、ハッシュタグなし、絵文字なし。

## 自動処理

本文出力後、使用したネタのステータスを「使用済み」に自動更新する。
