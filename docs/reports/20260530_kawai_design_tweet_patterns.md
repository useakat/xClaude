## 概要

`@kawai_design` の過去1ヶ月（2026-04-30〜2026-05-30）の投稿590件を対象に、冒頭1文のパターンを分類し、インプレッション平均を算出。IMP平均上位10パターンのうち、**2〜5位**の使用例を記録する。

| 順位 | パターン | 平均IMP | 件数 |
|---:|---|---:|---:|
| 1 | URLのみ（リンク投稿） | 27,682 | 33件 |
| **2** | **問いかけ型** | **12,016** | 10件 |
| **3** | **【】タイトル型** | **8,119** | 89件 |
| **4** | **短文報告・誘導型** | **6,189** | 260件 |
| **5** | **＼○○／ 囲み型** | **5,299** | 6件 |
| 6 | 一人称（私が/は）起点 | 4,404 | 5件 |
| 7 | AI〜で始まる主張・観察型 | 3,956 | 52件 |
| 8 | その他（主張・ストーリー型） | 3,349 | 115件 |

※1位「URLのみ」は、バズった投稿への引用RTが集まる構造のため除外。

---

## パターン2：問いかけ型（平均IMP: 12,016 / 10件）

**冒頭が疑問文・問いかけで終わるパターン。**  
「なぜ〜？」「どう〜ですか？」「これが〜!!!???」など、読者に問いを投げかけて続きを読ませる。

### 代表例

**① IMP 55,027**
```
これが、動画生成!!!???

Gemini Omni とやら、
すごすぎる。
```
> 驚き・感嘆の問いかけ。ニュース速報的に反応を引き出す型。

**② IMP 26,765**
```
どう使っていますか？

🟦 Skills と 🟧 SubAgent

ぜひ聞かせてください☺️

私の考えは↓に書きました。
```
> 読者に直接問いかけてエンゲージを促す。回答を誘導しながら自分の考えへ誘う。

**③ IMP 12,021**
```
なぜ、AIで作ったデザインが
毎回 " バラバラ " になるのか？

その理由は、

「センス不足」ではなく、
最初に渡す「ルール不足」

特に抜けるのはこの4つ。
✅ 使う色
✅ 余白の広さ
✅ 写真のトーン
✅ 避けたい表現
```
> 「なぜ〜か？」で痛みを言語化し、「センスではなくルール」と逆説で返す。問いと答えが一体になった型。

## パターン3：【】タイトル型（平均IMP: 8,119 / 89件）

**冒頭を【 】で囲んだタイトル見出しで始めるパターン。**  
「緊急」「超簡単」「〇〇大辞典」など価値・希少性を一語で示す。件数89件と最多量産パターン。

### 代表例

**① IMP 76,019**
```
【 文字のアニメーション100選 】

Webサイトに動きが欲しい。
でも、何て指示すれば良いの？
```
> 「100選」という量・網羅性の権威。すぐ使えるツール感を提示。

**② IMP 63,648**
```
【 超簡単 】
広告生成プロンプトがサクッと作れる
アプリと使い方を徹底解説
（プロンプトをスレッドに掲載中）
```
> 「超簡単」でハードルを下げ、「広告生成×アプリ」という具体的な成果物を続けて提示。

**③ IMP 41,642**
```
【 緊急で公開 】

「Markdown ファイル」を
「HTML でプレビュー」できる
Webアプリを作りました。
```
> 「緊急」で希少性・速報感を演出。公開直後の限定感でクリックを引き込む。

## パターン4：短文報告・誘導型（平均IMP: 6,189 / 260件）

**20字未満の短い冒頭で、すぐ本題に切り込むパターン。**  
件数260件（全体の44%）と最量産。「〜が苦手な人は」「〜を全部まとめた」のように読者の悩みを冒頭で代弁する形が高IMP傾向。

### 代表例

**① IMP 312,876**
```
UIデザインパターンを
全部1ページにまとめた
辞典サイトを作りました！

ハンバーガーメニュー、カンバン、OTP入力、ボトムシート…
108種のUIパターンを「名称 × ミニチュア実物」で一覧できます。

「あのUI、名前なんだっけ？」

そんな疑問が一発で解決します。
```
> 「全部1ページ」という網羅性＋「名前なんだっけ？」という共感フレーズが刺さった。

**② IMP 77,377**
```
「配色が苦手」は、
色を知らないだけです。

センスの問題ではありません。
良い配色を見た回数と、
それを使える形で持っているかの差です。
```
> 「苦手」を冒頭に置き、「センスではない」と即座に逆説。読者の言い訳を崩す構造。

**③ IMP 67,441**
```
コピーが弱い人は、
語彙が少ないだけです。

「すごい」「便利」「おすすめ」だけでは、人は動きません。

好奇心、共感、権威、希少性、行動喚起、失敗回避。
売れる言葉を150語、タイトル例を150本まとめた
スパイス辞典を作りました。
```
> 「〜が弱い人は、〇〇なだけです」という断定フォーマット。痛みの指摘 → 原因の単純化 → 解決ツール提示の流れが完成形。

## パターン5：＼○○／ 囲み型（平均IMP: 5,299 / 6件）

**＼ テキスト ／ で囲んだシリーズ名をタイトルにするパターン。**  
「1日1つ学ぶ」「にゃーにゃーにゃー」のように、シリーズ感・遊び心を演出する。件数は少ないが安定して高IMP。

### 代表例

**① IMP 8,477**
```
＼ 1日1つ学ぶ ／
Claude Code入門【 Vol.2 】

CLAUDE.mdは
Claude Codeに渡す「業務マニュアル」です。

イメージは " 新人教育 " 。
毎回口で説明するより、最初に手順書を渡した方が、作業は安定します。
```
> シリーズ化で継続フォロー動機を作る。「毎日少しずつ」の約束が安心感につながる。

**② IMP 8,035**
```
＼ にゃーにゃーにゃー ／
プロンプトCOLLECTION

222個の画像生成プロンプトを
" 無料公開したWebサイト " おーぷん

どなたでもアクセスできます。
```
> 遊び心のある囲み文字で目を引き、「無料公開」と「222個」の量で保存欲を刺激。

**③ IMP 6,345**
```
＼ 1日1つ学ぶ ／
Claude Code入門【 Vol.1 】

Claude Codeは
「相談窓口」ではなく、現場の「作業担当」です。

ここを間違えると、最初の使い方がズレます。
```
> Vol.1 から始まるシリーズ設計で、新規フォロワーに「最初から追える」安心感を与える。

## 所見・よーんへの示唆

| パターン | 活用可否 | メモ |
|---|---|---|
| 問いかけ型 | ◎ | 「なぜ〜？」はよーんの発信軸（科学の本質を問う）と相性が良い |
| 【】タイトル型 | ◎ | 「【 緊急で公開 】」「【 完全版 】」などW001-note 連動に使える |
| 短文報告・誘導型 | ○ | 「〜が苦手な人は」の断定フォーマットは note 誘導冒頭に転用可 |
| ＼○○／囲み型 | △ | W003シリーズ化（週7本）に導入を検討できるが、よーんの文体との相性要確認 |
