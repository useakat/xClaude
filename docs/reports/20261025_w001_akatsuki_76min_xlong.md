## 背景・動機

w002 の `funnel-brief.md` が決めた切り口（2015/12/7 の20分ブレーキ）は、note の見せ場と重なり、冒頭の像も結びにくいためユーザーが破棄した。候補A「76分の沈黙」（2010/12/7、金星の裏側で電波が途絶えた76分）で、モードC のまま W001 を制作した。

## 実施内容

- 本文約650字（冒頭フック2文＋本編）。可視ブロック（先頭280 weight）は「はずだった。」で終え、答えは折り返しの向こうに置いた。
- **試験設計**: 「Xは完結した短い物語、クリフハンガーにしない」を今回は意図的に破った。結末（5年後に金星へ戻れたか）は書かず、セルフリプで note に誘導する。ハッシュタグなし、締めの一文なし。
- 事実確認は NotebookLM のブラウザブリッジ（`notebooklm_browser_bridge.py`）で実施。数値（約2分30秒・76分遅れ・約5分の1）を計算し直し、「5分の1にも届かない」を「約5分の1」に修正した。
- check-fact-lim → check-reader → check-reader --fold → check-critic → check-yohn → check-brand を順に実行。項目7（結末の完結）は意図した設計のため7点のまま。
- サムネイル: lovart で5回再生成（ISAS 公式 CG を参照）。あかつきのサイズは「画面幅の約40％」のように数値で指定して解決。池下章裕氏の想像図は個人作品で利用条件が不明のため不採用。
- 画像出典: ISAS の利用ルール（出典「ISAS/JAXA」を明示すれば届け出なしで利用・加工可）に従い、本投稿の末尾に「画像: ISAS/JAXA」を入れた。
- セルフリプ: 「あかつきチーム・執念の金星再チャレンジ、noteに書いてます。→ [note URL]」。note 未公開のため Gmail 下書きには `[リプ]` を入れていない（cron が `[note URL]` を投稿するのを防ぐ）。
- Gmail 下書き作成、`hook_records.csv` への追記、Drive へのアップロード。
