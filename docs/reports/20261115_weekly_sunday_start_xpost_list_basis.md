## 背景・動機

2026-W46 の週次発信運用振り返り（routine）で、当週の X 投稿本数を「7本」と報告したところ、よーんから「月〜土で11本ないか」と指摘があった。調べると、レポートの投稿集計が outputs シート（スキル制作の記録）基準だったため、outputs に載らない手動投稿（感謝投稿・販促短文・小ネタなど当週4本、8週窓では15本。うち 9/29「998001」トリビアは 978,550 IMP）が毎週集計から漏れていた。

あわせて、よーんから週の区切りを「日曜始まり（日〜土）」にしたいという指示があった。従来は月〜日で「実行日を含む今週」を対象にしていたため、日曜 20:00 の routine 実行では常に集計が途中経過（週間インプは「暫定・月〜土合計」）になっていた。

## 実施内容

- **対象週を「直近の完了した日〜土週」に変更**（reporter-weekly-ops / reporter-weekly 共通）
  - 日曜 20:00 の ops routine では「前週日曜〜昨日（土曜）」、月曜朝の週報 routine では「一昨日の土曜までの週」が対象になり、どちらも**完了週＝確定値**でレポートできる
  - week_id は週内の月曜の ISO 週番号、week_label は開始日曜の日付（例: 11/15〜11/21 → 2026-W47「11月15日週」）
  - 移行: 2026-W46 までは月〜日集計。11/15（日）は旧 W46 と新 W47 の両方に含まれる（重複1日）。新方式初回のレポートに注記する
- **週間インプの定義を「日次インプの日〜土合計」に変更**
  - シートの `週間インプ` 列（日曜行・月〜日定義・月曜朝記入）は定義が異なるため使わない。週報のフォロワー増減も土曜行同士の差分に変更（総フォロワ数・noteフォロワ数は毎日記録されていることを確認済み）
- **ops の投稿集計を X投稿一覧基準に変更**
  - 当週・8週ローリングとも「X投稿一覧の通常ポスト全量」を母集合にし、outputs と tweet ID で突合して what_id を付ける。outputs に無い投稿は「分類外（手動）」として本数・IMP を KPI タイル・実績表・投稿一覧に含める
  - ただし ②の改善分析・H8 の比較群・z01 ベースライン・分散記録には入れない（what_id が無く、事前固定した検証の定義を変えないため）
  - 投稿0本日の判定も X投稿一覧の通常ポスト基準に明記（手動投稿も1本と数える）
- **note 導線スクリプトの週割りは月曜基準のまま維持**（N 施策の before/after 窓は事前固定のため。`note_funnel_measures.py` には対象週内の月曜を渡す）
- 2026-W46 レポートの投稿本数を修正（7本 → 通常ポスト11本・うち手動4本、引用RT 2本は別枠）

## 設計判断

- **対象週は「実行日を含む週」でなく「完了週」にした**: 日曜夜に日〜土週の「今週」を対象にすると開始1日しか経っておらず振り返りにならない。完了週を対象にすることで、暫定値の注記や翌週の確定値訂正が不要になる
- **手動投稿を改善分析・比較群に入れない**: H8（自己開示のプロフ率）や z01 ベースラインは比較群・母集合を事前固定して検証中のため、母集合の定義変更で数字が動くのを避けた。手動投稿は本数・IMP の実績把握のみに使う
- **note 導線の週割りは変えない**: N1〜N3 の before/after 窓（9/7 週〜）は月曜週で事前固定済み。レポート側の週区切りとずれる（両端1日）が、窓の合算値で判定するため影響は小さく、検証の連続性を優先した

## 確認結果

- 週計算コードを 日曜/月曜/水曜/土曜 実行・年末跨ぎ（2027-01-03 実行 → 2026-12-27〜2027-01-02・2026-W53）・引数指定の各ケースでテストし、すべて期待どおりの週を返すことを確認（初版の `last_sat -= 7` の型バグは timedelta に修正済み）
- X投稿一覧基準の検算: 2026-11-09〜11-14 の通常ポスト9本＋引用RT 2本＝11本が日次記録のポスト数合計と一致、日曜2本を足した通常ポスト11本が修正後レポートの本数と一致
- 土曜行の 総フォロワ数・総フォロー数・noteフォロワ数 が毎日記録されていることを日次記録の実データで確認

## 今後の課題

- **ops routine のプロンプト修正（よーん対応待ち）**: スケジュールタスク「発信運用振り返り（reporter-weekly-ops）」は http_api 作成のためエージェントから更新できない。プロンプト中の「対象週＝実行日を含む今週（月〜日）」を「対象週＝直近の完了した日〜土週（前週日曜〜実行日前日の土曜）」に、<https://claude.ai/code/routines/trig_01XrHUmbomeAsRtXC9LLfuLu> で手動修正が必要
- reporter-monthly-ops など月次側は月単位集計のため今回は変更していない（週次レポートの参照部分で週 ID の指す範囲が 11/15 を境に変わる点だけ留意）
- 手動投稿を outputs に記録する運用にするかは未決（今回は「集計側を X投稿一覧基準にする」で対処）
