## 背景・動機

知人から「3時間以内に1,000インプで通知する機能が欲しい」と相談があり、その人向けの実現方法（GAS 等）を検討する中で、X API の現行料金を調べ直した。2026-02-06 以降、新規開発者向けの Free / Basic などの定額プランは廃止され、**従量課金（pay-per-use）のみ**になっている。課金単位は「リクエスト回数」ではなく「返ってきた投稿1件ごと」（自分の投稿 = Owned Read は $0.001/件、他人の投稿は $0.005/件）。よーんのアカウントも従量課金で動いている。

現行の `x_imp_alert.py` は定額プラン前提で作っており、10分おきに「直近20件」を必ず取得し、時間窓（3時間）の絞り込みはスクリプト側で行っていた。この作りだと、窓内に投稿が無い時間帯でも3日前の投稿20件が返って20件分課金される。投稿頻度に関係なく月 $8〜9 が固定でかかる計算になる。

## 実施内容

- `GET /2/users/{id}/tweets` に `start_time`（現在時刻 − 時間窓 − 10分）を指定し、時間窓の外の投稿を X 側で除外するようにした。窓内に投稿が無ければ0件で返り、課金も発生しない
- `max_results` を 20 → 10 に縮小（`start_time` で絞られるので安全弁として）
- cron のチェック間隔を 10分 → 30分 に変更（VPS crontab を `*/30 * * * *` に書き換え。`run_x_imp_alert.sh` 冒頭のコメントも同期）
- スクリプトのヘッダに従量課金の注意書きを追記

### コストの目安（Owned Read $0.001/件）

| 条件 | 1投稿あたり読取回数 | 10投稿/日の月額 |
|---|---|---|
| 変更前（直近20件固定・10分） | — | 約 $8.6（投稿数に関係なく固定） |
| start_time 絞り込み・10分 | 18回 | 約 $5.4 |
| start_time 絞り込み・30分（採用） | 6回 | 約 $1.8 |

## 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `scripts/x_imp_alert.py` | `fetch_recent_posts()` に `start_time` を追加（`now`・`window_hours` を引数化）。`MAX_RESULTS` 20→10、`START_MARGIN_MIN=10` を新設。ヘッダに課金の注意を追記 |
| `scripts/run_x_imp_alert.sh` | cron 記載コメントを `*/30` に同期 |
| crontab（VPS、git 管理外） | `*/10` → `*/30` |

## 設計判断

- **インプ数での絞り込みは API 側ではできない**。投稿一覧エンドポイントの条件は時刻・ID範囲・種別だけで、指標（インプ・いいね）による条件は存在しない。検索 API にも `min_faves:` 相当の演算子は無い。したがって「監視中の投稿1件につき1チェック1読み取り」が課金の下限で、これ以上減らすならチェック間隔を伸ばすしかない
- **`start_time` の余裕は10分のまま**（チェック間隔に合わせて30分にはしない）。時間窓の外はスクリプト側でも除外するので、余裕を広げても窓際の投稿を余分に読んで課金が増えるだけ。10分は時計ずれ対策
- **30分間隔の代償**: 1,000インプ到達から通知まで最大30分の遅れ。また投稿から3時間ちょうど手前の到達は最後のチェックを逃す可能性がある。よーんの判断でコスト優先とした

## 確認結果

- `--dry-run`（3時間窓）: 直近3時間に投稿なし → 「時間窓内0件」で正常終了。従来なら20件返っていた場面で0件になることを確認
- `--dry-run --hours 24`: 4時間36分前の投稿1件（670インプ）を取得・判定。`start_time` 指定で正しく窓内の投稿が返ることを確認
- `crontab -l` で `*/30 * * * *` への変更を確認

## 今後の課題

- 知人向けには、相手自身が X Developer に登録（スマホのブラウザで完結、クレジット少額前払い）し、GAS に移植したコードを時間トリガーで動かす構成が現実的。よーんによる代行監視は行わない方針。GAS 版は未着手
- Owned Read の割引（$0.001）が app-only の Bearer Token で適用されるか、OAuth ユーザー認証が必要かは公式に明記が無い。通常料金（$0.005）になると月額は5倍。Developer Console の請求で実際の単価を確認する
