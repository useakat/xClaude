## 背景・動機

アポロ12号「SCEをAUXに」の note 販促 X長文（W001・2回目、`projects/w001/20260919_アポロ12号販促/`）で、check-fact-lim → check-reader（2巡）→ check-fold → check-critic → check-yohn（2巡）を通した原稿を提示したところ、よーんから**27件の修正指摘**が出た。W001 spec フロー6.8 の自己改善ループ「フロー7 でユーザーから出た新規指摘は check-yohn の見逃し」に従い、繰り返し出る型を検品ペルソナに追記する。

27件を系統分けすると、時制の統一（3件）／主語・指示語の明示（5件）／時間の接続語（3件）／語りの熱量（2件）／場面の順序と視点（4件）／note の売りの温存（2件）／語の選択（4件）／形式（4件）となった。このうち**判断基準として言語化できる5系統**を追記対象にした。よーん本人の要望で「判断基準が漠然としている書き方は避け、いつ直すかが決まるテストを添える」形にしている。

「ハッシュタグなし」「700字帯」は今回だけの指示（よーん確認済み）のためペルソナにも brand.md にも反映しない。

## 実施内容

- **W9 拡張（主語・目的語・指示語を省かない）**: 省略していなくても、名詞が2つ以上の候補を持ちうるなら指示語（その／この）か所属（〜の）で1つに絞る。判断テスト＝「読者が『どの？』『何の？』と一瞬でも候補を選ぶなら補う」。実例5件（その指示／この若手管制官の指示／管制室モニターの数字／記号の羅列／その意味）。
- **W10 新設（時間の接続語を文頭に置く）**: 前文との時間関係が一意に決まらないなら文頭に接続語。語は関係の種類（同時／直後・経過／逆接／転換の合図）に合わせて選び、決まった語彙は持たない。判断テスト＝「接続語を外して読んだとき、同時か・あとか・どれくらいあとかが決まるか」。当初案の「4つの語で足りる」はよーんの指摘で撤回した。
- **W11 新設（視点の往復を減らす）**: 同じ場面で視点を A→B→A と往復させない。判断テスト＝「1場面で3回以上切り替わっていたら真ん中の文が犠牲候補」。実例＝船長コンラッドの戸惑いの台詞を削除（地上→機内→地上→機内になっていた）。
- **W12 新設（余白で山場を作る）**: 山場の一語文（「カチリ。」）は前後に空行2つ。通常段落は空行1つ。2箇所以上に使うと効かない。
- **W13 新設（サムネの明るさ）**: 夜・室内のシーンでも、スマホ縮小表示で人物の姿勢と主要モチーフが読み取れる露出にする。判断テスト＝「縮小して3秒で『何をしている絵か』が言えるか」。生成時の再指示は「構図・配色・人物配置を変えず露出を1段上げ、環境光を少し足す」。

## 設計判断

- **W9 の拡張として書いた理由**: 既存の W9 は「省略しない」だったが、今回の指摘は省略ではなく「特定できていない」型（数字→管制室モニターの数字）。同じ「読者が戻る」症状なので節を分けず、判断テストの範囲を広げた。
- **W10 の語彙を限定しなかった理由**: 当初「その瞬間／その後／しかし／──そのとき の4つで足りる」と書いたが、よーんから「そうとも限らない」と指摘。語を固定すると検品役が語の有無で機械判定してしまうため、関係の種類ごとの例示にとどめ、判断は「時間関係が読者に決まるか」のテストに寄せた。
- **サムネの基準を W001 ペルソナに置いた理由**: check-yohn は本文検品だが、W001 spec フロー10 のレビュー基準（文字なし・結末なし・年代整合）に明るさの項目が無く、今回「ちょっと暗いかな」で差し戻しが発生した。まずペルソナに実例として残し、再発したら spec のレビュー基準へ昇格させる。
