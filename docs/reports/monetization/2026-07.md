### 3. 来月マネタイズ計画案

**マネタイズ目標**
- note 売上 **5,000円/月**（7月比 +1,570円）。主力＝執念の物語系 W001、価格帯 200〜490円。
- 有料note **月2本**（うち1本は既存人気テーマの続編・関連）。

**X・threads 運用の修正案**
1. **長文ストーリー(W001)の打率を上げる**。当たり1本依存なので、フックとテーマを売れたボイジャー型（不屈・再起）に寄せて安定させる。本数は月3→4本。
2. **ワンポイント解説の本数を戻す**（月4→7本目安）。効率は堅調で、量の絞りすぎがリーチ減の主因。
3. **短文は絞る**（11→6本目安）。低効率なので枠を W001・W003 へ。
4. **outputs 記録の徹底（note_url を必ず付ける）**。今回ボイジャーが導線表から抜けた原因。W001 の本体投稿に note_url を記録すれば、次月から売れた導線を型別に追える。セルフリプが(未記録)に沈む問題も、手動投稿・リプへの型付けで解消。

**note 導線の修正案**
1. **CTR/CVR の定点観測を開始**。CSV取込が回るようになったので（要毎月アップロード）、W001 ごとに「本体IMP→セルフリプCTR→購入CVR」を毎月追い、フック改善の効果を測る。
2. **執念の物語系で有料note を増産**。ボイジャー1号の実績（6件・CVR約0.49%）を横展開し、探査機の再起・不屈テーマを定番導線化。
3. **売れたセルフリプ誘導文のテンプレ化**。ボイジャー投稿の誘導文（1,215クリックを生んだ）を型化し、他 W001 でも再現する。

### 脚注（集計上の制約）
- outputs 未記録の投稿は型別・導線の集計対象外（型は「(未記録)」「(元投稿不明)」に計上）。ボイジャー再点火は本体投稿の note_url が 7/24 の自動記録導入前で空だったため、outputs.F を手動バックフィル（`n4ce6fbbf837f`）して導線表に反映済み。
- threads の型は outputs の threads行（permalink→元x_url→what_id）で解決。元X投稿が outputs 未記録だと「(元投稿不明)」（7月は49本中23本が未解決＝主に下書き転載の旧投稿）。
- 導線クリックは note リンクを載せたセルフリプ行のリンククリック合計を使う。X投稿一覧のリンククリック列は毎月 CSV 取込（update-x-analytics）が必要で、未取込の月はクリック0・CTR0 になる。
- 導線の売上/購入は note 記事単位（型内で重複排除）。月次総売上は note購入記録の実勢合計（本レポートの「売上」表）を正とする。
