## 背景・動機

他アカウントの投稿フック（冒頭1文）のパターンを分析し、効果の高い書き出しを学ぶための仕組みが欲しかった。既存の分析スキルは自アカウントの数値集計が中心で、「冒頭文のパターン」を外部アカウントから帰納的に発見する手段がなかった。

パターンを regex でハードコードすると、アカウント固有の傾向を取りこぼす・新しい型に対応できないという問題があるため、事前定義せず LLM で帰納的に分類する方式とした。

## 実施内容

- `research_xhook` スキルを新設：指定 X アカウントの投稿を X API で取得し、冒頭1文のパターンをゼロから帰納的に発見・命名・分類して、IMP平均でフックパターンをランキング提示する
- 入力は X ユーザー名（必須）＋期間（任意、デフォルト30日）
- パターン分類を regex ハードコードから **LLM 帰納型** に変更（後続コミット）
- `.claude/skills/metadata.yaml` に登録

## 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `.claude/skills/research_xhook/SKILL.md` | スキル本体を新設。冒頭1文のフックパターンを帰納的に分類・ランキングする手順を定義 |
| `.claude/skills/metadata.yaml` | research_xhook をリサーチ・分析カテゴリに登録 |

## 確認結果

`/research_xhook` で呼び出せること、metadata.yaml への登録により Wiki スキル一覧へ反映されることを確認。
