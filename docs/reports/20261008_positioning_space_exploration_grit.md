## 背景・動機

「非専門家に xx の面白さを伝える」の xx に何を入れるか、という問いから始まった。plan.md（2026-05-30 版）は「宇宙・物理に興味はあるが専門的な説明では理解しきれない人」に「物語・直感・比喩で分かりやすく届ける」という定義で、ポジション（何の人として覚えられるか）と、実際に伸びている型（執念の物語）が言葉になっていなかった。

途中で外部の意見（Persona＝「理系じゃないから難しい」と感じる人／Pain＝面白さまでたどり着けない／How＝難しい科学を「え？→なるほど」の驚きに翻訳／一文＝「難しい科学を、思わず誰かに話したくなる驚きに変える」）が提示され、それを検討する形で確定した。

## 実施内容

- **題材は「宇宙探査」**（＝人類が宇宙を探る営み：探査機・望遠鏡・検出器）。「宇宙」「物理」「科学」は範囲の言葉で、宇宙探査は約束の言葉。bio を初めて見た人が次の 10 投稿を予想できるのは後者
- **中身は「執念」、技法は「驚き」**。2026-06〜10 の通常ポスト（インプ 100 以上）で、長文（執念の物語）はインプ 1 万あたりフォロー増 0.70、短文（驚きの解説）は 0.13 と 5 倍差。短文は到達とリンククリック（1,076 vs 115）で効く。驚きは全投稿に使う道具、執念はよーんが何者かを決める中身
- **Persona と Pain・How の言葉を分ける**。Persona は読者の自己認識（宇宙・物理）、Pain・How・ポジション・価値は約束の言葉（宇宙探査）。Persona を宇宙探査にすると読者が探査ファンに狭まる。Pain を宇宙・物理のままにすると How との整合が崩れるので、Pain は「宇宙探査って面白そうなのに、難しくて、その面白さまでたどり着けない」に統一
- **Pain は 1 つに絞る**。「粘る生き方を肯定してほしい」は読者が自覚している悩みではなく、Pain に入れると自己啓発（説教）の方向に引っ張られる。「読後に残るもの」として価値の側に置いた
- **ポジションに執念を入れる**。旧案「宇宙探査を、理系じゃない人にも面白いと思わせる人」は解説の人に見えるため、「宇宙探査の執念を、理系じゃない人にも面白く語る人」に
- **運用ルール**：bio・固定ポスト・note の自己紹介は執念で統一（最初に見る場所が驚きトリビアだと「科学小ネタの人」と覚えられる）。宇宙と無関係な物理・数学トリビアは息抜き枠
- `plan.md` を書き換え（旧版は `plan_v1.md` にアーカイブ）、`CLAUDE.md` の「発信軸」節を同じ内容に更新。`research_pain-xpost` が参照する ①②③ の番号は維持

## 確定した定義

| | |
|---|---|
| ポジション | 宇宙探査の執念を、理系じゃない人にも面白く語る人 |
| Persona | 宇宙や物理に興味はあるけど、理系じゃないので「好き」と言い切れない人 |
| Pain | 宇宙探査って面白そうなのに、難しくて、その面白さまでたどり着けない |
| How | 宇宙探査にかけた執念の人間ドラマを、直感を裏切る驚きで届け、物理的な理由まで分かりやすく解く |
| サービス価値 | 宇宙探査にかけた執念のドラマを、思わず誰かに話したくなる驚きとともに聞ける |
| 読後に残るもの | 「あきらめの悪さは、こんなに美しい結果を生む」という感覚 |

## 設計判断

- **外部の意見のうち採用したもの**：Persona の自己認識「理系じゃないから難しい」、短文の 4 段構造（え？→知らない難しさ→科学で解く→なるほど）、「分かりやすく説明する人」ではなく「面白いと思わせる人」という位置取り
- **採用しなかったもの**：題材を「科学」に広げること（土俵が消える）、「驚き」を中心に据えること（一番効いている執念が脇役になる）、Pain を認知面だけにすること（③の読後価値が落ちる）
- 検討の過程で「Persona も宇宙探査にすべきか」「Pain を 2 つ持つと曖昧か」「驚きと執念のどちらがメインか」を順に詰め、いずれも上記の形に収束した
