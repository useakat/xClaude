## 背景・動機

週次の振り返りは `/reporter-weekly`（数値週報）しかなく、「どの投稿が・なぜ伸びた/沈んだか」「来週の運用をどう変えるか」を扱う場が無かった。マネタイズは `/reporter-monetization` が担うが月次のみ。

新設に先立ち、@galileo_fun の全投稿分析（8/12）と自アカウントの8週実績分析（6/22〜8/16、40本）を行い、以下が判明した：

- **週インプの支配要因は W001 長文の有無**。長文ゼロの週（W31）は前週の 1/3 に沈む
- **投稿0本日は日次インプが 1/4〜1/6 に沈む**（8週で 9/10 日再現。例外の 7/22 は前日に W001 があり、長文の尾の可能性）
- **7月中旬にアカウントのベースラインが半減**（z01 中央値 2,678 → 1,050。IQR外れ値除外平均で 3,775 → 952）
- **W001 の切れ位置は「文末か」より「答え・種明かしの直前か」が効く**（オポチュニティ 26,914・カッシーニ 5,080 の上位2本のみが該当。桁を変えるのはフックの謎の強さ＝ボイジャー再点火 228,250）
- 平均IMPは少数の跳ねに支配されるため、**中央値＋IQR外れ値除外平均**の併記が必要
- プロジェクト間の期待値差（W001 6,501 > W003 2,142 > z01 1,678）は Mann-Whitney U 検定で**有意差なし**（p=0.11〜0.37、n 不足）。統計的結論には W001 n=15〜20 が必要

この分析を受けて「週2回の長文投稿を最優先・note 週1本」の運用方針が決定され、その遵守と仮説検証を毎週回す仕組みとして本スキルを新設した。

## 実施内容

- `/reporter-weekly-ops` を新設（カテゴリ: レポート生成）。役割分担を明記（weekly=数値週報 / 本スキル=運用振り返り / monetization=月次マネタイズ）
- レポート構成: ⓪運用遵守チェック（W001週2本・note週1本・0本日ゼロ）→ ①プロジェクト別実績（**過去8週ローリング**、中央値＋IQR外れ値除外平均＋最大、n<4 は実値列挙、z01ベースライン定点観測、W001分散記録の累積）→ ②伸び・沈み要因分析（フックの謎の強さ／折り返しは答え直前か／題材が執念・復活の物語か／ベースライン交絡の分離）→ ③前週アクション消化確認 → ④学び → ⑤来週アクション → ⑥検証中の仮説 → ⑦検証結果
- 初期仮説 H1〜H4 を登録（H1: W001の期待値優位・n=15で検定 / H2: 答え直前の折り返し設計 / H3: ベースライン回復・4週観察 / H4: 長文の尾＝曜日配置と休み方の根拠）
- デフォルト対象週は**実行日を含む今週**（月〜日）。引数で過去週も指定可
- STEP 8 にメール送信（`send_gmail.sh` で useakat@gmail.com へレポート全文）
- X投稿一覧の IMP が**投稿から最大8日分の累積**である旨をデータソースに注記
- routine 化: 毎週日曜 20:00 JST（cron `0 11 * * 0` UTC）、model=claude-fable-5、環境=Default。クラウド差し替え（Sheets→`sheets_values.py`、メール→Gmail コネクタ、push失敗時フォールバック）をプロンプトに明記。routine ID: `trig_01XrHUmbomeAsRtXC9LLfuLu`
- 初回レポート `docs/reports/ops-weekly/2026-W33.md`（8月10日週）を手動実行で作成

## 設計判断

- **中央値を主指標・平均は IQR 外れ値除外つきで併記**: galileo 分析（会話起点型の平均が1本のバズで 750万に化けた）と8週分析（W001 全体平均 38,180 vs 除外平均 6,501）の教訓。IQR法は中央値ベースのため外れ値自身に判定基準が引きずられない
- **8週ローリング集計**: 単週では n が小さすぎて中央値も不安定なため。ベースライン変化（7月中旬の半減）も8週窓で検知できた実績
- **仮説検証セクション（⑥⑦）を独立させた**: 学びが毎週流れて消えるのを防ぎ、支持/反証/保留の判定を引き継ぐ。H5（W006質問回答の期待値）は n=1 で行動も変わらないため、よーんの判断で登録から除外
- **routine のモデルは claude-fable-5**: よーん指定。API は受理済み。routine 設定にモデルのフォールバック機構は無いため、初回実行がモデル起因で失敗した場合は claude-opus-5 へ手動で切り替える
