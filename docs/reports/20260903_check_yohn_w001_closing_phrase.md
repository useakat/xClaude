## 背景・動機

W001 のルメートル販促投稿（note記事「ハッブルの影に消えた司祭」の2回目の販促）の制作で、
`/check-yohn` を **3周通過した**原稿の締めに、よーん本人から「イマイチ」の指摘が出た。

問題になった締め:

> 正しさだけでは、時代は動かない。
> だが、一度「正しい」と認められた計算は、時代がどう拒もうと消えてなくなりはしないのだ。

この締めは、冒頭フックであるアインシュタインの台詞「**あなたの計算は正しい**。しかし、
あなたの物理はひどい」と呼応させ、W1 の「冒頭の具体物と呼応して輪を閉じると強い」を
狙って作られたものだった。つまり**ペルソナの既存ルールに従った結果**として生まれた締めである。

check-yohn の3周では、締めについて次の指摘までは出せていた:

- 1周目（違和感）: 「種は埋め込まれていた」の比喩が本文に伏線がなく唐突（→ 修正済み）
- 3周目（構成）: 結びが本文の示す範囲を超えた前向きな断定になっている（W1 抵触）

しかし、**修正後の「一度『正しい』と認められた計算は〜」のぎこちなさは指摘できなかった。**
論理的には本文の範囲内で、W1 の既存項目のどれにも抵触しないためである。

問題は論理ではなく**言い回し**にあった。本文中の台詞をカギカッコ付きで引用し直したことと、
「認められた計算」という名詞句の硬さが、締めの一文としてこなれていなかった。

W1 は「ほぼ毎回直される」最重要項目でありながら、**輪の閉じ方の失敗パターン**が
書かれていなかった（「呼応させると強い」という成功条件だけがあった）。

## 実施内容

- `persona-yohn_w001.md` の W1（締めの一文）に、本文の語を締めで再利用するとぎこちなく
  なるパターンを実例つきで追記
- 失敗例（今回の「一度『正しい』と認められた計算は〜」）と、なぜぎこちないかの2つの理由
  （カギカッコ付き引用の再利用・硬い名詞句）を明記
- 採用された締め（「それでも、埋もれた正しさは腐りはしない。じっと時代が追いつくのを
  待っている。」）を対比として併記
- 判断の指針を1行に凝縮: **「呼応させるのは『意味』であって『語』ではない」**

## 設計判断

**既存の「冒頭の具体物と呼応して輪を閉じると強い」を消さず、その直後に置いた。**

呼応させること自体は有効な手法であり（アルミホイルの実例が既にある）、否定すると
使える型を1つ失う。問題は呼応の**やり方**なので、成功条件の直後に失敗パターンを
並べる形にして、「呼応はする。ただし語ではなく意味で」と読める並びにした。

**共通コア（`persona-yohn.md`）ではなく W001 補足に追記した。**
判断基準3（意味が像を結ばない表現）に近いが、今回のケースは像は結んでいる（意味は通る）。
「締めの一文の言い回し」という W001 で毎回問題になる箇所に固有の癖なので、
プロジェクト別補足が適切と判断した。

**バックテスト（今回の事例で再現するか）**: 追記後のペルソナであれば、
「一度『正しい』と認められた計算は」に対し「本文中の台詞をカギカッコ付きで引用し直しており、
『認められた計算』という名詞句も硬い」という指摘が出る形になる。
今回よーんが実際に選んだ「埋もれた正しさは腐りはしない」は本文の語を引かずに
一般命題へ持ち上げた形なので、追記した基準では指摘対象にならない。

## 今後の課題

同じ制作で見つかった spec の穴2件は、今回は記録を見送った（よーんの判断）。
再発したら改めて検討する:

1. **有料 note 記事の正本取得手順**（モードB の遡及作成）— 有料記事は本文が課金壁の
   向こうで取得方法が spec に未定義。`2026-04-16_venera7/README.md` に「output/index.md:
   未取得」として未解決のまま残っていた。今回はよーんが保存した記事ページの HTML から
   本文を抽出して解決した
2. **参照画像の著作権の存続確認** — spec は年代整合の確認のみ。今回1927年ソルベー会議の
   集合写真が Commons で PD タグ付きだったが実際は撮影者の没年が1962年でベルギー・
   フランスでは2033年まで保護、削除依頼も係属中だった（使用を見送り）。NASA/ESA 画像は
   基本 PD なので問題化しなかったが、歴史写真では年代確認だけでは足りない
