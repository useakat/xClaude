## 背景・動機

5/20 の [Xペルソナ分析](./20260520_x_persona_analysis/) ではよーんの全投稿への反応を分析した。今回は **コンテンツタイプ別の反応特性**を見るため、ワンポイント解説の中核フォーマットである「実は、〜」で始まる投稿に絞って分析した。

ブックマークは X API では個別取得不可（プライバシー仕様）のため、リプライ＋引用RT の2軸で実施。

## 分析対象

- **過去3ヶ月（2026-02-20〜2026-05-20）の「実は」で始まる投稿 28本**
- 累計：引用RT 326件 / リプ 248件 / ブクマ 3010件（数値のみ）
- ユニーク反応者：531人（リプ164＋引用378、重複11）

## 重要発見

### ① 学生層に届いている（1.41x、新発見）
全フォロワー 0.9% → 「実は」反応者 1.2%。**ワンポイント解説の文体・構成（教科書概念の裏側を短く深く）が高校〜大学初期層と相性◎**。
→ ペルソナ18（物理に目覚めかけている学生）を新設。

### ② 研究者・学術層も予想以上に反応（1.76x、判断保留）
全フォロワー2.4% → 反応者4.3%。「直感を裏切る事実フック」が学術関心層と相性◎。
**しかし plan.md の方針（科学素人への発信）に照らしてペルソナ追加は見送り**。
学術層は副次的な受益者として扱い、訴求軸はあくまで「素人が直感で分かる」を維持。

### ③ ブックマーク 3010 件の存在
平均107件/投稿。「保存して後で読む」サイレント層がフォロワーの 3% 規模で存在。
コア読者層の証拠だが、API では個別追跡不可。

### ④ 既存ペルソナの追認
クリエイター（1.64x）・シニア（1.70x）・映画/サブカル（1.43-1.28x）は引用RT分析と同じく拡散貢献。
既存ペルソナ04・16・17 への訴求は「実は」型でも有効。

## 戦略示唆

### ① 「実は」型は維持・強化
学生・研究者層に予想以上に届いている。**ワンポイント解説の中核フォーマットとして継続**。

### ② 学生層への訴求を意識的に
ペルソナ 18 を意識した投稿（教科書概念の本当の意味、大学レベルの先取り、進路へのヒント）を月に1〜2本入れる。

### ③ 研究者層は「無理に狙わない」
反応してくれるが、訴求軸を学術寄りに振ると **素人層が離脱するリスク**。あくまで素人向け軸で書き、学術層には「結果として届く」関係を保つ。

### ④ ブックマーク数を新KPIに
3010件/28投稿 = 平均107件/投稿。これは「保存される深さ」の指標。
今後は **インプ・エンゲ・リンククリック・ブクマ** の4指標で投稿評価する運用を検討。

## 確認結果

- 28件の「実は」投稿を抽出、531人の反応者を分析
- ペルソナ 18（学生）を追加し、persona/ 配下は 18 人体制に
- 既存ペルソナの妥当性が「実は」型でも確認された

## 今後の課題

- 学生層へのリーチ計測（ペルソナ18 を意識した投稿の反応を別計測）
- ブックマーク数を投稿評価に組み込む（既存集計に追加）
- コンテンツタイプ別分析の他フォーマット展開（ストーリー型・質問回答型）
