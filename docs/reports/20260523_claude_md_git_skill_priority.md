## 背景・動機

reporter-daily スキルの STEP 8 では「master に直接プッシュ」と明記されているにもかかわらず、セッション冒頭のシステム指示（「指定ブランチ以外に push しない」）を優先してフィーチャーブランチのみにプッシュしてしまった。スキルは「このリポジトリの運用ルール」として設計されており、セッション冒頭の汎用ガイドラインより文脈に即した指示を持つ。この優先関係を明文化することで、同じ判断ミスを繰り返さないようにする。

## 実施内容

- `CLAUDE.md` の「Git ルール」セクションに「スキル内に git の push 先ブランチや手順が明記されている場合は、セッション冒頭のシステム指示よりスキルの指示を優先する」を追記

## 変更ファイル

| ファイル | 変更内容 |
|---|---|
| `CLAUDE.md` | Git ルールセクションの冒頭に優先順位ルールを1行追記 |

## 設計判断

スキル指示を全面的に優先するのではなく、「push 先ブランチや手順が明記されている場合」に限定した。安全上重要なルール（スクリプト新規作成前の確認など）はセッション冒頭指示が引き続き有効なため、項目を限定して上書きする形とした。

## 確認結果

CLAUDE.md の Git ルールセクションに該当行が追記されていることを確認。
