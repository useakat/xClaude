## 背景・動機

「物理定数（光速・シュテファン＝ボルツマン定数など）に特化したアカウント」というアイデアが出た。評価は「アカウントの軸としては弱いが、シリーズ（型）としては強い」：定数は尖っていて素粒子博士の土俵だが、読者の母数が小さく、基礎定数は 30 個程度で有限、収益化の実績は執念の物語に集中している。一方で定数の裏には「測った人間の執念」（マイケルソン・キャベンディッシュ・キログラム原器の引退・ペンジアス＆ウィルソン）があり、確定した軸（宇宙探査の執念）と同じ構造で語れる。

よーんの判断は「アカウントは分けない。note 記事の題材になればいい」。そこで、定数ごとに note・X長文・onePoint の 3 展開のフォーカスを持つ専用シートを作ることになった。

## 実施内容

- `postNeta` スプレッドシートに `teisuNeta` シートを新設（newsTopics の次、4 番目）
- 列：No / 定数 / 記号・値 / 分類 / noteフォーカス（執念の物語：主人公／危機／逆転）/ X長文フォーカス（執念・600字）/ onePointフォーカス（「実は、」の一行）/ 宇宙探査との接続 / 出典メモ / ステータス / 追加日
- **24 定数を登録**（「物理定数はある程度広く」との指示で天文定数・派生定数・地球の定数を含む）：光速 c、万有引力定数 G、プランク定数 h、ボルツマン定数 k_B、シュテファン＝ボルツマン定数 σ、微細構造定数 α、電気素量 e、アボガドロ定数、ハッブル定数、宇宙定数 Λ、宇宙背景放射の温度、太陽定数、天文単位、パーセク／光年、チャンドラセカール限界（使用済み）、プランク長・時間、ε₀・μ₀、陽子／電子質量比、重力加速度 g、地球の GM、ウィーンの変位定数、リュードベリ定数、ボーア半径、ファラデー定数
- 各行に、展開が弱いもの（onePoint 向きのみ等）は「弱い」と明記し、ハッブル定数は結末未確定（note は決着後）と注記。「宇宙探査との接続」列で確定した軸に寄せられるようにした
- `/add-neta` の判定順 2 位に teisuNeta を追加（thoughts → teisuNeta → noteNeta → newsTopics → onePointNeta）。条件は「物理定数・天文定数そのものが主題」。定数が出てきても探査機・人物の物語が主なら noteNeta。記入要領と description（5 つのネタシート）も更新

## 設計判断

- **別アカウントにしない**：制作時間が割れる（今の発信は自動化で成立）、読者の母数が小さい、軸を捨てる理由がない。定数は軸の中の切り口として扱う
- **1 定数＝1 行で 3 展開を横に持つ**：noteNeta / onePointNeta に分けて入れると「同じ定数の別展開」が散るため、定数を主キーにした専用シートにした。展開が弱い欄は空にせず「弱い」と書く（後で埋めるべき欄か、埋まらない欄かを区別するため）
- **出典メモは一次資料の手がかり**：パウリの 137 号室、ガモフ経由の「最大の失敗」、ミリカンのデータ選別、ル・ジャンティルの死亡扱いなど伝聞を含む逸話が多いので、制作時に `/check-fact` を必ず通す前提で手がかりだけ残した
