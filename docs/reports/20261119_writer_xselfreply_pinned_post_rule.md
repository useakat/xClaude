## 背景・動機

Threads の「あかり」投稿（赤外線衛星の全天サーベイ）にセルフリプを付けるため `/writer-xselfreply` を使ったところ、v1 のルール4「本編と同一題材のみ。別題材の販促は置かない」に当たり、あかりの note 記事が無いので誘導文が作れなかった。実運用では「同一題材の note 記事が無い本編」の方が多く、そのたびに販促を諦めるとセルフリプ導線そのものが途切れる。よーんの判断で、ルール4を**同一題材を優先し、無い場合に限り別題材可**に緩和した（同一題材 CTR 2.0〜3.3% vs 別題材 0.3〜0.5% の実績は維持し、優先順位として残す）。

さらに、誘導先として選んだあかつき記事（`n14b63771bfe5`）は 2026-11-09 から Threads の固定ポストが誘導している記事だった。同じ記事への入口を固定ポストの外に散らすと、`固定ポスト日次` シートの IMP・クリック集計が割れて導線の計測が崩れる。そこで**誘導先が今の固定ポストと同じ記事なら note リンクを貼らず固定ポストへ送る（プロフ誘導）**ルールにし、プロフ誘導の締めを定型文「プロフィール固定のnoteに書いてます。」に統一した。

なお、この作業の途中で Threads の固定ポストをニューホライズンズと誤認した。原因はローカルに残っていた古い導線 CSV（`logs/note_funnel/pinned.csv`、11/8 時点のエクスポート）を読んだこと。固定ポストの正は「発信記録」シートの `固定ポスト履歴` なので、スキルにはシートを直接読む手順を書き、ローカルコピーは見ないことを明記した（古いフォルダはよーんの指示で削除）。

## 実施内容

- `.claude/skills/writer-xselfreply/SKILL.md`
  - **ルール4**を「本編と同一題材を優先。別題材の販促は同一題材の誘導先が無い場合に限る。別題材のときは予告1文に本編と誘導先をつなぐ具体的な共通点（同じ年・同じ国・同じ失敗など）を1つ入れる」に改定
  - **STEP 2.5「固定ポストとの重複確認」**を新設。`python3 scripts/sheets_values.py get <発信記録 SS> "固定ポスト履歴!A:H"` で終了日が空の行（固定中）を読み、その `記事ID` が誘導先と同じならプロフ誘導にする。理由（計測を固定ポストに集める）と、`logs/note_funnel/` などローカル CSV を見ない注意を記載
  - **ルール6**（プロフ誘導）の締めを定型 **「プロフィール固定のnoteに書いてます。」** に統一。誘導先の記事が固定ポストと同じ場合もこの形にする
  - 版の履歴表の v1 行に、ルール4 緩和の経緯を追記（改定時点の after 記録が 0 件のため版は v1 据え置き）
- `logs/selfreply_records.csv` に あかり投稿のセルフリプ（版 v1・誘導先 `プロフ`）を記録
- `docs/skills/writer-xselfreply.md` を `update_wiki_skills.py` で再生成（commit 時の自動フックが動かなかったため手動実行）

採用文面（Threads・あかり投稿のセルフリプ）：

```
「あかり」の4年後に飛んだ金星探査機「あかつき」。
金星到着に失敗してから、５年後の再挑戦までの話を、プロフィール固定のnoteに書いてます。
```

## 設計判断

- **版を v2 にせず v1 据え置き**にした。版管理の目的は「検証途中のルールを変えて before/after を濁さない」ことだが、改定時点で v1 の after 記録は 0 件で、判定窓はまだ始まっていない。ここで v2 を切ると v1 が空のまま残るだけなので、v1 のルールとして確定させた
- **固定ポストと同じ記事は note リンクを貼らない**のは、計測を一箇所に集めるため。固定ポスト経由のクリックは `固定ポスト日次` で日次計測できるが、個別投稿のリンクに散ると記事ごとの導線が割れる
- 締めを定型文にしたのは、プロフ誘導の文面がぶれると「固定ポストを見に行く」行動の計測が比較できないため
