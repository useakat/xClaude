## 背景・動機

X運用の日次・週次・月次の推移を一目で把握できるダッシュボードが「発信記録」スプレッドシートに存在しなかった。よーんから提示された他アカウントのダッシュボード画像（カードUI＋期間指定＋推移グラフ）を参考に、自アカウントのデータ（日次記録・X投稿一覧）から同等のものを作ることになった。

mcp-gsheets（MCPツール）にはデータ検証（日付ピッカー・ドロップダウンリスト）やグラフの積み上げ設定・系列色指定を行う API が無いため、この2点だけは GAS（clasp）側からスクリプトで設定する必要があった。

## 実施内容

### スプレッドシート側（「発信記録」`1_0317hOqbgGfcSZQ9D9-JlwgqvKxzQuRaw08U-5nw0c`、mcp-gsheets 経由・git管理外）

- 新タブ `Xダッシュボード` を追加
  - 対象期間_Start / End（日付入力）・日数（自動）・データ範囲の自動注記
  - グラフ粒度（日次／週次／月次）
  - カード12枚：インプレッション・エンゲージメント率・プロフィールアクセス・プロフィールアクセス率・フォロー率・オリジナルポスト（ポスト数−引用）・返信（リプ数（他人））・引用RT（引用）・新規フォロワー・フォロー解除・いいね・ブックマーク（いずれも対象期間の合計＋平均/日）
  - 推移グラフ4枚（2×2）：インプレッション／プロフィールアクセス率／フォロー率／新規フォロー・フォロー解除（積み上げ）
- 新タブ `Xダッシュボード_集計`（グラフ用の中間集計タブ・非表示予定）
  - 日次記録の R（インプ）・S（プロフ）・M（新規フォロヷ数）・N（アンフォロワ数）を集計元とする
  - **日次**：対象期間_Start〜End の実データ日をそのまま表示
  - **週次／月次**：対象期間の指定に関わらず、最新データ日（`MAX(日次記録!A:A)`）を含む期間までの**直近12週・12ヶ月を固定表示**
  - 当初 `ARRAYFORMULA(SUMIFS(...))` で行ごとに期間集計しようとしたところ、Google Sheets の仕様上 `SUMIFS` は複数条件の配列化に対応しておらず全行が同じ値になる不具合が発生。`MAP`+`LAMBDA` で1行ずつ確実に計算する方式に修正して解消した

### GAS 側（`gas/XDashboardSetup.js` 新規）

- mcp-gsheets では設定できない以下2点を Apps Script から設定する `setupXDashboardExtras()` を追加
  - `C3:C4` に日付のみのデータ検証、`C6` に「日次／週次／月次」のリスト検証
  - グラフ④（新規フォロー／フォロー解除）を積み上げ縦棒＋系列色指定（青=新規フォロー／赤=フォロー解除）に変更
- 冪等な一回限りのセットアップ関数。`clasp run` は Apps Script API 未設定のため実行不可（`Error code NOT_FOUND`）と判明し、Apps Script エディタからよーんに手動で1回実行してもらう運用とした
- 初回実装ではグラフの積み上げ設定に `EmbeddedChart.modify().setStacked()` を使ったが、`.modify()` が返す `EmbeddedChartBuilder`（汎用型）には `setStacked()` が存在せず `TypeError` が発生。汎用的に使える `.setOption('isStacked', true)` に修正して解消した
- clasp が別アカウント（`kitanagasekids.sys@gmail.com`）でログインしていたため、`useakat@gmail.com` へ再ログインして push・実行検証を行い、global の clasp 認証は元の `kitanagasekids` に復元した（本 GAS プロジェクトは `useakat` 所有のため、以後この GAS を push する際は毎回同様の再ログインが必要）

## 確認結果

- 日次モード：対象期間 9/14〜9/22 のカード合計値が「日次記録」シートの該当期間 SUM と一致することを確認（インプ合計 23,137,826・プロフ合計 9,689・新規フォロワ合計 309 など）
- 週次モード：対象期間を 9/14〜9/22 のままにしても、集計タブが最新データ日（9/24）を含む週までの直近12週（2026/07/06〜2026/09/21）を表示し、期間指定を無視して固定表示されることを確認
- 月次モード：同様に直近12ヶ月（2025/10〜2026/09）を固定表示することを確認
- `setupXDashboardExtras()` をよーんに Apps Script エディタで実行してもらい、以下を確認
  - データ検証：`sheets_get_data_validation` で `C3:C4`=DATE_IS_VALID、`C6`=ONE_OF_LIST（日次/週次/月次）を確認
  - グラフ④の積み上げ・色指定：`TypeError` 修正後の再実行で正常終了（エラーログなし）
