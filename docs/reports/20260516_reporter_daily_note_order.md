## 背景・動機

日報の特記事項は投稿種別ごとに記載するが、順番にルールがなく毎回バラつきが生じていた。週報・月報で日報を参照する際に同じ種別を追いやすくするため、記載順を固定した。

## 実施内容

- STEP 5 に「特記事項の記載順」セクションを新設
- 順番を以下に定義：①Xワンポイント解説投稿 → ②X質問投稿 → ③Xストーリー投稿 → ④note 記事投稿 → ⑤変更ログまとめ → ⑥その他
