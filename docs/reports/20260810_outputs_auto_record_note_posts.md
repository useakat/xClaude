## 背景・動機

note 記事を公開したあと、記録先は2つある。

- **note投稿一覧シート**（SS3）… ビュー・スキ・サムネ等。`/record-note-posts` が毎日 3:00 の cron（`scripts/run_record_note_posts.sh`）で自動更新していた。
- **outputs シート**（SS2）… what_id / neta_id を持つ投稿台帳。マネタイズ月報や `sync-x-note-analytics` の導線集計が参照する。**こちらは手動記録のままだった。**

実際、W002 の記事3本（アポロ12・ボイジャー再点火・ケプラーK2）が outputs に未記録のまま放置されていた。手動記録は忘れられる前提で設計すべきなので、note投稿一覧を更新している `/record-note-posts` に outputs 同期を相乗りさせることにした。

## 実施内容

**`/record-note-posts` に STEP 6（outputs シートへ新規投稿を自動記録）を新設**

- outputs の B列（URL）と `NOTE_DATA` を突き合わせ、未記録の記事を抽出する。note投稿一覧への新規追加の有無にかかわらず全記事を対象にする（note投稿一覧に既存でも outputs に無い記事があり得るため）。
- 追加行は `[公開日時, URL, "W002", neta_id, "", "", "", ""]`。
- **neta_id の解決**: 記事フォルダ直下の `note-record.md`（w002 spec フロー16 で生成する記録ファイル。title / what_id / neta_id / draft_edit_url を持つ）をタイトル完全一致で grep して引く。特定できなければ**空欄にして完了報告に「neta_id 未解決」として列挙**する（推測で埋めない）。
- **F列 `note_url` は空欄固定**。この列は「X投稿がどの note へ誘導したか」を記録する列であり、note 本体行に入れると `sync-x-note-analytics` の導線集計が二重計上する。

**ワークフロー外記事の除外ガード（実データ検証で追加）**

実行してみたところ未記録が **16件** あり、うち **15件が 2026年2月以前のワークフロー外の旧記事**（iPad mini・Replit・RStudio・数学入門など）だった。当初の「outputs に無い note 記事はすべて W002 として追加」という書き方では、`/record-note-posts all` のように過去記事まで取得して実行した瞬間にこれらが W002 として一括投入されてしまう。

そこで次のどちらも満たさない記事は記録せず、完了報告に「ワークフロー外として除外」と列挙するガードを追加した：

- `projects/w002/*/note-record.md` にタイトル一致の記録ファイルがある、**または**
- 公開日時が実行時点から30日以内

## 設計判断

**なぜ note 側に記録ファイル（`note-record.md`）を置いて neta_id を引く方式にしたか**
公開後の note 記事から neta_id を知る手立ては無い（note API はネタ番号を持たない）。cron の無人実行でタイトルから推測させると誤った neta_id が混入し、マネタイズ集計が静かに狂う。制作時点で分かっている情報を記事フォルダに書き残し、**タイトル完全一致という機械的な条件でのみ引く**方式にした。引けない場合は空欄＋報告とし、推測は一切させない。

**なぜ30日ガードを日数で切ったか**
`note-record.md` は今回導入した仕組みなので、既存記事には存在しない。記録ファイルの有無だけを条件にすると、当面はすべての新規記事が「neta_id 未解決」で弾かれる。cron が毎日回る前提なら「30日以内の公開」は実質「この仕組みが動き始めてからの新規公開」と同義になるため、これを併用条件にした。

## 確認結果

- 実データで STEP 6 相当の突き合わせを実行し、未記録16件を検出。うち W002 は1件（ケプラー、2026-08-09公開）、残り15件がワークフロー外の旧記事であることを確認した。
- ケプラー記事を outputs 174行目に記録。続けてバックフィル分2件（175・176行目）も記録し、追加後に再度突き合わせて**残る未記録13件がすべてワークフロー外の旧記事**であることを確認した。
- この検証結果（未記録16件中15件が旧記事）を SKILL.md 内に根拠として明記した。
