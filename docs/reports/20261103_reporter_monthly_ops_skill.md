## 背景・動機

発信運用の振り返りは週次（`/reporter-weekly-ops`、2026-08-16 新設）しかなく、月の単位では数値月報（`/reporter-monthly`）とマネタイズ月報しか無かった。週次は投稿単位の要因分析と翌週のアクションを扱うが、「基準（W001 週 2 本・note 週 1 本・0本日ゼロ）が月に何週守れたか」「同じアクションが何週繰り越されているか」「学びのうち月をまたいで繰り返し出たものはどれか」「仮説・施策が月初から月末でどう動いたか」は週次を 4〜5 本読み直さないと分からなかった。よーんから「月次の発信運用振り返り報告も作成するようにして」と依頼。

よーんの決定：実行は毎月 1 日（当初案の「月末後の最初の日曜 21:00」から変更）／数値集計はスクリプトを新設。

## 実施内容

- **集計スクリプト** `scripts/ops_monthly_metrics.py --month YYYY-MM [--json] [--cache-dir]`：outputs（SS2）× X投稿一覧（SS3）× 日次記録（SS3）を tweet ID で突合し、対象月＋前 2 か月の プロジェクト別（本数・中央値・IQR 外れ値除外平均・最大・倍率中央値・top/worst）、週ごとの遵守（W001 本数と曜日時刻・note・0本日・z01 週中央値・週間インプ）、0本日、月間インプ（日次合計）、フォロワー増減、z01 週中央値の直近 13 週、W001／z01 の分散記録（7/3〜）を JSON で出す。レポートに貼る SVG チャート 4 枚（日次インプ・z01 週中央値・W001 分散・z01 分散）も生成する（Starlight の CSS 変数のみ）。認証は `sheets_values.py` と同じ。実行 4 秒
- **スキル** `.claude/skills/reporter-monthly-ops/SKILL.md`：対象月（既定は前月）→ 集計 → 対象月に重なる週次レポート・前月の月次・数値月報・施策レジストリを Read → ⓪遵守の月間集計（達成週数）→ ①プロジェクト別実績と前月比（3 か月表・チャート）→ ②月で見える伸び沈みの共通点（z01 は観察のみ）→ ③週次アクションの消化率と 2 週以上の繰り越し → ④学びの蒸留（2 回以上出たものだけ）→ ⑤仮説の月次総括（月初→月末）→ ⑥施策の月次総括 → ⑦来月の運用方針（前月方針の消化確認つき）→ 保存・index・commit・push → テキスト版メール。役割分担（weekly-ops／monthly／monetization）と禁止事項（数値の捏造・投稿単位の分析・基準の勝手な変更）を明記
- **初回レポート** `docs/reports/ops-monthly/2026-10.md`（10 月分）：遵守 W001 1/5 週・note 0/5・0本日 1/5、X 20 本（W001 3・z01 17）、0本日 10 日（7 割が月〜水）、アクション消化率 30%、W001 週 2 本は 4 週連続繰り越し、H1 確定・H4 支持（暫定）・H5 終了→H6・H7 廃止、来月方針 5 つ
- **Wiki**：サイドバー「報告書」に「発信運用振り返り（月次）」を追加（`reports/ops-monthly`）。`metadata.yaml`・`docs/scripts/index.md`・`.gitignore`（`/logs/ops_monthly/`）
- **routine**：「発信運用振り返り・月次（reporter-monthly-ops）」`trig_01S4UmtfbfcnWjJh2cNWTtNQ`。毎月 1 日 09:30 JST（cron `30 0 1 * *` UTC）、対象は前月。Default 環境・claude-fable-5・Gmail コネクタ。クラウド差し替え（集計はスクリプト、メールは Gmail コネクタ、push 失敗時は本文を出力）をプロンプトに明記

## 設計判断

- **数値はスクリプト、判断はスキル**：週次は inline python だが、月次は 3 か月分の突合と 4 枚のチャートで量が多く、無人実行で毎月同じ数字を出すためにスクリプトに寄せた。チャートも JSON に入れてスキル側の生成を無くした
- **0本日は X投稿一覧で判定**：outputs に記録されない手動投稿（10/6・10/8）があり、outputs だけだと 0本日が 2 日多くなった。週次の判定とも X投稿一覧の方が一致する。X 本数は outputs（プロジェクト分類あり）と X投稿一覧（全投稿）の両方を出す
- **月次は週次を束ね直す**：投稿 1 本ずつの要因分析はしない（週次の領分）。学びは「2 回以上観察されたもの」だけに絞り、アクションは「2 週以上繰り越されたもの」を構造として書く
- **毎月 1 日実行**：月末を含む週の週次レポートがまだ無い月があるが、よーんの判断で月報（1 日 09:00）に揃えた。その週は「週次レポートなし」として扱い、数値は集計スクリプトから取る
- **基準の見直しは「提案」止まり**：⑦で基準を変えたくなっても書くだけで、決定はよーん
