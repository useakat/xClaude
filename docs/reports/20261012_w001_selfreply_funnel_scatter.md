## 背景・動機

W001（執念の物語の X 長文）は本体ポストの下にセルフリプで note リンクを付ける。どの投稿が note に人を送れたかを一枚で見たい、というよーんの要望。最初の指示は「親投稿の IMP（縦）× リンククリック率（クリック ÷ 親投稿 IMP、横）」だった。

作ってみると、IMP が大きい投稿ほど率が下がる（1 万 IMP 未満は 0.7〜1%、数十万 IMP は 0.1% 未満）。拡散が広がると宇宙に関心の薄い層に届き、率が薄まる。よーんから「分母をエンゲージメント数にすれば能動的に見た人が母数になるのでは」との案が出たので数字で確かめ、最終的に分母はセルフリプ IMP、縦軸は地力で補正した倍率に落ち着いた。

## 実施内容

- `scripts/note_funnel_export.py`（`funnel_posts.csv`）
  - 列「型」を追加。outputs シート（SS2）の what_id を本体ポストの tweet ID で引く（W001 / z01 / W003 など）
  - 列「地力IMP」を追加。その投稿の直前 14 日に投稿した非 W001 の親ポスト（親ポストURL が空の行）の IMP 中央値
  - X集計（X アナリティクスのリンククリック）の投稿でセルが空のものは、クリックを 0 ではなく空にする（未取込と 0 を区別）
  - `get()` / `get_optional()` にスプレッドシート ID の引数を追加（SS2 を読むため）
- ダッシュボードページ（`files/index.html`、v15 → v19）
  - 「投稿ごとのファネル（累計）」の下に散布図「W001：セルフリプ IMP（地力比）× CTR」。縦軸 ＝ セルフリプ IMP ÷ 地力IMP（倍、対数）、横軸 ＝ CTR ＝ クリック ÷ セルフリプ IMP。対象は 型 ＝ W001・リンク位置 ＝ セルフリプ・クリックが空でない X 投稿
  - 点の色はクリック数で 4 段階（0〜99 水色、100〜499 緑、500〜999 黄色、1,000〜 ピンク）。ラベルは投稿日。吹き出しに本文冒頭・記事・本体 IMP・セルフリプ IMP・クリック・リンククリック率・CTR・到達率・地力と倍率
  - 未取込・地力なしの件数を図の右上に表示
  - 途中で作った「本体 IMP × リンククリック率」の図はよーんの指示で削除
  - 「数字の定義」に図の意味と分母の選び方を追記
- `datasets/funnel_posts` の description を更新

## 設計判断

- **エンゲージメント数を分母にしない**：W001 20 投稿でエンゲージメント ÷ IMP は IMP が 1 千でも 88 万でもほぼ 5〜8% で一定だった。いいねや詳細表示は流し見の人もするので IMP に比例して増えるだけで、クリック ÷ エンゲージメントも IMP が大きいほど下がる（IMP の対数との相関 −0.59 → −0.50、ほぼ改善なし）
- **詳細表示（さらに表示）も不採用**：小さい投稿でクリック ÷ 詳細表示が 100% を超える。セルフリプは本文を開かなくてもスレッドで目に入る
- **分母はセルフリプ IMP**：「リンクが目に入った人のうち押した割合」で定義が一番素直。相関は −0.38、変動係数 0.65 と最も安定する。縦軸をセルフリプ IMP にすると「入口まで運んだ人数 × 入口で押させた割合」が一枚で読める
- **縦軸は地力で補正**：セルフリプ IMP はその時のアカウントの拡散力にも依る。直前の非 W001 投稿の IMP で割る。平均は 1 本のバズで桁が飛ぶ（9/21 の直前 7 日は円周率ポストで平均 232 万、中央値 2,833）ので中央値、7 日では夏場の本数が 5〜6 本しかないので 14 日。地力は期間を通じて 600〜3,700 の範囲で、3 月の巨大な値は投稿自体が跳ねた分。補正が効くのは 5〜7 月（5/15 は生の値だと中堅に見えるが地力が高い時期で 1.5 倍止まり）
- **未取込と 0 を区別**：6/13 の投稿は X アナリティクスが未取込（セルが空）なのに 0 クリックとして出ていた。空にして散布図から外す

## 確認結果

- W001 でセルフリプにリンクのある投稿は 21 件、うち未取込 1 件を除く 20 点
- 倍率の上位：3/11 火星 122 倍（CTR 0.30%）、3/27 冥王星 64 倍（1.24%）、7/3 ボイジャー 14 倍（3.30%、1,215 クリックで唯一のピンク）、8/15 90日の命 7.7 倍、5/15 ひてん 1.5 倍。8〜9 月の多くは 0.5〜1.3 倍
- routine を手動実行し、funnel_posts の差し替えが成功（v13、CSV に 型・地力IMP 列を確認）
