## 概要

`@russianblue2009` の過去30日（2026-05-01〜2026-05-30）の投稿814件を対象に、冒頭1文のパターンを帰納的に発見・命名・分類し、インプレッション平均を算出。

## 代表ツイート（各パターン上位2件）

### #1 ドラマ・場面描写型（平均 1,128,566）

場所・人物・動作を物語的に描写して冒頭に置く。情景が先に来て、ニュースの「種明かし」が後に続く構造。

**① IMP 4,438,848**
```
早朝の金山駅。出勤途中の警察官が、通り過ぎた男の顔を見て直感した。「あの顔、もしかして……」
```
> 場所+時間+職業+直感という最小限の情報で読者を引き込む。「もしかして」の省略が好奇心を最大化。

**② IMP 66,110**
```
先輩にこう教わりました。
```
> 極限まで短い物語起点。誰から何を、という情報をゼロにすることで「続きを読まなければ」感を作る。

---

### #2 社会変化・危機提起型（平均 940,713）

「〜が静かに臨界点を超えようとしています」「〜が次々と消えています」という進行形で、構造的変化の到来を告げる。

**① IMP 3,282,739**
```
日本のコメを誰が作るのか、という問題が静かに臨界点を超えようとしています。
```
> 「静かに」「臨界点」という語が危機の静けさと深刻さを同時に表現する。

**② IMP 327,850**
```
中国軍のトップが次々と消えています。
```
> 「次々と」「消えています」の組み合わせが不気味さと緊迫感を短文で演出。

---

### #3 知識提示型（平均 734,995）

「あなたが毎日使っている〜」「〜は自動では切れません」のように、多くの人が知らない事実を宣言する。

**① IMP 2,958,879**
```
あなたが毎日使っている「1秒」の定義が、63年ぶりに書き換えられます。
```
> 「あなたが毎日使っている」で親近感を作り、「63年ぶり」でスケールを示す。

**② IMP 2,566,263**
```
配偶者が亡くなっても、義父母との「親族関係」は自動では切れません。
```
> 知らないと損をする生活情報。「自動では」という限定が意外性の核心。

---

### #4 逆説・常識覆し型（平均 295,159）

「〜という常識が覆された」「〜だと思っていたが、実は〜」という構造。引用符で「旧常識」を括り、続きで裏切る。

**① IMP 5,701,073**
```
膝の半月板が傷んだら、今まで「切り取るしかない」が医療の常識でした。
```
> 「でした（過去形）」が「もう違う」を暗示。続きへの引力が最大。

**② IMP 1,839,859**
```
「表面は滑らかなほど空気抵抗は減る」。
```
> 引用符で旧常識を提示し、句点で止める。「これが覆る」という予告だけで読者を引き込む最短形。

---

### #5 速報型（短文）（平均 115,078）

60字以内の事実宣言。バズトピックと重なると急伸する。「今日」「本日」を使って即時性を強調する形が多い。

**① IMP 2,254,563**
```
ソフトバンクグループが本日、2026年3月期の決算を発表しました。
```

**② IMP 1,062,149**
```
トヨタが今日、面白いものを発表しました。
```
> 「面白いもの」という曖昧表現が強力な誘導フックになっている。

---

### #6 問いかけ型（平均 34,189）

「〜したことはありますか？」「〜ご存知でしょうか？」。読者に答えを考えさせてから本題に入る。

**① IMP 334,558**
```
神社に馬がいる理由、考えたことはありますか。
```

**② IMP 53,673**
```
ANCA関連血管炎という難病をご存知でしょうか。
```

## 冒頭フック 表現テンプレート集（応用可能形）

高IMP4パターンを構文レベルに分解。`〇〇`＝主題、`△△`＝対比要素。writer 系スキルが冒頭フックを書く際の参照素材。

### ① 逆説・常識覆し型（最安定・量産可 / avg 295k）

**旧常識を「」で括って提示 → 否定・裏切りで返す。**

| 構文テンプレート | 実例 |
|---|---|
| 「〇〇」——その常識が、〜覆された | 「Macはウイルスに強い」——その常識が、今週完全に覆されました |
| 「〇〇」が、〜書き換えられようとしています | 「哺乳類は四肢を再生できない」——その常識が、静かに書き換えられようとしています |
| 〇〇は「△△」だとずっと教わってきました。ところが〜 | 心臓病は「血管の詰まり」だとずっと教わってきました。ところが〜 |
| 「△△」が通じない〇〇があります | 「甘いものは血糖値を上げる」——その常識が通じない果物があります |
| 〇〇は、単なる△△ではありません | 米国バーボン業界の在庫問題は、単なる売れ残りではありません |
| 〇〇が△△なのは「□□」からではありません。〜からです | ハチミツが赤ちゃんに危険なのは、菌を「殺せない」からではありません。「増える」からです |
| 〇〇って、実は△△だった | 自転車の変速って、実は「使われていない機能」の代表格だった |
| 「〇〇」。（引用符＋句点で止め、予告だけ） | 「表面は滑らかなほど空気抵抗は減る」。 |

物理応用例：「『光より速いものはない』——その常識は、ある条件下で崩れます。」

### ② 知識提示型（avg 735k）

**「あなた」を主語に、知らない事実を断定で突きつける。**

| 構文テンプレート | 実例 |
|---|---|
| あなたが毎日使っている「〇〇」が、〜 | あなたが毎日使っている「1秒」の定義が、63年ぶりに書き換えられます |
| あなたの〇〇には、いま△△が起きています | あなたの細胞の表面には、いま「砂糖の膜」が張り巡らされています |
| あなたの〇〇は、何もしなくても△△ | あなたの自宅Wi-Fiルーターは、何もしなくてもAppleのDBに登録されています |
| 〇〇しても、△△は□□しません | 配偶者が亡くなっても、義父母との「親族関係」は自動では切れません |
| 〇〇だということを、多くの人は知りません | 冷凍倉庫の中がマイナス25度だということを、多くの人は知りません |
| 日本人の〇人に1人が、△△だと認識しています | 日本人の約4人に1人が、刺身の短冊は海で泳いでいると認識しています |

物理応用例：「あなたが今見ている星の光は、もう存在しない星のものかもしれません。」

### ③ ドラマ・場面描写型（avg 1.1M ※少数）

**場所・時間・人物・動作だけ提示し、結末を伏せる。小説の一行目。**

| 構文テンプレート | 実例 |
|---|---|
| 〔時間〕の〔場所〕。〔人物〕が〔動作〕した。「〜」 | 早朝の金山駅。出勤途中の警察官が、男の顔を見て直感した。「あの顔、もしかして……」 |
| 〔人物〕が、〔状況〕した。（主語を絞り事実だけ） | 弁護士が、勾留中の依頼人に頼まれて自宅を訪問した |
| 〔数字〕、〔状態〕。（年齢・年数で人生を圧縮） | 53歳、日本を離れて25年 |
| 〔誰か〕にこう教わりました。（情報をゼロにして引く） | 先輩にこう教わりました |

固有名詞・結論は冒頭で出さない。物理応用例：「1986年1月28日、フロリダ。技術者の一人だけが、打ち上げに反対していた。」

### ④ 問いかけ型（avg 34k）

**身近な対象＋「考えたことはありますか／ご存知ですか」で手を止めさせる。**

| 構文テンプレート | 実例 |
|---|---|
| 〇〇の理由、考えたことはありますか | 神社に馬がいる理由、考えたことはありますか |
| 〇〇を見たことはありませんか | 通路に黒い縄で縛られた小石が置いてあるのを見たことはありませんか |
| 〇〇をご存知ですか／でしょうか | ラスベガスの「スフィア」をご存知ですか |
| あなたは今日、〇〇していませんか | あなたは今日、右手でスマホを持っていませんか |
| なぜ〇〇なのに、△△なのでしょうか | 受信料が落ちているのに、なぜNHKは督促を10倍に増やしたのでしょうか |
| 〔逆説的事実〕。この〇〇、考えたことはありますか | 雪は白いのに、古い氷は青い。この逆説、考えたことはありますか |

物理応用例：「夜空が暗い理由、考えたことはありますか。」

### 横断技法

①〜④すべてに共通して効く2要素：
- **引用符「」で意外な一語を強調**する
- **数字で一気にスケールを提示**する（「63年ぶり」「4人に1人」）

①と④は組み合わせ可（逆説的事実→問いかけ）で最も汎用性が高い。
