## 背景・動機

同日新設した `reporter-monetization` を 2026-07 で試作したところ、よーんのレビューで4つの実データ上の問題が判明した。数値が実態を誤って見せる／導線が測れていない状態を、試作しながら順に修正した。

- threads の型が全「(元投稿不明)」になっていた
- IMP平均が1本のバズに引っ張られ実態を過大表示（外れ値未処理）
- 3ヶ月推移が平均のみで本数の増減が見えない
- note 導線の CTR/CVR が 0 のままで「どの投稿が売ったか」を数値で追えていなかった

## 実施内容

- **threads 型解決を outputs 経由に変更**（①）：判定を Threads投稿一覧 H列（元X投稿URL＝全行空だった）から、**outputs の threads行（permalink→x_url→what_id）** に切り替え。2026-07 は 0本→26本が型解決。
- **IMP合計・中央値の追加**（②③）：型別成績に IMP合計・**中央値**を追加し、平均は外れ値に弱いため中央値を主軸に。3ヶ月推移も IMP平均→**IMP合計（＋本数）**表示に変更。長文ストーリーは平均78,375でも中央値5,080＝1本のバズ依存が可視化。
- **導線をセルフリプ click 基準に**（③a）：note リンクは本体でなくセルフリプ側にあるため、**親ポストURLで紐付けたセルフリプ行のリンククリック合計**を導線クリックに使うよう変更。CTR＝セルフリプclick÷本体IMP。
- **7月Xアナリティクスの取込**：別フォルダ（`1HlkV8...`）にあった `account_analytics_content_2026-07-01_2026-07-31.csv` を取得し、X投稿一覧の 詳細表示/リンククリック/フォロー増（AA:AC）を **38行更新**。
- **ボイジャー本体の note_url バックフィル**：最も売れた 7/3 ボイジャー再点火は本体投稿の note_url が 7/24 の自動記録導入前で空だったため、outputs.F に note記事URL（`n4ce6fbbf837f`）を手動記入。
- 上記により 2026-07 レポートの導線を実数化：**長文ストーリー 本体IMP233,330→クリック1,252（CTR0.54%）→購入6・売上2,940円（CVR0.48%）**。

## 確認結果

- `--dry-run` で threads 型解決（26本）、IMP合計3ヶ月推移、中央値を確認。
- CSV取込後、ボイジャーのセルフリプ＝URLクリック 1,215 を確認。
- note_url バックフィル後、導線表が 長文ストーリー CTR0.54%・CVR0.48%・売上2,940円 で実数化。
- note売上 3,430円は据え置き（note購入記録の実勢合計と一致）。

## 設計判断・今後の課題

- **数値は中央値で語る**：平均は少数のバズに歪められるため、型別成績は中央値を主軸にした。
- **導線は親ポスト紐付けのセルフリプclick**：note リンクの実クリックはセルフリプ行にしか出ないため、本体ポストではなく親子紐付けで拾う。
- **運用の要点**：①W001本体は必ず `[note_url]` タグ付きで下書き（7/25以降は自動記録が稼働）②毎月Xアナリティクスの月次CSVを Drive にアップして update-x-analytics で取込む——この2つが揃えば、売れた導線が毎月自動で型別に出る。
- 下書き転載の threads（元X投稿がoutputs未記録）は依然「(元投稿不明)」になる。手動投稿・引用RT・セルフリプも型を持たないため型別成績から抜ける（記録運用の課題）。
