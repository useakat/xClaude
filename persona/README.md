## 構成

- **01-10**: `plan.md` の理想読者像を細分化した「理想ペルソナ」
- **11-14**: 過去3ヶ月の実リプ送信者（10回以上）をベースにした「実在系ペルソナ」
- **15-17**: 直近3ヶ月の新規フォロワー3000人 bio 分析から派生した「フォロワー実態ペルソナ」
- **04・07**: 理想ペルソナ＋実在系を統合した「ハイブリッドペルソナ」（複数スタイル層を1つに含む）

## 共通項目（各ファイルの構成）

理想ペルソナ：
- 基本／趣味／悩み／日常で扱うもの／期待／SNS閲覧シーン／目的／刺さるキーワード／避ける表現／想定反応／響く投稿角度

実在系ペルソナ：
- ベースアカウント／bio／基本像／過去3ヶ月の累積リプ特徴／人物像／関心領域／文体・温度感／配慮ポイント／代表リプ／投稿側として響かせる角度

ハイブリッド（04・07）：
- 統合元の明示／共通基本／共通刺さりポイント／応答スタイル別の記述／投稿角度／代表リプ
