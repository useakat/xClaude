## 世界初の賭けが、2分半で壊れた

1. 図解画像 — 2010年12月7日の時系列図。上段に「8時49分 噴射開始 → 1分43秒後 金星の裏側へ（電波が途切れる）→ 9時12分 戻る予定（電波は来ない）→ 10時28分 76分遅れで電波（非常用アンテナ）」を横一列の時間軸で示す。下段に噴射の実績バー：予定12分に対して2分30秒で停止、周回軌道に必要だった最低9分20秒のラインを重ねる。計画どおりの区間は青、止まった箇所と空白の76分は赤。ラベルは本文の言葉と数値をそのまま使う。
2. イメージ画像 — 金星の裏側へ消えていく瞬間の「あかつき」。手前に巨大な金星の縁（昼と夜の境目）、その影に溶けこもうとする小さな探査機。噴射の青白い炎がまだ点いている。静かで、これから何が起きるか分からない空気。文字なし。
3. 写真画像（Web取得） — 「あかつき」のメインエンジン（セラミックスラスタ）または実機の写真。世界で初めて燃焼室をセラミックスで作ったエンジンの実物。検索語句：「あかつき セラミックスラスタ ISAS」「Akatsuki OME ceramic thruster JAXA」。ISAS/JAXA のページから取得し、クレジット「ISAS/JAXA」を付ける。

## 近づくことと、捕まることは違う

1. 図解画像 — 「近づく」と「捕まる」の対比図。左：ブレーキをかけずに金星のそばを通り過ぎる探査機（通過＝そのまま遠ざかる）。右：小さなエンジンで減速して捕まるが、速度を落としきれず、金星から最も遠い点で約37万キロの細長い楕円を描く。右の楕円に、当初計画の8万キロの小さな楕円を重ねて4倍以上の差を見せる。参考スケールとして「地球から月までの距離とほぼ同じ」を添える。ラベルは本文の言葉。
2. 図解画像 — 漂流軌道の熱の図。太陽を中心に、金星の軌道（225日で一周）と、それより内側に入り込む「あかつき」の漂流軌道（203日で一周）を描く。太陽に最も近づく点で「地球のあたりの3倍の熱」、横に「設計寿命 4年半／2017年まで待てば7年半」を添える。熱・危機を赤、軌道を青で区別する。
3. イメージ画像 — 太陽に焼かれながら漂う探査機。画面の片側に白熱する巨大な太陽、遠景に小さく金星、そのあいだに小さな「あかつき」が漂っている。過酷で静かな空間。派手な演出はしない。文字なし。

## 何万通りの近づき方

1. 図解画像 — 太陽の引っぱりの差で軌道がずれる仕組みの図。金星をまわる細長い楕円軌道（最も遠い点37万キロ）を中央に置き、画面外の太陽の方向から矢印を引いて、金星と探査機を「別々の強さ、別々の向き」で引いている様子を示す。金星に最も近づく点の高度が「下がる向き」と「上がる向き」の2つの矢印を対比し、「どちらが勝つかは近づき方しだい」を示す。危機（下がる→大気に突っ込む）を赤、安定を青。
2. 図解画像 — 外側から追いつかれて投入する仕組みの図。太陽をまわる金星の軌道の外側に「あかつき」を置き、「外側＝ゆっくり進む」ので金星が後ろから追いつく → 金星がすぐ内側を追い抜く → その瞬間に逆噴射 → 金星の重力に引かれて背後へ滑り込む → 大気と同じ向きで周る軌道に乗る、を時系列の矢印で描く。「12月1日頃 100万キロ前方を横切る」「12月7日 金星が追いつく」の2時点を添える。
3. イメージ画像 — 深夜の運用室。モニターに無数の軌道の線が重なった図が映り、その前に座る軌道設計者の後ろ姿（顔は描かない・特定の人物に似せない）。机の上には書きとめたメモの束。静かな集中と、終わりの見えない計算の時間。文字なし。

## 塩の結晶と、20分間の賭け

1. 図解画像 — エンジンが壊れた仕組みの因果図。「酸化剤タンク → 弁のシールをにじみ出る → 配管を伝う → 燃料側の弁で燃料と反応 → 白い結晶（硝酸アンモニウム）が弁をふさぐ → 燃料の出が細くなる → 燃焼の温度が上がる → セラミックスの限界を超えて噴射口が壊れる」を左→右の矢印でつなぐ。結晶と温度上昇を赤、正常な流れを青。ラベルは本文の言葉をそのまま使う。
2. 図解画像 — 「満点を狙わない」設計の図。数直線上に「計画どおりの軌道＝秒速202メートル」と「狙い＝秒速198メートル」を置き、エンジンのぶれ（約5パーセント）の帯を重ねる。202を狙うと3パーセント強く噴いただけで外れる範囲に入ること、198なら強くても弱くても金星に捕まる範囲に収まることを対比する。下に「噴射時間 1228秒＝20分28秒」を添える。
3. イメージ画像 — 2011年10月、酸化剤65キロを宇宙空間へ捨てる場面。暗い宇宙を背景に、「あかつき」の機体から白い霧状の酸化剤が噴き出し、太陽光を受けて光りながら散っていく。メインエンジンを使う道を自分たちの手で断った、静かで決定的な瞬間。文字なし。

## 五年後、同じ日に

1. 図解画像 — 2015年12月7日、8時51分からの20分28秒の時間軸図。「1分 → 2分30秒（五年前はここで止まった：赤いマーカー）→ 5分 → 10分 → 20分28秒 計画どおり停止」を一本の青いバーで描き、2分30秒の地点だけ赤で五年前の停止点を重ねる。右端に「減速量 秒速198メートル、狙いどおり」、脇に「地球に届くまで8分半遅れ」を添える。
2. イメージ画像 — 金星の至近で、4基の小さなエンジンを噴きながら減速する「あかつき」。画面いっぱいに広がる金星の雲の縁と、その手前の小さな機体、4つの小さな炎。地上からは何もできない20分間の、静かな緊張。文字なし。
3. 写真画像（Web取得） — 2015年12月7日、金星軌道投入当日の相模原の管制室の写真。モニターを見守るチームの姿。検索語句：「あかつき 金星周回軌道投入 管制室 2015年12月7日」「Akatsuki VOI-R1 control room ISAS 2015」。ISAS/JAXA のページから取得し、クレジットを付ける。

## 静かな執念が遺したもの

1. 写真画像（Web取得） — 「あかつき」が撮影した金星の画像。南北1万キロにおよぶ弓の形をした大気の模様（中間赤外カメラ LIR の画像）、または紫外線カメラがとらえた雲の模様。検索語句：「あかつき 金星 弓状構造 LIR 2015年12月7日」「Akatsuki Venus bow-shaped structure LIR」。ISAS/JAXA のページから取得し、クレジット「ISAS/JAXA」を付ける。
2. 図解画像 — 「あかつき」の14年の時間軸図。「2010年5月 打上げ → 2010年12月 投入失敗 → 2015年12月 再投入成功 → 8年以上の観測 → 2024年4月 通信途絶 → 2025年9月 運用終了」を横一列に並べ、その下に「設計寿命 4年半」の短いバーと「実際に働いた 14年近く」の長いバーを重ねて対比する。失敗を赤、成功と観測を青。
3. イメージ画像 — 役目を終えて金星の軌道上を静かにまわる「あかつき」。金星の厚い雲の上を、斜めから差す太陽の光に照らされて飛ぶ機体。余韻と静けさ。派手な演出なし。文字なし。
