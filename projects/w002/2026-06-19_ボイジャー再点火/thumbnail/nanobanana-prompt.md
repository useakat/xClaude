# 役割

# 何のサムネイルか
NASA のボイジャー1号という科学ノンフィクション記事のサムネイル。弱った姿勢制御スラスタの代わりに、37年間も眠っていた予備のスラスタを再点火して探査機を延命させた「執念の物語」。古く単純な設計だったからこそ、人の手で立て直せた、という逆説がテーマ。

# 媒体・サイズ
note の横長サムネイル。アスペクト比 1.91:1（1280×672px 相当）。

# 誰に見せるか
科学に憧れつつ数式で挫折した経験のある30〜40代の社会人。専門家ではないが、知的で静かなドラマを好む層。

# 起こしてほしい行動
スクロールする指を止めさせ、「続きを読みたい」とクリックさせる（有料記事の購入につなげる）。煽らず、静かな高揚感で引く。

# 被写体（メインビジュアル）
漆黒の星間空間。満天の星と、淡くにじむ天の川を背景に、年季の入った宇宙探査機ボイジャー1号が浮かんでいる。大きな白い円盤型の高利得アンテナ、金色がかった本体、長く伸びる細いブーム（アンテナ／磁力計）をもつ、1970年代のリアルな探査機。機体は中央〜やや右に大きく、重厚でリアルに描く。機体の小さなスラスタの一つから、青白い小さな噴射の光がひと噴き上がっている（37年ぶりに目を覚ました再点火の一瞬。派手な炎ではなく、静かで小さな光）。画面の遠く（右奥など）に、ごく小さく淡い太陽が一つの明るい星のように光り、暖かいオレンジのアクセントになっている。全体は冷たく静かな深宇宙のトーン。

# レイアウト
- 上部〜左：タイトル（メイン＋サブ）。上部と左側に文字を載せる余白を確保。
- 右上：メタ情報「Voyager 1 / 2017」。

- 視線誘導：タイトル → 探査機×噴射の光 → 遠くの太陽。

# 配色
- 背景（メイン）：深宇宙の濃紺〜黒。星空と淡い天の川。静かで張り詰めた冷たいトーン。

- 文字：白の極太＋黒のフチ取り。強調キーワード「37年ぶり」のみ黄色。色は詰め込みすぎない。

# 文字表現の要件
太いゴシック体（Noto Sans JP Black 相当）。日本語の長体・平体は禁止。3秒で読める可読性を最優先し、フチ取り・余白で背景から抜く。文字化け・崩れは不可。

# 禁止事項
