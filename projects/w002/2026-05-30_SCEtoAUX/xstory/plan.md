# plan.md — W001 執念の物語 X長文ポスト（SCEtoAUX）

## Goal
- **第一目的**: note 記事（W002「SCEをAUXに」アポロ12号の話）への流入を増やし、記事購入につなげる。
- 本編ポストで「最後まで読みたい」「もっと知りたい」を作り、セルフリプの note 導線でクリックさせる。
- 副次: フォロー・スキ・RT を本文の質で取りに行く（明示的 CTA はしない）。
- 共通の発信目的は `../../../plan.md` を継承。

## Target
- W001 の persona は **PE01・PE05・PE09・PE10**（pain は PR001「失敗・制約の中で諦めそうになる気持ち」severity 4）。
  - **PE01** 物理に憧れがあるが数式で挫折した文系会社員
  - **PE05** 文系就職した元理系学生
  - **PE09** 物理で挫折経験のある医療職
  - **PE10** 科学を経営の比喩に持ち込みたい起業家
- 共通項: 科学への憧れと挫折経験／理想の自分と現実のギャップへの後ろめたさ。
- 接触: タイムラインを流し見する中で、冒頭2行で足を止めさせる必要がある。
- 状態: じっくり読む時間はないが、引きが強ければ長文も最後まで読む層。

## Value
- 「困難 → 工夫 → 逆転」の実話を、X 内で完結する1本の物語として体験させる。
- 24歳の管制官が雷に撃たれたアポロ12号を救った実話で、「諦めなくていい」「自分の理想を追っていい」という肯定感を渡す。
- 本編は単体で満足できる完成度にしつつ、note 記事には「ここに収まらなかった裏側」があると感じさせ、続きを取りに行かせる。

## Funnel（このプロジェクトの導線設計）
- **本編ポスト**（約600字・X内で完結）→ **セルフリプで note 導線**（`全部 note に書いた → [URL]`）。
- 本編に note 誘導や「続きはnoteで」を入れない。中断型にせず、リプで分離する2段構造にする。

## CTA（取ってほしい行動）
- note 記事のリンククリック → 記事購入（最優先）
- フォロー・スキ・RT（本文の質で取りに行く）

## Success Criteria
- 本編の IMP：10万インプ
- noteリンクCTR > 0.26%
- note 記事購入

## Risks（失敗要因）
- 冒頭2行で足を止められず、流し見でスルーされる。
- 本編で全部語りきってしまい、note を読む動機が残らない。
- 逆に本編が不完全で「未完の中断」に見え、リプを押す前に離脱する。
- 教訓・説教を前半に挿入して物語のドライブが鈍る。
- 史実・出典のない描写で信頼を損なう（note 記事 `../draft/draft.md` の事実と矛盾させない）。
