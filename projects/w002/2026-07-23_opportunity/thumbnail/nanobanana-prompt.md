# 役割
note の有料記事サムネイル（横長 1枚）を生成してください。実話の重みを感じる、映画のワンシーンのようなリアルな写真/CG 調で。

# 何のサムネイルか
火星探査車オポチュニティの科学ノンフィクション記事のサムネイル。設計寿命90日と言われた探査車が、火星の砂と風に翻弄されながら15年走り続けた「執念の物語」。

# 媒体・サイズ
note の横長サムネイル。アスペクト比 1.91:1（1280×672px 相当）。

# 誰に見せるか
科学に憧れつつ数式で挫折した経験のある30〜40代の社会人。専門家ではないが、知的で静かなドラマを好む層。

# 起こしてほしい行動
スクロールする指を止めさせ、「続きを読みたい」とクリックさせる（有料記事の購入につなげる）。煽らず、静かな高揚感で引く。

# 被写体（メインビジュアル）
火星の砂の大地に立つ6輪の太陽電池式探査車オポチュニティ。
**カメラは砂の上、デッキ（太陽電池パネルの面）よりわずかに低い高さから、機体をやや斜め前から見るローアングル。地平線は画面内に残し、機体が地面に立っていることが分かる高さにとどめる。太陽は機体の後方に低くあり、逆光ぎみに輪郭を光らせ、空気には砂塵がかすむ。** 機体が画面幅の8割を占めるほど大きく迫り、手前の車輪と車体下部が近く、奥の太陽電池パネルとカメラマストが空を背に高くそびえる。
夕方近い低い斜光が機体の輪郭を金色に縁取り、足元には細かい砂塵がうっすら舞い、機体の下に濃い影が落ちる。太陽電池パネルは左右にほぼ水平に広がっているが、実機どおり車体のデッキに沿って畳まれた低い形で、上へ反り返らせない。左右の広がり方は対称にする。見上げるアングルのため、その裏面がわずかに見えている。
**重要: 太陽電池セル（濃紺の格子模様）はパネルの上面にだけあり、裏面にはセルがない。裏面は無地の構造材（淡い金色〜ベージュのハニカム板）として描く。裏側に濃紺の太陽電池を描いてはいけない。**
**本体（電子機器箱）は金色の断熱材で覆われており、その金色がはっきり分かるように描く。**
機体の足元から、走ってきた車輪の轍が画面奥（左）へ細く伸びていく。
**接地は最優先の条件**: 6つの車輪すべてが火星の地面にしっかり接地していること。各車輪の下に接地影が落ち、砂に沈み込む接触点が見えること。機体が宙に浮いている、傾いて一部の車輪だけが接地している、地面から離れている描写は不可。**迫力よりも接地の自然さを優先する。**
破損・擬人化・表情は描かない。
機体の形と色は添付の参照画像に従う（車輪は6輪、太陽電池パネルは車体デッキに沿って左右対称にほぼ水平に広がる。上面は濃紺〜黒に近い青のセル、裏面は無地の構造材で淡い金色〜ベージュ。本体は金色の断熱材、カメラマスト・ロボットアーム・車輪は白〜シルバーの金属）。

# 画面内に入れる文字（正確に、崩さず日本語で描く）
文字サイズは 1280×672px の画像を基準に、以下のピクセル値で描くこと（比率を必ず守る）。

- メインタイトル: 「90日の命と言われた探査車」

  - 「**90日**」のみ = **86px**（通常の約1.2倍＝一回りだけ大きい）で黄色。**2倍のような極端な差はつけない**
- サブタイトル: 「火星の砂と生きた、15年の物語」
  - 通常の文字 = **44px**（メインタイトルの約6割。小さくしすぎない）、白
  - 「**15年**」のみ = **53px**（通常の約1.2倍＝一回りだけ大きい）で黄色
- 右上のメタ情報: 「Opportunity / 2004-2018」= **28px**、控えめな白文字

# レイアウト
- 上部左：メインタイトル、その下にサブタイトル。空の面積を広く取り、文字を載せる余白を確保する。
- 右上：メタ情報「Opportunity / 2004-2018」。
- 中央〜右：主役の探査車（煽りで大きく）。
- 下部左：足元から奥へ伸びる車輪の轍。
- 視線誘導：左上のタイトル → 中央〜右の機体 → 足元の轍 → 地平線。

# 配色
- 背景（メイン）：赤褐色〜くすんだオレンジブラウンの火星の空と大地。低彩度で落ち着いたトーン。地平線近くは砂塵で薄くかすむ。
- アクセント：斜光による機体輪郭のあたたかい金色 × 太陽電池パネルの濃紺（画面内で唯一の寒色）。
- 文字：白の極太＋濃い色のフチ取り。強調は「90日」「15年」の2語のみ黄色＋約1.2倍（一回りだけ大きく）。それ以外の語には色を付けず、サイズも変えない。文字サイズは上記のピクセル指定に従う。

# 文字表現の要件（厳守）
**文字は必ず太いゴシック体（Noto Sans JP Black 相当）で描くこと。明朝体・セリフ体・筆文字・手書き風・細いウェイトは禁止。**日本語の長体・平体は禁止。3秒で読める可読性を最優先し、フチ取り・余白で背景から抜く。文字化け・崩れは不可。最小の文字（右上のメタ情報）でも画像幅の2.19%以上（1280px 幅なら28px以上）の大きさにする。

# 禁止事項
CTA（「今すぐ読む」等のボタン/誘導文）を入れない。絵文字・ハッシュタグ・ロゴを入れない。人物・キャラクター・白一色の人型を入れない。過剰なサイバー感、安っぽい量産イラスト/AI 感、読めない小さな文字、煽り文句を入れない。爆発・光条・レンズフレア・過剰なコントラストで騒がしくしない。
