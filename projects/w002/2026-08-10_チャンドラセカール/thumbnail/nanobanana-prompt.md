# 何のサムネイルか
天体物理学者スブラマニアン・チャンドラセカールの科学ノンフィクション記事のサムネイル。1930年、19歳の青年が英国へ向かう船の上で「燃え尽きた星には、それ以上重くては存在できない限界がある」ことを見つけた。5年後、当代最高の権威に公開の場で全否定される。彼は戦い続けることも忘れることもせず、47年を歩いた「執念の物語」。

# 媒体・サイズ
note の横長サムネイル。アスペクト比 1.91:1（1280×672px 相当）。

# 誰に見せるか
科学に憧れつつ数式で挫折した経験のある30〜40代の社会人。専門家ではないが、知的で静かなドラマを好む層。

# 起こしてほしい行動

# 被写体（メインビジュアル）
1930年、インド洋を行く客船の夜の船室。若い男性が木の机に向かい、手書きの紙束に計算を書きつけることに没頭している。うつむいて紙に向かう姿勢。後ろ姿、または背中越しの斜め後方から捉え、顔は見えない。机の上には紙束と万年筆、そして真鍮または布のシェードの小さなランプ。ランプの暖色の光だけが室内を照らし、部屋の大半は暗い。人物の正面か斜め前に丸い舷窓または四角い窓があり、その外には天の川を含む圧倒的に濃密な星空が広がっている。室内の暗さと窓の明るさの落差で、外の宇宙こそが彼の向き合っている対象であることが伝わる。人物と机は中央〜やや右に配置する。静かで、孤独で、同時に高揚した空気。映画のワンシーンのようなリアルな写真/CG 調。
