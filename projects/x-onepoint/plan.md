# Project Plan — X ワンポイント解説（W003）

## Purpose

- 物理に憧れがあるが数式で挫折した文系会社員の「科学の面白い話をサクッと知りたい」というニーズを満たす。
- 1 日 1 本の継続運用で、非フォロワー流入とフォロー転換を本文の質だけで取りに行く。

## Audience

- メインターゲット: **PE01 — 物理に憧れがあるが数式で挫折した文系会社員**（例: 中村美咲・32歳・メーカー総務・名古屋・独身）。
- 状態: 高校までは物理が好き。相対論・量子力学の本を開くと数式で挫折。Newton や Eテレは見る。知的好奇心は強いが、自分で深掘りする時間と余裕がない。
- 心理: 「文系だから無理」という諦めと、それでも惹かれる気持ちの板挟み。周りに科学の話ができる人がいない。
- 接触: 朝の通勤電車（7:30〜8:15）で X、昼のカフェで長文、就寝前 23 時前後に流し見。リプより、いいね・ブクマで静かに反応する。
- 読む目的: 知的好奇心を満たす / 翌日の雑談ネタ / 静かな興奮（派手でない、しみじみ）。

## Offer

- 直接の商品案内はしない（W003 は本文の質でフォロー・信頼を獲得する短文投稿）。
- 中長期の導線: 同じ価値観（執念・再挑戦）の **note 記事（W002）/ X 長文ストーリー（W001）** への自然な接続。
- ワンポイント投稿の積み重ねが、よーんアカウントへの信頼・フォローという無形のオファーになる。
