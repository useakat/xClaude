# CLAUDE.md — 投稿系プロジェクト共通ルール（w001 / w002 / w003）

各プロジェクトの `spec.md` に加えて、**w001・w002・w003 に共通する制作ルール**をここに置く。
プロジェクト固有の手順は各 `spec.md` を正とし、ここには「3つとも同じであるべきこと」だけを書く。

※ z01 は `draft/` を持たない別系統のため、このファイルの draft ルールの対象外。

---

## draft ファイルの扱い

作業フォルダの `draft/` は次の3種類で構成する。

| ファイル | 役割 | 上書き |
|---|---|---|
| `draft/draft.md` | 本文の作業ファイル。執筆・推敲・修正はすべてこのファイルを直接更新する | する（常に最新版） |
| `draft/first-draft.md` | **初稿**（ユーザーに最初に提示した版）の凍結コピー | **しない**（自動生成・編集禁止） |
| `draft/<工程名>.md` | 工程ごとの中間生成物（`agenda.md`・`hook-candidates.md`・`image-plan.md` など） | 工程ごとに1ファイル |

- **本文の版を `draft_vN.md` として増やさない。** 推敲は `draft.md` を直接更新する。
- 初稿と最終稿の2点があれば差分の振り返りは足りる。中間の各版は残さない。

### first-draft.md（初稿の凍結）

**hook（`scripts/freeze_first_draft.sh`）が自動で作成する。手で作らない・編集しない・削除しない。**

2段階で動く：

1. **PostToolUse(Write|Edit)** — `draft/draft.md` に書き込んだら、そのパスを記録簿 `.claude/.draft-touched` に控える。
2. **Stop** — Claude がターンを終える＝ユーザーに原稿を提示した瞬間に、記録簿にある `draft.md` を `first-draft.md` へコピーして記録簿を空にする。`first-draft.md` が既にあれば何もしない（＝**最初の1回だけ**が「初稿」）。

書き込み時点ではなく Stop まで待つのは、w002 のように**執筆後に自動チェックを重ねてから提示する**フローがあるため。ユーザーが実際に目にした版を残す。

対象は**そのセッションで自分が書いた `draft.md` だけ**で、過去記事の走査はしない。

**目的**：ユーザーに見せる初稿の完成度を上げること。初稿と最終稿を突き合わせて「毎回どこを直されているか」を分析し、その結果を `brand.md` / `spec.md` の執筆前ルールに反映していく。

**注意**：原稿を書いた直後に（提示前に）ターンを終えると、その版が初稿として凍結される。原稿を書いたら、チェック・推敲を終えて提示できる状態にしてからターンを終えること。
