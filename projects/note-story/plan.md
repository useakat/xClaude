# Project Plan — 困難を乗り越え成功した執念の物語の note 記事（W002）

## Purpose

宇宙探査・科学発見の「困難 → 工夫 → 逆転」の実話を物語として描き、読者に
**「失敗や制約の中でも諦めなくていい」「自分の理想を追っていい」**という肯定感を体験させる。

科学の解説そのものより、それを成し遂げた人間の知性・執念・再挑戦にスポットを当て、
読み終えたあとに「自分ももう一歩動いてみよう」と静かに背中を押される読後感を残す。
（共通の発信目的は `../../plan.md` を継承）

## Audience

W002 が対象とする persona は **PE01・PE05・PE09・PE10**。
共通項は「科学への憧れと挫折経験」「理想の自分と現実のギャップへの後ろめたさ」。

- メインターゲット:
  - **PE01** 物理に憧れがあるが数式で挫折した文系会社員（中村美咲・32）
  - **PE05** 文系就職した元理系学生（高木涼・27）
  - **PE09** 物理で挫折経験のある医療職（藤本由香・41）
  - **PE10** 科学を経営の比喩に持ち込みたい起業家（三崎拓海・44）
- 状態: 知的好奇心はあるが、専門書は途中で挫折／時間がない。科学への憧れと劣等感が同居。
- 心理（pain PR001「失敗・制約の中で諦めそうになる気持ち」severity 4）:
  - 「自分には無理」とブレーキをかけている
  - 理想を追う自分と現実的な自分の板挟みに後ろめたさを感じている
- 接触: 昼休みのカフェ・通勤・子の寝かしつけ後（22〜23時）に note の長文をじっくり読む。
- 読む目的: 知的好奇心を満たす／挫折した過去を肯定してほしい／静かな興奮と余韻を味わう。

## Offer

- 直接の商品案内はしない。
- 価値は「執念の物語による疑似体験」と「もう一歩動いてみようと思える肯定感」。
- 記事後半（有料部分）で物語のクライマックスと意味の宣言を届ける。

## Deliverables

→ `spec.md` 参照（Media / Output / Format / Naming）。

## Success Criteria

- 読後に「諦めなくていい」「自分の理想を追っていい」と感じられる読後感になっている。
- 専門外の読者が数式なしで物語として最後まで読み通せる（読了率）。
- 記事購入・フォロー・スキにつながる導入部の引きがある。
- 共通成功条件（`../../plan.md`）: 発信全体で月15万円の収益に寄与する。

## CTA（このプロジェクトのターゲットに取ってもらいたい行動）

- フォロー
- 記事購入（有料部分）
- スキ・ブクマ（本文の質で取りに行く。明示的な誘導はしない）

## Risks（プロジェクトの失敗要因）

- 解説に寄りすぎて「人間のドラマ」が薄くなり、ただの科学記事になる。
- 専門用語の噛み砕きが不足し、対象読者が途中離脱する。
- 煽り・上から目線・「文系でも分かる」の押し付けで、挫折経験者の劣等感を刺激する。
- 出典のない発言・心情の捏造で史実の信頼性を損なう。
- 導入部（無料部分）で引きが弱く、有料部分に進む動機が作れない。
