# brand.md — W001 執念の物語 X長文ポスト（SCEtoAUX）

## Inherits
- `../../../brand.md`（共通ブランド定義：よーんの人格・温度感・1人称/2人称・共通NG）
- note 記事側の世界観は `../../brand.md`（W002）と揃える。事実・呼称・装置の帰属を note 記事と矛盾させない。

固有ルールが共通定義と矛盾する場合は共通定義を優先する。本ファイルには W001（X長文ポスト）固有の方針のみ記す。

## Impression
- 「ガチな科学」×「中の人の泥臭いドラマ」を、約600字で一気に読ませる知的エンタメ。
- 語っているのは科学に見せた**人間の知性・執念・再挑戦**。読後に「諦めなくていい」と静かに背中を押す。
- 騒がしい煽りではなく、**静かに熱い**。先輩が「これ、かなり震える話なんだけど」と熱を抑えて語る距離感。
- 挫折経験のある読者（PE01/05/09）の劣等感を刺激しない。「文系でも分かる」と銘打たず、自然に分かる構造で書く。

## Visual
- X のプレーンテキスト投稿。ブロック間は空行のみ（`---` は本編内で使わない）。
- 1段落1〜3文。緊張・転換では短文を畳みかける。
- 装飾記号・絵文字は使わない。強調は「」または太字（`""` は使わない）。
- 末尾に関連ハッシュタグを数個（例: `#アポロ12号 #NASA #宇宙`）。

## Writing

### 構成（X長文の型）
- **冒頭フック2文**: 1文目は引きの強い一撃、2文目は「〇〇な話。」「〇〇の物語。」で何の話か一目で伝える。
- 物語の基本形は「困難 → 工夫 → 逆転」。主人公（24歳の管制官ジョン・アーロン）を立て、その判断・好奇心・立て直しを軸にする。
- 前半はドラマの描写に徹する（事実・出来事のみ）。**教訓・メッセージは最後の1〜2段落に集約**。前半に「諦めないとは〜」を挿入しない。
- 締めは「意味の宣言」「感情」「未来へのまなざし」で、PR001 を解消する読後感（諦めなくていい）に着地。
- **本編は X 内で完結させる**。「続きはnoteで」と中断しない。note 誘導は本編に入れず、セルフリプで行う（plan.md の Funnel 参照）。

### 文体・語尾
- 口語・会話的。驚き重視。`buzzPostData.txt` の既存投稿のトーンに揃える。
- 常体を主軸に、要所で体言止め・「である」調・短文太字を混ぜる。同じ語尾を3文以上続けない。

### 冒頭フック
- 冒頭フックは `~/xClaude/style/hook-patterns.md`（逆説・知識提示・場面描写・問いかけの4型テンプレート）を参考にして組み立てる。
- 書き出しフック例: 「これ、かなり震える話なんだけど聞いてほしい。」「これ、ヤバすぎる話なんだけど聞いてくれ——」。

### 専門語の翻訳（最重要）
- 専門用語は直前か直後に必ず噛み砕く。残してよいのは噛み砕きが隣接する場合のみ。
- 手法: 実体に置き換える／動作で説明する／身近な比喩で重ねる。
  - 例: 「3軸姿勢制御を失った」→「自分がどっちを向いているか、わからなくなった」。
  - 「SCE」「AUX」を出すなら、その場で役割（宇宙船の信号を整える装置／その安全装置を外すモード）を一言で添える。
- 読者が知らない因果を1ステップも飛ばさない。前方参照を作らない（使う前に前提を説明）。

### 史実・出典
- 史実・数値・人物名・判断は note 記事 `../output/index.md` の内容に合わせる。想像で発言・心情を捏造しない。
- 断定の強さは事実に合わせる（「すべて」「〜寸前」など出典を超える誇張をしない）。
- 同一対象の呼称を統一し、装置の帰属（燃料電池・SCE は宇宙船側）を取り違えない。
- X 本編に出典マーカーや参考文献リストは載せない（詳細・出典は note 記事側に置く）。

## Do Not
- 専門用語の無翻訳（直後の噛み砕きがない）
- 本編での明示的 note 誘導・「続きはnoteで」の中断型（誘導はセルフリプのみ）
- 前半への教訓・説教の挿入
- 出典のないセリフ・心情の捏造、事実の誇張
- 「文系でも分かる」「これが分からないと恥」系の煽り・上から目線
- 「すごい」「とても」「非常に」など中身のない強調語の連発
- 明示的 CTA（「フォローしてください」等）。フォロー・スキ・購入は本文の質で取りに行く。

## 採点基準

`/check-brand` が本文を採点するための基準。各項目を 0〜10 で採点し、**全項目8点以上で合格**。
8点未満の項目は該当箇所のみ事実を変えず書き直す（最大5回ループ・既に8点以上の項目は壊さない）。字数目標は **約600字**。

| 項目 | 9〜10（優） | 7〜8（合格・最低ライン） | 5〜6（要改善） | 0〜4（不可） |
|---|---|---|---|---|
| 1. 冒頭フック2文 | 1文目の一撃＋2文目「〇〇な話。」で何の話か即伝わり、続きを強く読みたくなる | 2文で何の話か伝わり引きがある | 引きが弱い／2文で話が見えない | 抽象・凡庸でスルーされる |
| 2. 具体3点セット | 冒頭に日付・場所・状況が自然に揃い場面が立ち上がる | 3点が揃う | 1〜2点欠ける | 抽象的な書き出し |
| 3. 字数・X内完結 | 約600字（±50）でX内完結・中断型でない | 500〜700字でX内完結 ← **8点の最低ライン** | 400〜500字 / 700〜800字、または一部未完感 | 400字未満 / 800字超、または中断型 |
| 4. 専門語翻訳・前方参照 | 全専門語が直前直後で噛み砕かれ前方参照なし | ほぼ噛み砕き済・前方参照なし | 一部裸の専門語／軽い前方参照 | 専門語が裸／種明かしが後段 |
| 5. 教訓の配置 | 前半は描写に徹し教訓は末尾1〜2段落に集約 | 教訓がほぼ末尾に収まる | 前半に教訓が混じる | 全体に説教が散在 |
| 6. 史実整合 | 人物名・日付・装置の帰属が note 記事と完全整合 | 整合（軽微な表現差のみ） | 一部あいまい／取り違えの懸念 | note 記事と矛盾・捏造 |
| 7. 締めの着地 | 「意味の宣言/感情/未来」で「諦めなくていい」読後感に強く着地 | 「諦めなくていい」に着地 | 着地が弱い | 教訓・感嘆のみで着地しない |
| 8. ハッシュタグ | 末尾に内容に合った関連ハッシュタグが数個 | 関連ハッシュタグあり ← **8点の最低ライン** | 数が少ない／関連薄い | ハッシュタグなし |

- note 導線は本編に入れずセルフリプで分離する（本編採点では「本編に note 誘導が混入していないか」を項目5/7の観察に含める）。
- 字数超過時は、本筋に不要な機構説明・重複数値・冗長な接続文から順に削る。
