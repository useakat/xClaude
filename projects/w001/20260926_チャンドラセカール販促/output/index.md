# チャンドラセカール販促 — X長文

## 本編

これ、ショッキングな話なんだけど聞いてほしい。
24歳が5年かけた計算を、時の権威が公開の場で葬った話。

1935年、英国の王立天文学会
無名の青年チャンドラセカールは、星の運命を変える計算を発表した。
「燃え尽きた星は、ある重さを超えると潰れ続ける」

その直後、一人の男が演壇に上がった。

当代最高の天文学者アーサー・エディントン。
研究の進み具合を聞き、手回し計算機まで貸してくれる間柄だった。

その彼が言い放った。
「星がこんなばかげた振る舞いをしないように、自然の法則があるべきだ」
つまり、星が潰れ続けるなんてありえない、と。

青年は耳を疑った。
あれほど研究を見守ってくれた人が、なぜ。
5年かけて積み上げたものが、信頼していた権威の手で崩された。

青年は、うつむいたまま会場を後にした。

──それでも。

自分の計算を捨てなかった。
英国を離れ、アメリカで研究を続けた。数式に向き合い続けた。

あの日から48年後。
1983年、チャンドラセカールはノーベル物理学賞を受賞する。

かつて「ばかげている」と言われた理論は、いまや「チャンドラセカール限界」として恒星進化の基礎になっている。

信じていた人に否定されることがある。
積み上げた努力を、たった一言で踏みにじられることがある。

それでも、自分を信じて続けた歩みが、道になっていく。
