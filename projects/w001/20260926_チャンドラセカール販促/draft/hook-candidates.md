> フォーカス: 1935年1月11日、王立天文学会の演壇
>
> brand.md「高反応投稿の型」A-1 により、**採用すべきは ⑤語りかけ・口火型 か ①逆説・常識覆し型**。口火型なら温度形容（ヤバい／震える／痺れる／熱い）必須、逆説型なら落差構文。②③④は引き出しとして併記する。

> A-2: 認識の落差を冒頭3文以内に置く。使える数字ペア＝「24歳 → 半世紀後のノーベル賞」「5年の計算 → 数分で片づけられた」

## ① 逆説・常識覆し型

**1-1**
「発表を勧めてくれた人は、味方だ」——その常識が、24歳の目の前で崩れた。
1935年、世界最高の天文学者が、背中を押した当人を公開の場で葬った話。

**1-2**
「正しければ、いつかは認められる」。
そう思っている人に聞いてほしい。24歳が5年かけた計算が、たった一言で片づけられた日の話。

**1-3**
科学は、正しさで決まる——そう教わってきた。
ところが1935年のある学会では、「誰が言ったか」だけで全員の判断が決まった。

**2-1**
あなたが「ブラックホール」と呼んでいるものは、かつて「あってはならないもの」だった。
そう言い切ったのは、当時世界最高の天文学者だ。

**2-2**
星に「これ以上重くなれない限界」があることを、最初に見つけたのは19歳の学生だった。

**2-3**
24歳で世界最高の権威に全否定された科学者が、半世紀後にノーベル賞を取ったことを、多くの人は知らない。
1935年1月11日、ロンドンでの話だ。

## ④ 問いかけ型

そんな場所に立たされたら、あなたはどうするだろうか。

**4-2**

**4-3**

## ⑤ 語りかけ・口火型

**5-1**

24歳が5年かけた計算を、世界最高の権威が公開の場で葬った日の話。

**5-2**

**5-3**

## 決定

**1-1（①逆説・常識覆し型）をベースに、検品を経て次の形に確定**

```
「発表を勧めてくれた人は、味方だ」
その常識が、その日のうちに崩れた話だ。
```

当初案は「——その常識が、24歳の目の前で崩れた。／1935年、世界最高の天文学者が、背中を押した当人を公開の場で葬った話。」だったが、折り返しチェックで **2文目が種明かしを済ませてしまい、折り返し直前の一行が「確認」になっている**（引き7/10）と判定されたため、裏切りの中身を2文目から外し、折り返し直前へ移した。
「数分で崩れた」は出典で裏が取れず（note 正本は「その日のうちに片づけられた」）、よーん役検品の【疑義】を受けて「その日のうちに」に改めた。

理由:
- 誰もが疑わない前提を1文目に置き、2文目で崩す。brand.md A-1 の逆説型の落差構文に合致
- 「背中を押した人に潰される」は科学の話を超えて読者の職場感覚に届く
- note の売り（沈黙の解剖・1982年の記念講演・10年ごとの歩き方）を一切匂わせない

## 折り返しブロック（フロー5.5・実測確定）

280weight ちょうど。切れ位置は **「彼は言い放った。」の直後**。

```
「発表を勧めてくれた人は、味方だ」
その常識が、その日のうちに崩れた話だ。

1935年1月11日、ロンドン。王立天文学会。
24歳のチャンドラセカールが、5年かけた計算を発表した。

次に演壇に立ったのが、その発表を勧めた当人だった。
当代最高の天文学者アーサー・エディントン。
彼は言い放った。
```

**ここで伏せている情報**
- エディントンが何を言ったのか（引用そのもの）
- 会場の反応（「気の毒に」）
- その後の48年とノーベル賞

**設計の経緯**
1. 当初案は切れ位置が語の途中（「存在でき|ない」「勧めた|当人だった」）に落ちた。
2. 2文目から年を外し、最終行の「そして」を削って文末で切れる形にした（279weight・切れ位置＝「当人だった。」の直後）。
3. よーん役検品1巡目で **実測すると人名「アーサー・エディントン」が割れている**ことが判明（私の確認ミス。スクリプト出力の「切れ目直前」を読み違えた）。あわせて「落差の材料が全部折り返しの向こう側にあり、可視だけ読むと好意的な場面に見える」と指摘された。
4. そこで可視ブロックに**権威の情報まで入れる**方針へ変更。「当代最高の天文学者アーサー・エディントン。彼は言い放った。」までを可視に収め、権威が口を開く直前で切る形にした（280weight ちょうど）。
