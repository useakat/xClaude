# 役割
X（Twitter）の長文ポストに添付する横長画像を1枚生成してください。1927年の実話の重みを感じる、映画のワンシーンのようなリアルな写真調で。文字は一切入れないでください。

# 何の画像か
1927年10月、ブリュッセル。物理学の国際会議の廊下の片隅で、無名の若いカトリック司祭が、論文を手に、窓際に立つ高名な老物理学者へ歩み寄ろうとしている——その「声をかける直前」の一瞬。

描くのは挑む直前の緊張だけ。この後どうなったかは絶対に描かない。

# 媒体・サイズ
横長 16:9（1600×900px 相当）。単体でタイムラインに表示され、スクロールを止める役割。

# 被写体（メインビジュアル）

**手前・画面左寄り（主役）**: 若い男性のカトリック司祭。1920年代の黒いカソック（足首まである黒の長衣）にローマンカラー（白い立ち襟）。**カメラに背を向けた後ろ姿〜斜め後ろからの姿**。片手に紙の束（論文の原稿）を持ち、体はすでに奥の人物のほうへ向いていて、まさに一歩踏み出そうとしている。**顔は見えない。**

**奥・画面右寄り（対する人物）**: 高い縦長の窓のそばに立つ、年配の男性のシルエット。1920年代の三つ揃えのスーツ。**強い逆光で完全に影になっており、顔は黒く潰れて一切判別できない。** 癖のある豊かな白髪の輪郭だけが窓明かりに縁取られている。誰かと会話している最中の、くつろいだ立ち姿。

**さらに奥（背景）**: 同じく1920年代の背広姿の学者が数人、ぼんやりと。被写界深度で溶けており、顔は誰も判別できない。

**二人の間には、まだ数歩の距離が空いている。** その空白が画面の中心にあり、「これから声をかける」緊張を生む。

# 場所
1920年代ヨーロッパの学術会議場・大学建築の廊下。天井まで届く高い縦長の窓が並び、床は使い込まれた寄木の木床。装飾的な石またはダークウッドの柱。人だかりから少し外れた、静かな片隅。

# 光（この絵の要）
**窓からの秋の午後の逆光が唯一の主光源。** 奥（窓側）が明るく、手前が暗い。
- 司祭は**影の側**にいる。
- 老物理学者は**光の側**にいる。
この明暗が、そのまま「無名」と「権威」の力関係になっていること。

司祭が手にした**白い紙束が、画面で最も明るい小さな一点**。逆光を受けて浮かび上がる。これがこの男の唯一の武器に見えること。

# 配色
- ベース：秋の午後の褐色〜セピア。古い木材、暗い室内。
- 光：窓から差す蜜色〜淡い金の逆光。
- アクセント：司祭の紙束の白（画面唯一の強い明部）と、ローマンカラーの白。
- 彩度は抑える。ドラマチックだが騒がしくない。静かに熱いトーン。

# 質感
フォトリアル、映画的。1920年代を写した写真のような、わずかな粒子感と空気感。カソックの布の落ち感、木床の傷、窓ガラス越しの柔らかな光。イラスト調・平面的なCG調にしない。

# 最も大事なこと
小さなサムネイルでも、一目で「黒い服の男が、奥の人物へ向かおうとしている」と読めること。誰なのかは分からなくていい。「これから何かが起きる」という緊張だけが伝わること。

# 禁止事項
文字・数式・読める文書・コピー・ロゴ・透かし・絵文字を一切入れない（紙束は白紙の質感のみ）。
**顔がはっきり見える人物を描かない。**特定の実在人物の似顔に見える顔を描かない。
宇宙・星空・銀河・惑星・宇宙の膨張のイメージを一切入れない（これは地上の人間ドラマ）。
黒板・数式の書き込み・図表を描かない。
拒絶・落胆・口論・対立の決着が分かる表情や身振りを描かない（肩を落とす・背を向けて去る・手で払いのける等）。
教会・聖堂・祭壇・ステンドグラスを描かない（会議場であって教会ではない）。
現代的な服装・照明・家具・建築を描かない。
