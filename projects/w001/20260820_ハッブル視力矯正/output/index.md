# 「世界最高の目」と言われたハッブル宇宙望遠鏡。その目に映る宇宙は、しかし、ぼやけていた

## 本編

「世界最高の目」と言われたハッブル宇宙望遠鏡。その目に映る宇宙は、しかし、ぼやけていた。

1990年5月、打ち上げから1か月がたった頃。地球を周るハッブルから、待ち望んだ最初の写真が届いた。しかし、星は点にならず、にじんだ光の輪へと広がっていた。

誰もが、息を呑んだ。何が起きたのか？

原因は主鏡。光を集めて像を結ぶ心臓部だ。外周が、髪の毛の太さの約50分の1だけ削られすぎていた。それだけで光は一点に集まらない。

世紀の失敗作とまで書かれ、NASAは批判を浴びる。

主鏡の修理は難しい。しかもハッブルがあるのは地球を周る軌道上だ。

技術者たちは、鏡を直さず「視力を矯正する」道を選んだ。主鏡で集めた光が観測装置に届く前に、歪みを打ち消す鏡を通す。メガネと同じように、目に届く前に整えるのだ。主力カメラはその鏡を内蔵した新型に替え、観測装置をひとつ降ろして補正鏡10枚を差し込む修復計画を立てた。

どうやってそれを実行するのか？

もちろん、人が行ってやる。

1993年12月、シャトル・エンデバー。

4人の飛行士が2人ずつ交代で船外に出た。ピアノほどの大きさの新型カメラを差し入れ、冷蔵庫ほどの補正装置を据え付ける。

威信をかけた作業は合計35時間以上におよび、船外活動5回は当時の最多記録となった。

そして、ハッブルから新しい画像が届く。

にじんだ光の輪は消えた。あるのはくっきりとした一点の星。

人々の底力、半端ない。

失敗作と呼ばれた目は、その後も更新を重ね、今もブラックホールや生まれたての星を映す。

失敗したら終わりじゃない。そこからどれだけ粘れるか、それが勝負だ。

#ハッブル宇宙望遠鏡 #NASA #宇宙 #失敗してからが勝負
