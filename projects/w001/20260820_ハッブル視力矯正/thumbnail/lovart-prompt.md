```
# 役割
X（Twitter）の長文ポストに添付する横長画像を1枚生成してください。実話の重みを感じる、映画のワンシーンのようなリアルな写真/CG 調で。文字は一切入れないでください。

# 何の画像か
ハッブル宇宙望遠鏡が、1990年の打ち上げ直後、地球を周る軌道上に静かに浮かんでいる場面。世界最高の望遠鏡と呼ばれながら、届いた最初の写真がぼやけていた——その原因がまだ誰にも分かっていない時点の投稿に添える画像。

# 媒体・サイズ
横長 16:9（1600×900px 相当）。単体でタイムラインに表示され、スクロールを止める役割。

# 誰に見せるか
科学に憧れつつ数式で挫折した経験のある30〜50代の社会人。専門家ではないが、静かなドラマを好む層。

# 被写体（メインビジュアル）
漆黒の宇宙に浮かぶハッブル宇宙望遠鏡。

**カメラは機体のやや前方・やや上から見た斜め45度の3/4視点**（添付の参照写真 hst_orbit_full.jpg と同じアングル）。円筒形の機体が画面を斜めに横切り、太陽電池パネルは水平な棒ではなく斜めの線を描く。機体は画面のやや右寄り、画面幅の6〜7割を占める。

**筒の口（開口部）はカメラのほうを向かず、画面の奥・上方の宇宙へ向いている。** 何かを見ようとして構えている姿勢。

画面の**下辺にだけ**、地球の丸みが細い弧として入る。深い青の海と、地平線に沿った薄く光る大気の層。地球は主役ではなく、静かに遠い。

**最重要——この絵の核心**: **機体そのものは完全にシャープでピントが合っていること。** 継ぎ目・ハンドレール・断熱材のしわの1本まで鮮明に。**その一方で、背景の星だけがおかしい。** 星が清らかな点にならず、ごく淡いハロー（芯のぼやけた小さな光の円）として写っている。光が一点に集まりきっていない状態。

**この効果は控えめに。** 一目では気づかず、目が落ち着いてから「星がなんだか変だ」と感じる程度。**これはレンズのボケでも、被写界深度でも、ピンぼけ写真でも、手ぶれでもない。** 画面は全体としてシャープで、星の芯だけが結ばれていない。星は数を少なく、暗く、まばらに。星空を密に敷き詰めない。

破損・火花・煙・ひび割れは描かない。壊れて見える絵にしない。まだ原因が分かっていない、静かな時点を描く。

# 機体の形と色（添付の参照写真に従う）
- **本体は銀色〜アルミ色の円筒**。ずんぐりした太い筒。**箱型・球体・円盤型にしない。**
- 筒の一端が**望遠鏡の開口部**。**蝶番式の扉が開いて機体側に折り返され**、開口部そのものは暗い円の穴として見える。
- **太陽電池パネルは左右に1枚ずつ、合計2枚**。円筒の両側面からまっすぐ水平に張り出す。表面は濃紺〜黒に近い青のセルに細かいグリッド、縁は淡い金色〜ベージュの枠。**4枚にしない。折り曲げない。**
- **円形のパラボラアンテナが2基**、短いブームで突き出る（1基は上側、1基は下側）。
- 機体表面は銀色〜灰色の断熱材。パネル状の継ぎ目・リング状の分割線・ハンドレールが見え、ところどころに**しわの寄った金色のMLIフォイル**が覗く（質感は添付の hst_body_closeup.jpg を参照）。

# 光
画面外の太陽からの強い斜光が、機体を舐めるように当たる。円筒の片側と手前のパネルが眩しく照らされ、反対側は深い影に沈む。硬く清潔でコントラストの高い宇宙の光。**レンズフレア・光条・ブルームは入れない。**

# 配色
- 背景：漆黒の宇宙。星はまばらで暗い。
- 機体：銀色〜アルミ（ハイライトは冷たい白）× 太陽電池パネルの濃紺（画面内の主要な色アクセント）。
- 地球：下辺にごく薄く、深い青と大気の淡い光。
- 抑制の効いた、冷たく静かなトーン。派手にしない。

# 質感
実際に近くの宇宙船から撮った写真のような、フォトリアルで高精細なハードサーフェス表現。断熱材のしわ、パネルの継ぎ目、リベット、ハンドレールが見える。イラスト調・平面的なCG調にしない。静かで重量感のあるムード。アクション映画的な派手さは不要。

# 最も大事なこと
小さなサムネイルでも、一目で「巨大な望遠鏡が、地球の上に静かに浮かんで、宇宙の彼方を見つめている」と読めること。星のハローは、その後に気づく二段目の情報。

# 禁止事項
文字・コピー・ロゴ・透かし・絵文字を一切入れない。宇宙飛行士・宇宙服・船外活動・ロボットアーム・スペースシャトル・管制室・人物を入れない。修理機器や補正光学装置を描かない。破損・ひび割れ・火花・煙・分解図を描かない。鮮明な星雲・銀河・星団などの派手な天体を描かない。画面全体をぼかさない。
```
