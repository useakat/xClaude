## 候補1: グランドフィナーレ — 「英雄をなぜ自ら燃やしたのか」
- 入口: 2017年、NASA は20年働いた探査機を、自らの手で土星に突入させて燃やした。なぜか?
- 引きの強さ: 「成功した探査機を自分で壊す」という逆説。理由（自分たちが見つけたかもしれない“命のゆりかご”を汚染から守る）に倫理と愛がある。**過去投稿では一切触れていない場面**。
- 完結: 突入の決断→理由（エンケラドスの発見が自らの死に方を決めた）→「発見が探査機の運命を変えた」で完結。噴水発見の経緯は note へ。

## 候補2: 決死のダイブ — 「噴水の中に探査機を突っ込ませた日」
- 入口: 2015年、高度わずか49km。人類は探査機を、異世界の噴水の真っ只中に突っ込ませた。
- 引きの強さ: 「見つけて満足しない」チームの狂気と、その場で成分を嗅ぎ取る発想の大胆さ。過去投稿では1段で触れただけの場面を主役化。
- 完結: ダイブの決断→リスク→突入→見つけたもの（塩・有機物・熱水の手がかり）で完結。「なぜ噴水があると分かったのか」の前段は note へ。

## 候補3: 軌道変更の直訴 — 「却下されるはずの提案が歴史を変えた」
- 入口: 燃料は有限、相手は「何もないかもしれない」小天体。それでも一人の科学者が NASA に軌道変更を直訴した。
- 引きの強さ: 組織 vs 個人の確信という普遍ドラマ。ただし過去投稿の中心軸（ドハーティの違和感〜説得）と部分的に重なる。
- 完結: 提案の異例さ→葛藤→GO→歴史が変わった、で完結。その後の発見の詳細は note へ。

## 決定
**候補1（グランドフィナーレ）**。「なぜNASAは20年働いた英雄を自ら燃やしたのか」を主役に、突入の決断→理由（自分たちの発見が探査機の死に方を決めた）→発見と運命の交差で完結。噴水発見の経緯・ダイブの詳細は note へ温存。過去投稿（違和感起点の全アーク要約）との重複ゼロ。
