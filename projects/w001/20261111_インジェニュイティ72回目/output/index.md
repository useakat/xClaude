# 地球に火星の空を作った人たち

## 本編

地球に火星の空を作った人たちがいた。
高さ約26mもある巨大な実験室に、二酸化炭素の薄い空気を満たして。
目的は火星で飛ぶ小型ヘリを開発すること。

火星の空気は地球の約1%。
ヘリの揚力を生む空気が、ほとんどない。
そんな環境でヘリが飛んだ前例はなかった。

薄い空気で、機体は浮くのか。

答えは、機体の重さにかかっていた。
許された重さは、約1.8kgまで。

だから、チームは削った。
火星へ行くのに、科学観測機器はゼロ。飛ぶことだけに絞った。

コンピューターには、宇宙用の大きくて重い部品ではなく、スマホ用のチップを使った。

火星の空気そのものを、極寒の夜から電子機器を守る「断熱材」として使うことにした。

火星の空気を模した実験室で、ヘリの羽を毎秒約40回転で高速回転させる。
火星の重力を再現するため、機体をワイヤーで上に引っ張り、地球の重力から余分な62%分を打ち消した。

機体は、浮いた。

チームを率いたミミ・アウンは言った。
「次に飛ぶのは、火星だ」

2021年4月19日、ヘリ型実証機「インジェニュイティ」は火星の空で3mの高さまで浮き、約40秒間飛行した。
地球以外の惑星での、人類初の動力飛行だった。

当初予定された飛行は30日間で5回だったが、インジェニュイティは約3年間、71回飛び続けた。
そして72回目、着陸の衝撃で羽が折れ、二度と飛べなくなった。

火星の空に、探査機を飛ばしたい。
その情熱が、惑星探査に新しい世界を開いた。

インジェニュイティに続く空を飛ぶ探査機は、土星の衛星タイタンへ向かうドラゴンフライ。2028年の打ち上げ予定だ。
その挑戦は、次世代の探査機へと受け継がれている。
