# 火星で止まらない再起動を、地上の「分身」が捕まえた（マーズ・パスファインダー 1997）

## 本編

これ、地味に見えて痺れる話なんだけど聞いてほしい。1997年7月、着陸成功に沸く地上をよそに、その探査機は火星で再起動を繰り返していた。

探査機の名前はマーズ・パスファインダー。7月4日にアレス谷へ降りたばかりだ。

着陸から10日で4回。その度にその日の作業は止まった。原因が分からない。

手詰まりに見えたが、探査機を作ったNASA/JPLのチームには切り札があった。

地上のラボに、火星の機体と同じソフトウェアが動く試験機があった。

火星にいる実機を直接調べるのは難しい。
だが、目の前の「分身」なら何度でも試せる。

チームは、火星で再起動が起きた日の手順を、そのままの順番で地上の試験機にやらせた。

最初は何も起きない。

それでも、何度も何度も繰り返した。

そして、開始から18時間が経とうとする頃、試験機が火星の機体と同じように再起動した。


来た！


試験機が残した記録を詳しく調べると、とうとう犯人が見えた。

「優先度逆転」。

探査機のプログラム処理の順番の決め方に、穴があいていたのだ。
後回しでいいはずの処理が、いちばん急ぎの処理を間接的に足止めしていた。

チームは修正を徹底的に検証し、7月21日、地球から火星へソフトウェアの変更を送った。

「優先度継承」という仕組みを有効にする、小さな変更だった。


それ以降、この問題による再起動は起きなかった。

火星での不具合を捕まえたのは、勘でも運でもない。
同じ状況を地上で再現してみせた執念だった。

#マーズパスファインダー #NASA #宇宙 #バグを再現する執念
