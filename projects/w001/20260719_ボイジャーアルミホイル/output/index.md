# スーパーのアルミホイルが、木星の脅威からボイジャーを守った（No 150）

## 本編

人類でいちばん遠くを飛ぶ探査機を守っているのは、最先端の特殊素材だけじゃない。
近所のスーパーで買った、台所用のアルミホイルだったりする。

1977年、フロリダ。探査機を打ち上げ基地へ送り出す2ヶ月前、ボイジャーの技術者たちは青ざめていた。

木星の放射線帯が、想定を遥かに超えて強烈だとわかったのだ。

木星の衛星イオの火山ガスが、地球の約20倍という木星の強い磁場に捕まり、光の速さ近くまで加速される。その中を通れば、人間の致死量の1000倍もの放射線を浴びる計算だった。

いちばん危ないのは、放射線の一種、高エネルギー電子による静電気だ。
外に張り巡らせた配線に電気がたまり、パチッと放電すれば、ボイジャーの頭脳であるコンピュータが壊れかねない。

だが、専用の遮蔽材を用意する時間はない。かといって延期もできない。木星から海王星までが一列に並ぶ「175年に一度」のチャンスは、ここを逃せば次はない。

打つ手なしに見えた。

そのとき、エンジニアの一人が気づいた。
必要なのは、電気を逃がす導電性のバリアだけだ、と。

答えは、金属の薄い膜。どこにでもあるやつでいい。

技術者たちは地元のスーパーへ走り、棚の台所用アルミホイルを買い占めた。油をアルコールで拭き取り、一枚ずつ配線に巻いて機体につなぐ。たまった電気を逃がし、電磁波を弾く、即席のシールドだ。

2年後、ボイジャーは無事木星の放射線地獄をくぐり抜けた。

あれから半世紀近く。あのアルミホイルは、いまも配線に巻かれたまま、太陽系の外を飛び続けている。

宇宙で機体を守ったのは、最先端の技術じゃない。土壇場で最善をひねり出した現場の粘りと、どこの台所にもあるアルミホイルだった。
