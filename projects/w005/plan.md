# Project Plan — 科学ニュース解説 X長文ポスト（W005）

## Purpose
- **第一目的**: いま起きた宇宙探査・科学のニュースを、「なぜそれがすごいのか」まで分かる形で届け、到達（IMP）とフォローを増やす。
- 本編ポストだけで「そういうことか」まで完結させる。note 導線は設けない（セルフリプは空タグを置くだけ。後から手で書く場合に備える）。
- 共通の発信目的は `../plan.md` を継承。

## Audience
- W005 の what は `W005`、pain は PR003（`database/what.csv`）。persona は科学好きの一般読者（W001・W003 の読者層と重なる）。
- 宇宙や物理に興味はあるが、ニュースを見ても「すごいな」で終わってしまう人。
- 接触: タイムラインでニュースを流し見している。冒頭2文で「何が起きたか」が伝わらないとスルーされる。
- 状態: じっくり読む時間はないが、「なぜ？」が引きになれば最後まで読む。

## Offer
- 最新ニュースの「核心」を、直感を裏切る落差とともに1本の物語として届ける。
- ニュースの事実（いつ・どこで・何が）を押さえたうえで、「なぜそうしたのか」「何が難しかったのか」まで解く。
- 読後に「誰かに話したくなる」状態を作る。

## Funnel
- 本編ポスト（約600字・X内で完結）のみ。セルフリプは空タグ（`[リプ][/リプ]`）で残す。
- note への誘導はこのプロジェクトでは行わない。

## Deliverables
→ `spec.md` 参照（Output / Format / Naming）。

## Success Criteria
- 本編の IMP（目標値は運用しながら決める。初回は直近の W001 通常ポストの中央値を比較基準にする）
- フォロー増（インプ1万あたり）

## CTA
- フォロー・いいね・RT（本文の質で取りに行く。明示的 CTA はしない）

## Risks
- 速報性を失う（ニュースが古いまま出る）。
- ニュースの誤読・二次情報の誤り（日付・数値・発表元の取り違え）。
- 冒頭で「何のニュースか」が伝わらず、流し見でスルーされる。
- 展望・予測を断定してしまい、信頼を損なう。
