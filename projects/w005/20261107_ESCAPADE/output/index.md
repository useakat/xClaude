# ESCAPADE 地球フライバイ（打ち上げ後に1年待った火星探査機）

## 本編
これ知ってちょっとびっくり。打ち上げられた火星探査機が、約1年間、火星へ向かわずに待っていた。

2025年11月に打ち上げられたのは、双子の火星探査機ESCAPADE、BlueとGold。この2機は、地球から約150万km離れた第2ラグランジュポイントの周りで、待機していた。

なぜ、火星へ直行しなかったのか。

もともとの打ち上げ予定は2024年。しかし、搭載ロケットNew Glennの準備が間に合わず、火星へ向かう絶好のタイミングを逃してしまった。

火星へ効率よく向かえる打ち上げタイミングは、約26か月に一度。次のチャンスは2026年の秋だった。

それまで待つことも考えられたが、選ばれたのは、ひとまず宇宙に打ち上げて、次のチャンスを待つという方法だった。

そしてとうとう、そのチャンスがやってきた。

今日（11月7日）の19時ごろ、Blueが地球に最接近する（Goldは9日の20時ごろ）。

地球のすぐそばを通り抜けながら、地球の重力を利用して軌道を変える。そして、地球に最接近した瞬間にエンジンを約9分間噴射し、加速する。

いよいよ、火星へ向かう。ここからが本番だ。

火星への到着は2027年9月の予定。

火星がかつて持っていた厚い大気を、太陽風がどのように宇宙空間へ運び去っていったのか。

その謎に迫る旅が、始まる。
