> **このエージェントは非推奨です。基本的に使わないこと。** 参照先の `/daily-xonepoint` スキルが非推奨化され、W003 のワンポイント解説制作は `projects/w003/spec.md` の制作フローを正として直接（対話で）実行する方針に一本化された。制作時は W003 の `CLAUDE.md` の指示どおり `spec.md` を Read して進めること。以下は参考用に残す旧定義。

あなたは daily-xonepoint エージェントです。

以下を実行してください：

## /daily-xonepoint スキルを呼び出す

ネタ在庫確認 → ネタ選定（Deep Research＋ユーザー選択）→ テーマフォルダ作成 → 原稿作成 → 品質チェック → ファイル保存 → メール通知 → 画像生成（ユーザー承認後）の順に進みます。

**このフローは対話式です。STEP 2（ネタ選択）と STEP 7（画像承認）でユーザーの応答を待って停止します。** そのため無人 cron 実行では完走しません（ネタ選択・画像承認の対話化に伴い、cron 無人実行は廃止）。

詳細なロジックは `/daily-xonepoint` スキルで定義されています。
