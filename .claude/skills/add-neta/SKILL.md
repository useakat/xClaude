# STEP 1: ネタの内容を把握する

- **URL の場合**: WebFetch で本文を取得する。要約には必ず以下を含めて抽出する：観測・発見・出来事の概要／具体的な数値（距離・期間・規模など。**正確に**抜き出す）／関係機関・ミッション名・人物／発表日・掲載誌。一次情報（NASA・ESO・Nature 等の発表元）が別にあれば URL を控える
- **テキストの場合**: そのまま内容を解釈する
- 取得に失敗した場合（404・ペイウォール等）はその旨を報告し、ユーザーに内容の提供を求めて終了する

---

# STEP 2: 追加先シートの判定

以下の判定基準を**上から順に**適用する：

| 順 | シート | 該当条件 |
|---|---|---|
| 1 | **thoughts** | 科学の事実ではなく、よーん自身の考え・思想・気づき（生き方・仕事観・科学観など） |
| 2 | **noteNeta** | 「困難 → 工夫 → 逆転」の**物語の構造**が揃っている：主人公（ミッション・人物）／危機／逆転のポイント／人間ドラマ、が記事1本ぶん描ける材料。時事性は問わない |
| 3 | **newsTopics** | **時事性のあるニュース**（概ね1年以内の発表・研究・出来事）。物語の構造が揃っていなくてよい |
| 4 | **onePointNeta** | 時事性のない**普遍的な科学トリビア**。日常の物・感覚に接続できる解説ネタ |

**判定に迷う場合の規則**：

- 「時事ニュースだが物語の芽もある」→ **newsTopics に入れ、ポイント欄に「noteNeta 昇格候補」と付記する**（例: ボイジャー省電力化）。物語の材料（危機・逆転・人間ドラマ）がその時点で揃い切っていないニュースを noteNeta に入れない
- 「進行中で結末が未確定」→ newsTopics（noteNeta は結末=逆転が確定した話に限る）
- 複数シートに**同等に強く**該当し、上記規則でも決められない場合のみ AskUserQuestion でユーザーに確認する（それ以外は自動判定して進む）

---

# STEP 3: 重複チェック

判定先シートの既存データを取得し、重複を確認する：

```
sheets_get_values(spreadsheetId=SS1, range="{シート}!A:{末尾列}")
```

- **ソース URL の一致**、または**同一の事象・発見を扱うタイトル・テーマ**があれば追加せず、既存行の No と内容を報告して終了する
- 類似ネタ（同じ探査機・同じ分野の別事象など）があれば、追加はするが完了報告で「類似: No.X」として言及する（例: ボイジャーのネタが複数あっても事象が違えば追加してよい）

---

# STEP 4: 行データの作成

STEP 3 で取得した既存データから採番し、シートの列構成に合わせて1行を作る。

**共通ルール**：

- **No**: 既存の No の最大値 +1（過去に重複採番の事例があるため、行数ではなく最大値から採番する）
- **ステータス**: 「未使用」
- **追加日**: 実行日の `YYYY-MM-DD`（JST）
- **数値・固有名詞は STEP 1 で取得した内容から正確に転記する。推測で補完しない**。原文に無い情報（停止した機器名など）は書かない
- 概要・内容欄には**発表日・発表機関を必ず含める**（後のファクトチェックの起点になる）

**シート別の記入要領**：

- **newsTopics**: カテゴリは既存値（インパクト強め / 知的驚き系 / 近未来・人類の挑戦系）から選ぶ。タイトルは「具体数字 or 意外性」＋「――」＋補足の形を目安に。ポイント欄には「なぜよーんの発信軸（執念・逆転・スケール感・日常接続）に効くか」と、既存ネタとの関係（類似・別ネタの区別）を書く
- **onePointNeta**: 冒頭1行案は「実は、〇〇は△△だ。」形式で具体数字入り。身近さ接続には読者が今日触れる物・感覚を書く。分野は 宇宙/物理/化学/生物/医学 から1つ
- **noteNeta**: 危機・逆転・人間ドラマの各欄は**出典で確認できた事実のみ**で埋める。埋まらない欄がある場合はその欄を空にせず newsTopics 行きを再検討する
- **thoughts**: ID は既存の `T{連番}` の最大値 +1。内容は1〜2文に整える

# STEP 5: シートへ追記

```
sheets_append_values(
  spreadsheetId=SS1,
  range="{シート}!A:{末尾列}",
  valueInputOption="USER_ENTERED",
  insertDataOption="INSERT_ROWS",
  values=[[...]]
)
```

---

# 完了報告

追加した行の全項目を表で提示し、以下を添える：

```
✅ {シート名} の {行番号} 行目に追加しました（No.{採番}）
```

- 判定理由を1行で書く（なぜこのシートか）
- 類似ネタ・留意点があれば添える（例: 結末未確定のネタは制作時に切り口の判断が要る、一次情報の URL、など）
- 制作時の使いどころが明確な場合は1行で示唆する（例: W003 の冒頭フック軸4 に使える数字がある）

## 禁止事項

- 原文に無い数値・事実で欄を埋めない（正確な転記のみ）
- 判定に迷いが無いのにユーザーへ質問しない／迷いが強いのに勝手に決めない
- 既存行の編集・削除はしない（追記のみ）
