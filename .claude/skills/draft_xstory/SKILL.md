あなたはX長文ストーリー投稿を自律的に制作するエージェントです。
**以下のSTEPをすべて順番に、自動的に実行してください。各STEPが完了したら、直ちに次のSTEPに進む。ユーザー入力を待たない。**

# STEP 1: ネタ在庫確認

以下を呼び出して未使用ネタを確認する：

```
sheets_get_values(spreadsheetId="1zCT0Kv0Q0qr83c6e_jQxUJeUQ1Y8iz0Zlm_0U5RMaEM", range="noteNeta!A:M")
```

取得した行の L列（ステータス）が「未使用」の件数をカウントする。

未使用が **5件未満** の場合は、次のSTEPの前にSTEP 1aを実行する。

## STEP 1a: ネタ補充（在庫5件未満のときのみ）

以下の手順でネタを5件収集し、Sheets に追記する。

1. 既存ネタ一覧を取得して重複を避ける（上記 sheets_get_values の結果を使用）

2. WebSearchで以下を検索し、**宇宙探査・科学史の「執念の物語」5件**を収集する：
   - 「宇宙探査 失敗 復活 ミッション」「spacecraft mission comeback failure recovery」
   - 「科学 発見 苦労 粘り強さ」「science discovery perseverance years」
   - 「JAXA NASA ESA ミッション 危機 克服」

3. 以下の条件をすべて満たすネタのみ採用する：
   - 実際に起きた出来事（人名・日付・場所が特定できる）
   - 「危機 → 逆転」の構造がある
   - 科学的見どころと人間ドラマの両方を含む
   - 科学的に正確（出典確認できる）
   - 約800文字のストーリーに展開できる

4. 採用ネタを以下で保存する（5件分実行）。No は既存の最大 No + 1 から連番で採番する：
   ```
   sheets_append_values(
     spreadsheetId="1zCT0Kv0Q0qr83c6e_jQxUJeUQ1Y8iz0Zlm_0U5RMaEM",
     range="noteNeta!A:A",
     values=[[No, タイトル案, 主人公(ミッション名), 時代・背景, 危機の内容, 逆転のポイント, 科学的見どころ, 人間ドラマの核心, 記事展開のヒント, 難易度, 出典メモ, "未使用", YYYY-MM-DD]]
   )
   ```

---

# STEP 2: ネタ選定

STEP 1 で取得した「未使用」ネタの中から、以下の優先順位で1件選ぶ：

1. 行番号が最も小さい（Noが小さい）「未使用」ネタを選ぶ
2. ただし直近5回の使用済みネタと同一ミッション名のものは除外する

選んだネタの以下の情報を記憶する：
- **【選定ネタ】**：No, タイトル案, 主人公(ミッション名), 危機の内容, 逆転のポイント, 科学的見どころ, 人間ドラマの核心, 記事展開のヒント, 出典メモ
- **【行番号】**：シート上の行番号（ヘッダー込みで何行目か）

---

# STEP 3: 投稿原稿作成

`/writer-xstory` スキルを呼び出す。引数として【選定ネタ】の情報を渡す：

```
引数: 「{タイトル案}」のストーリー投稿を作成してください。
主人公: {主人公(ミッション名)}
時代・背景: {時代・背景}
危機: {危機の内容}
逆転のポイント: {逆転のポイント}
科学的見どころ: {科学的見どころ}
人間ドラマ: {人間ドラマの核心}
展開のヒント: {記事展開のヒント}
出典: {出典メモ}
```

writer-xstory が返却した**【本文】**（約800文字のストーリー投稿）を記憶してSTEP 4へ進む。

---

# STEP 4: 品質チェック & トンマナ調整

## 4-1: ファクトチェック

STEP 3 で出力した【本文】に対して、/check-fact スキルを実行する。

- /check-fact が「チェック完了」を報告するまで結果を確認する
- チェック完了後、check-fact の「最終修正案」を記憶する
- check-fact の出力から **【チェックサマリー】**（「チェックサマリー」の見出し以降のテーブル）を抽出して記憶する

## 4-2: トンマナ調整

1. `$(git rev-parse --show-toplevel)/.claude/skills/writer-xstory/SKILL.md` を Read で読み込む
2. 4-1 で確定した「最終修正案」を writer-xstory のスタイルガイド（冒頭フック集・フックの構成ルール・本編冒頭の具体3点セット・執筆ガイドライン）と照合し、**事実は変えず**文体・口調のみ必要最小限調整する
3. 調整後のテキストを **【最終原稿】** として記憶する
4. 【チェックサマリー】の末尾に以下の行を追記して記憶し直す：
   `| トンマナ | — | （調整内容の要約、変更なしの場合は「スタイル適合」） | 調整あり／変更なし |`

**STEP 4 完了後、直ちに STEP 5 へ進む（ユーザー入力を待たない）**

---

# STEP 5: ネタ「使用済み」更新

STEP 2 で記憶した【行番号】を使い、L列のステータスを「使用済み」に更新する：

```
sheets_update_values(
  spreadsheetId="1zCT0Kv0Q0qr83c6e_jQxUJeUQ1Y8iz0Zlm_0U5RMaEM",
  range="noteNeta!L{行番号}",
  values=[["使用済み"]]
)
```

---

# STEP 6: メール下書き作成

STEP 2 の【選定ネタ】タイトル案・STEP 4 の【最終原稿】【チェックサマリー】を使用して、`mcp__claude_ai_Gmail__create_draft` ツールで Gmail 下書きを作成する。

1. 以下の形式で本文を組み立てる：
   ```
   [チェックサマリー]

   （STEP 4 で記憶したチェックサマリーテーブル）

   [/チェックサマリー]

   [投稿文]

   （STEP 4 で確定した【最終原稿】）

   [/投稿文]
   ```

2. 日時を JST（UTC+9）で取得する：
   ```bash
   TZ=Asia/Tokyo date '+%Y%m%d %H:%M:%S'
   ```

3. `mcp__claude_ai_Gmail__create_draft` ツールを呼び出す：
   - `to`: `["useakat@gmail.com"]`
   - `subject`: `"【Xストーリー】YYYYMMDD HH:MM:SS の原稿ができました"`
   - `body`: 上記で組み立てた本文

## 実行ルール

- **`mcp__claude_ai_Gmail__create_draft` ツールを使用する** — bash スクリプトではなく MCP ツールを直接呼び出す
- **成功判定はレスポンスに draft ID が含まれることで行う**
- **失敗した場合は、エラー内容をそのまま報告する**
