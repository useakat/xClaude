# writer-xstory

テーマ（引数）: $ARGUMENTS

## 目的
- テーマから、インプレッションが取れるX長文投稿を作成する。


## 手順

1../plan.md と ./brand.md を読み込む
2. 引数（$ARGUMENTS）にテーマや題材が指定されていれば、それをもとに投稿を作成する
3. 指定がなければ、テーマを確認する
4. `examples/buzzPostData.txt` を読み、既存投稿のトーンと重複を確認する
5. ./plan.md と brand.md を参考にして投稿本文を作成する
6. **字数・完結チェック**: 作成した本文が ./brand.md で指定された文字数にだいたい収まり、その投稿内で物語が完結している（中断型でない）かを確認する。超過時は本筋に不要な記述から削り、未完／中断型なら結末まで収める
7. チェックを通した本文を提示する


## 想定読者
**作業フォルダ（カレントディレクトリ）の `plan.md`（Target / Audience）を参照する。** その読者に向けて書く。
`plan.md` が無い場合は、宇宙・天文学の専門家ではない一般読者を想定し、「知らなかった！」「面白い！」と感じてもらえる内容を目指す。

## 投稿スタイル・執筆ガイドライン

**文体・トーン・余白・強調・NG 表現・字数・ハッシュタグなどのスタイルは、作業フォルダ（カレントディレクトリ）の `brand.md` を参照する。**
冒頭フックの作り方は下記「# 冒頭フック」を参照。

- 技術的事実は正確に
- 「なぜそうなるのか」という問いかけ構造を使うと読者の興味を引きやすい

## 冒頭フック

冒頭は **「2文フック」＋「本編冒頭の具体3点セット（日付・場所・状況）」** で始める。型・例・根拠は [`style/hook-patterns.md`](../../../style/hook-patterns.md)（①〜⑤のフック型＋「本編冒頭の具体3点セット」＋例）を参照する。長文ストーリーの1文目には ⑤語りかけ・口火型 が向く。


## 出力後の保存手順

本文を出力したら、以下のファイルに保存する：
- 保存先: **呼び出し元の制作仕様（spec 等）に指定があればそれに従う。指定が無い場合は `./draft/draft.md` に保存する。**
- 保存内容:
  ```
  # [タイトル案から選んだ1つ]
  
  [本文]
  ```
ユーザーへの確認は不要。保存後にファイルパスを1行だけ報告する。

## 禁止事項
- 特になし
