# writer-xstory

テーマ（引数）: $ARGUMENTS

## 目的
- テーマから、インプレッションが取れるX長文投稿を作成する。


## 手順

投稿は **「フォーカス決定 → 冒頭フック決定 → 本文作成」の3段階**でユーザーと相談しながら制作する。
各ステージで候補を提示し、ユーザーが決めてから次へ進む。**ユーザーに判断を求めたら、必ず回答を待ってから次のステージに進む（回答前に先へ進まない）。**

### 事前準備

1. カレントディレクトリの `plan.md` と `brand.md` を読み込む。
2. 入力（$ARGUMENTS）から**入力状況**を判定する：
   - **状況A（note記事あり）**: 題材の note 記事正本のパス（例 `../output/index.md`）が渡されている／参照できる。→ フォーカスは記事の「最も引きの強い一場面」。
   - **状況B（テーマ先行）**: note 記事はまだ無く、テーマ情報（主人公・時代背景・危機・逆転のポイント・科学的見どころ・人間ドラマ・展開のヒント・出典）が渡されている。→ フォーカスは「どの切り口を主役にするか」。
3. 状況Aなら正本記事を読み、事実・人物名・日付・装置の帰属・呼称を確定する（ここに無い事実を作らない）。`examples/buzzPostData.txt` を読み、既存投稿のトーンと重複を確認する。

### ステージ1: フォーカス決定（ユーザー相談）

1. フォーカス候補を3つ作る：
   - 状況A: 正本記事の中で「最も引きの強い一場面」を3つ。
   - 状況B: テーマ情報から「主役にする切り口」を3つ。
   - フォーカスの考え方は `brand.md`「### フォーカスと完結」（一点フォーカス＝要約しない）に従う。
2. 各候補に「何を入口にするか / なぜ引きが強いか / 投稿内でどこまで完結させるか」を1〜2行で添える。
3. `draft/focus-candidates.md` に3候補を保存する。
4. ユーザーに3候補を提示して1つ決めてもらう。**回答を待つ。**
5. 決定したフォーカスを `draft/focus-candidates.md` の末尾に「## 決定」として追記する。

### ステージ2: 冒頭フック決定（ユーザー相談）

1. 決定したフォーカスについて、`~/xClaude/style/hook-patterns.md` の**5型すべて**で冒頭フック候補を作る：
   - ①逆説・常識覆し型 ②知識提示型 ③ドラマ・場面描写型 ④問いかけ型 ⑤語りかけ・口火型
   - **各型3案ずつ＝計15案**。
2. 各案は「2文フック」で書く（1文目＝口火/つかみ、2文目＝主題を一目で伝える）。長文ストーリーの1文目には ⑤語りかけ・口火型 が向く。
3. `draft/hook-candidates.md` に型別の見出し付きで15案を保存する。
4. ユーザーに提示して1案決めてもらう。**回答を待つ。**
5. 決定したフックを `draft/hook-candidates.md` の末尾に「## 決定」として追記する。

### ステージ3: 本文作成＋字数・完結チェック

1. 決定した冒頭フックに続けて本文を作成する。フック直後に**本編冒頭の具体3点セット（日付・地名・状況）**を置く（`hook-patterns.md` 参照）。
2. `plan.md`（想定読者）と `brand.md`（文体・トーン・NG・字数・ハッシュタグ）に沿って書く。
3. **字数・完結チェック**: `brand.md` で指定された文字数にだいたい収まり、その投稿内で物語が完結している（中断型でない）かを確認する。超過時は本筋に不要な記述から削り、未完／中断型なら結末まで収める。
4. 本文を「## 出力後の保存手順」に従って保存し、ユーザーに提示する。


## 想定読者
**作業フォルダ（カレントディレクトリ）の `plan.md`（Target / Audience）を参照する。** その読者に向けて書く。
`plan.md` が無い場合は、宇宙・天文学の専門家ではない一般読者を想定し、「知らなかった！」「面白い！」と感じてもらえる内容を目指す。

## 投稿スタイル・執筆ガイドライン

**文体・トーン・余白・強調・NG 表現・字数・ハッシュタグなどのスタイルは、作業フォルダ（カレントディレクトリ）の `brand.md` を参照する。**
冒頭フックの作り方は下記「# 冒頭フック」を参照。

- 技術的事実は正確に
- 「なぜそうなるのか」という問いかけ構造を使うと読者の興味を引きやすい

## 冒頭フック（参照）

冒頭は **「2文フック」＋「本編冒頭の具体3点セット（日付・場所・状況）」** で始める。型・例・根拠は [`style/hook-patterns.md`](../../../style/hook-patterns.md)（①〜⑤のフック型＋「本編冒頭の具体3点セット」＋例）を参照する。フック候補の作成・決定はステージ2で行う。


## 出力後の保存手順

ステージ3で確定した本文を、以下のファイルに保存する：
- 保存先: **呼び出し元の制作仕様（spec 等）に指定があればそれに従う。指定が無い場合は `./draft/draft.md` に保存する。**
- 中間生成物（`draft/focus-candidates.md`・`draft/hook-candidates.md`）は各ステージで保存済み。
- 保存内容:
  ```
  # [タイトル案から選んだ1つ]
  
  [本文]
  ```
保存後にファイルパスを1行だけ報告する。

## 禁止事項
