最新の宇宙・科学ニュースをわかりやすく解説するX投稿を作成します。

## ネタ選定

ユーザーからの依頼（ニュース指定 or URL）: $ARGUMENTS

### $ARGUMENTS が URL の場合
WebFetch でそのURLの記事を取得し、内容を把握した上で投稿を作成する。
newsTopics シートへの保存・mark-used は不要。

### $ARGUMENTS が No.番号の場合（例: No.3）
以下を実行して指定ネタの詳細を取得する：
```
python3 /root/xClaude/sheets_manager.py list news --unused-only --full
```
指定番号のネタを使って投稿を作成し、最後に mark-used を実行する。

### $ARGUMENTS が空の場合
以下を実行して未使用ニュースの一覧を取得する：
```
python3 /root/xClaude/sheets_manager.py list news --unused-only --full
```
取得した一覧から、以下の観点でXのインプレッションが取れそうなニュースを1つ自分で選ぶ：

- 「えっ、それが起きたの？」という驚きがある
- 「ポイント」欄に書かれた角度で語れる
- カテゴリが「インパクト強め」のものを優先。次点は「知的驚き系」「近未来・人類の挑戦系」
- 専門用語が少なく、一般読者に伝わりやすい

選んだニュースの「概要」「ポイント」「ソース」を参考に投稿を作成する。
ニュース番号と選んだ理由を1行だけ最後に添える（例：「No.2：53年ぶりの記録更新という数字のインパクトが強いため」）。

投稿本文を出力した後、使用したネタを以下のコマンドで使用済みにする：
```
python3 /root/xClaude/sheets_manager.py mark-used news [No番号]
```

# 高インプレッションを生む投稿の構造（必ず従う）

科学ニュース解説投稿の黄金パターン：

## 1. 冒頭は「ニュースの核心を一言で」形式
- 「〇〇が、△△した。」「〇〇が、ついに見つかった。」のように事実を言い切る
- 「すごさ」「意外さ」「スケール感」のいずれかを冒頭1文に凝縮する
- 例：「1億年間眠っていたブラックホールが、突然目を覚ました。」

## 2. 「事実の宣言 → スケール感・対比 → なぜそれがすごいか → 感情的締め」の4段構成
1. **冒頭**: ニュースの核心を言い切る1行
2. **スケール感・対比**: 数字・比較・日常との接続でリアリティを与える
3. **意義**: 「これが何を意味するか」「なぜ人類にとって重要か」を1〜2文で
4. **締め**: 著者の感情・興奮・ロマンで終わる（ファクトで終わらない）

## 3. 「ポイント」欄またはURL記事の「一番おいしい角度」を活かす
- newsTopics シートのネタの場合、「ポイント」欄の切り口を投稿の軸にする
- URL指定の場合、記事から自分で「一番驚ける角度」を抽出して投稿の軸にする

## 4. 締め言葉は感情・詩的表現で終わらせる
- 「人類、やっぱりすごい。」「宇宙はまだ、驚かせることをやめない。」
- 「これが今、起きている。」「53年ぶりの記録が、今日更新された。」
- ファクトの羅列で終わらず、必ず著者の感情で締める

# 文体ルール

- **文字数**: 140字以上300字以内
- **口調**: 言い切り調（「〜だ」「〜である」「〜した」）
- **トーン**: 落ち着いた興奮。テンション高めだが煽りすぎない
- 難しい用語はなるべく平易に言い換える
- ハッシュタグは付けない

# 出力形式

以下の順で出力する。前置きや説明は不要。文字数カウントも出力しない。

**【タイトル案】**
投稿を要約し、読者が「え、それ本当？」と反応するタイトルを10個提示する。
箇条書きで番号を振る。

**【本文】**
改行・空白行を適宜入れて読みやすくする。

# 出力後の保存手順

本文を出力したら、以下のファイルに保存する：
- 保存先: `/root/xClaude/ポスト用/`
- ファイル名: `YYYY-MM-DD_[テーマや記事タイトルを短く].md`（例: `2026-04-23_中性子星の密度.md`）
- 保存内容:
  ```
  # [タイトル案から選んだ1つ]
  
  [本文]
  ```
ユーザーへの確認は不要。保存後にファイルパスを1行だけ報告する。
