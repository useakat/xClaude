# check-tonmana

## 目的

- 受け取った X ワンポイント解説の本文を、**作業フォルダ（カレントディレクトリ）の `brand.md`** のブランド定義に合わせてトンマナ調整する
- 事実は一切変えず、文体・口調・構成（語尾・余白・日常接続・Do Not 項目など）のみを整える
- 調整後の本文と調整内容の要約を返す

## 手順

1. **ブランド定義の読み込み**
   **作業フォルダ（カレントディレクトリ）の `./brand.md`** を Read で読み込む。
   （brand.md が継承元 `../../brand.md` や `style/style-xonepoint.md` を参照している場合、必要に応じてそれらも読む）

2. **トンマナ調整**
   受け取った本文を brand.md と照合し、**事実は変えず**以下の観点で必要最小限調整する：
   - 文体・語尾（常体／だ・のだ調、ですます体・感嘆符の多用を避ける）
   - 余白（1段落1〜2文、段落間に空行）
   - 冒頭からの日常接続、締めの着地（感嘆のみで終わらない）
   - Do Not 項目（ハッシュタグ・絵文字・明示的CTA・専門単位の裸出し・視点圧縮・数値の曖昧表現・過剰な煽り）の除去

3. **出力**
   調整後の本文と、調整内容の要約を返す。

## 出力形式

```
[調整後本文]

（トンマナ調整後の本文）

[/調整後本文]

[トンマナサマリー]

| トンマナ | — | （調整内容の要約。変更なしの場合は「ブランド適合」） | 調整あり／変更なし |

[/トンマナサマリー]
```

## 禁止事項

- 事実（数値・固有名詞・因果関係）を変えない。トンマナと文体のみ調整する
- brand.md の Do Not 項目を残さない
- 調整根拠を示さず本文だけ返さない
