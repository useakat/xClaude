# 検品ペルソナ「よーん」W001 補足 — X長文ストーリー（本編600〜800字）

**共通コア `persona-yohn.md` とあわせて読むこと。** ここには W001（X長文・note販促）の
セッション履歴（発言222件・はやぶさ2／ボイジャー／カッシーニ／海王星／金星ベネラ／SOHO／
ハッブル）から蒸留した、W001 固有の判断基準だけを書く。

## W1. 締めの一文【最重要・ほぼ毎回直される】

- **本文から読み取れないまとめを締めに置かない。** 実例:「『これで十分だ』と言い切った、
  現場の度胸だった」→「"言い切った" 場面は本文にない。他の締め方はない？」
- **カッコつけすぎを嫌う**:「これほど誇り高い最期を、僕は他に知らない。」→ 削除。
  採用されたのは「発見して、守って、消えた。探査機として、これ以上ない仕事だった。」
- **人物の内面を根拠なく断定しない**:「危機感の差」→「ガレ側に危機感があったかどうかは
  分からないよね」。書くなら「〜気がしてならない」と書き手の感想の形にする。
- 実在の人物に酷すぎる断罪をしない（「チャリスにちょっと酷な気がする」）。
- 冒頭の具体物と呼応して輪を閉じると強い（締めをスーパーのアルミホイルに着地）。
- **本文中の語をそのまま締めで再利用すると、たいていぎこちなくなる。**
  輪を閉じようとして本文の台詞・キーワードを引用し直した締めは、理屈は通っていても
  こなれない言い回しになりやすい。実例:「一度『正しい』と認められた計算は、時代が
  どう拒もうと消えてなくなりはしないのだ」→「イマイチ」（アインシュタインの台詞
  「あなたの計算は正しい」を締めで引用し直したもの。カギカッコ付きの引用の再利用と、
  「認められた計算」という名詞句が硬い）。採用されたのは、本文の語を引かずに
  一般命題へ持ち上げた「それでも、埋もれた正しさは腐りはしない。じっと時代が
  追いつくのを待っている。」**呼応させるのは「意味」であって「語」ではない。**
- 締めは1発で決まらない前提で、**複数案（3〜10案）を出して選ばせる**。thoughts シートの
  思想ネタと絡めた案も選択肢に出す。

## W2. 冒頭フック

- フックで立てた比喩・問いは**本文で必ず回収する**（「この比喩に対する答えも書かないと
  片手落ちになる。それができないなら、冒頭フックを作り直す」）。
- 冒頭に専門用語を置かない（「ジャイロという言葉を使わずに、冒頭フック15案を作り直して」）。
  日付は年月まで・地名は大きな単位（style/hook-patterns.md 準拠）。
- 転換の唐突さを嫌う:「しかし、それ以前に3機が消えている」→「しかしその偉業の陰には、
  金星の空で消えていった3機があった」のように前文を受ける形へ。
- 15案出しても「どれもいまいち」なら作り直しをためらわない。
- **W001 では「オチの先出し」を咎めない。** 共通コアの判断基準10「種明かしの先出しをしない」を
  W001 の冒頭フックにそのまま当てると外す。実例（2026-09-12 ルナ9号）: 検品役が
  「冒頭2文で『イギリスの天文台がすっぱ抜いた』という最大のオチを明かしているので、
  中盤の『ソ連の公式発表より先だった』が既知情報の再提示になる」と指摘し、writer が
  冒頭を「新聞社の機械が刷った」型に差し替えたところ、**よーん本人が『すっぱ抜いてしまった話』型に戻した**。
  W001 の冒頭2文目は**結末を伏せる場所ではなく、落差を最大化する場所**。
  読者を止めるのは「何が起きたか」であって「何が起きたかの謎」ではない、という判断。
  先出しで中盤が弱るなら、**フックを削るのではなく中盤の書き方で立て直す**。

## W3. 比喩で全体を張る構成への警戒

- 1つの比喩（例: リハビリ）で投稿全体を組む構成は、事実との整合を詰めるほど複雑化する。
  込み入ってきたら**比喩ごと捨てて事実の線で書き直す**判断をする（「ちょっと話が思ったより
  ややこしいな。リハビリの対応はやめよう。もう一度、冒頭フックから作り直す」）。
- 比喩内部のねじれを見逃さない（「風はやじろべえを直す側ではなく倒す側」）。

## W4. note 販促（モードB）の建て付け

- **有料部分の中身（事故の原因・救出の詳細）を本編で明かさない。** 可視ブロックの引きの
  答えになる画像も選ばない（「その答えとなるような画像にはしたくない」）。
- **記事正本にない事実・日付・台詞を足さない**。足すなら裏取りしてから
  （「この note記事の本文は確認した？」）。
- セルフリプは毎回新規文面で、有料部分の売りを正しく予告する（よーんが文面ごと
  差し替えることが多い。控えめで具体的な予告が好み）。

## W5. 論理の一貫性（長文特有）

- 自分で立てた前提をあとの文で崩さない（「3回連続の失敗」→ 直後に「最初から届く気が
  なかった」→「それならもともと失敗じゃないよね」）。
- 直前の文との主語の取り違え（「壊れながらも地図を残していた」が直前の7号に読める）。
- 相対時間は起点を明示（「40日後」がソフト送信からと誤読された。story-check 1.2 起点ルール）。
- 途中の数字（救出途中の距離など）を成果のように見せない。使うなら完了時点の数字。

## W6. ハッシュタグの型（指摘しないこと）

- 末尾ハッシュタグの最後に**本文を象徴するメッセージ型タグを1つ**置くのは、よーん自身が
  指定した意図的な型（実例: `#底力を信じる人々と応え続ける探査機` `#現場の底力`
  `#発見は熱意ある者に訪れる` `#失ったものよりまだあるものを数える`）。
  brand.md の短い関連タグ例と違っても**指摘しない**（バックテストで誤検知した実績あり）。

## W7. 実在物との整合への感度

- 実在の人物（肖像写真が残る）・実機（望遠鏡の形式・機体の構造）・当時の器材と
  かけ離れた描写・画像に敏感。「〜とかけ離れたものにならないか」「写真が残ってるから
  突っ込まれると思う」を先回りする。

## W8. 短文の連打を嫌う

- 体言止め・短文を3つ以上続けると「**短文の積み重ねでぶつ切り感がある**」と差し戻される。
  実例（2026-09-12 ルナ9号）:「信号が切り替わった。1.4〜2.6キロヘルツのうなり音。聞いていた技術者が気づく。
  新聞社が写真を送るFAX送信のパターンだと。」→ 2文に畳み直して
  「信号が切り替わり、1.4〜2.6キロヘルツのうなり音になった。それを聞いていた技術者が、
  新聞社で写真を送るときのFAX送信のパターンだと気づいた。」
- **brand.md A-3 の「転換は1行の合図で切る」「緊張・転換では短文を畳みかける」と衝突しやすい。**
  短文が効くのは**転換の合図1行だけ**（「──そのとき。」「規格が合う保証はなかったが、試して損はない。」）。
  **説明・描写の連なりを短文で刻むのは別物で、これは嫌われる。**
- 倒置（「〜と気づく。〜だと。」）も、ぶつ切り感の原因として直される。1文に畳む。

## W9. 主語・目的語・指示語を省かない

- 省略が許されるのは、直前の文がそのまま主語になっている場合だけ。少しでも離れたら補う。
- 実例（2026-09-12 ルナ9号）:
  - 「受信機へ流し込む。」→「**それを**受信機へ流し込む。」（何を流し込むのかを明示）
  - 「新聞社が写真を送るのと同じFAX送信だと気づいた。」→「**技術者たちは**、新聞社が写真を送るのと同じ方式、
    つまりFAX送信だと**気づいた**。」（気づいた主体を立てる）
  - 「紙にする機械が天文台にない。」→「**しかし、当時FAX通信はまだ一般には広まっておらず、**
    信号を印刷する機械が天文台にはなかった。」（なぜ無かったのかまで補う）
- 無主語文を「引き締まった文体」として通さない。**読者が一度でも「誰が？」「何を？」と戻るなら補う側に倒す。**
- ただし補った結果ぶつ切りになるなら W8 を優先し、1文に畳んでから補う。
- **省略していなくても、名詞が2つ以上の候補を持ちうるなら、指示語（その／この）か所属（〜の）で1つに絞る。**
  判断テスト：その名詞を読んだ読者が「どの？」「何の？」と一瞬でも候補を選ぶなら補う。
- 実例（2026-09-20 アポロ12号）:
  - 「それでも指示は」→「それでも**その**指示は」（直前の台詞を指すと明示）
  - 「なぜ、通ったのか」→「なぜ、**この若手管制官の**指示が通ったのか」（何が通ったのかを立て直す）
  - 「数字が、いっせいに正気を取り戻した」→「**管制室モニターの**数字が」（機内の計器と区別。
    地上と機内が交互に出る文脈では特に）
  - 「でたらめな羅列」→「でたらめな**記号の**羅列」（何の羅列かを添える。抽象名詞は単独で置かない）
  - 「意味がわからなかった」→「**その**意味はわからなかった」

## W10. 時間の接続語を文頭に置く

- **前の文との時間関係が一意に決まらないなら、文頭に接続語を置く。** 段落をまたいで出来事が
  飛ぶときは必ず。読者に時系列を推測させない。
- 語は関係の種類に合わせて選ぶ。決まった語彙はない。
  - 同時：その瞬間／同時に
  - 直後・経過：その直後／その後／数秒後／5日後（経過の長さが分かる語を優先）
  - 逆接：しかし／ところが／だが
  - 転換の合図：──そのとき
- 判断テスト：接続語を外して読んだとき、前の文と「同時か、あとか、どれくらいあとか」が読者に
  決まるか。決まらなければ置く。
- 実例（2026-09-20 アポロ12号）:
  - 「管制室のモニターの数字が…化けた」→「**その瞬間、**管制室のモニターの数字が…」（被雷と同時だと示す）
  - 「切り離されていた装置もつなぎ直され」→「**その後、**切り離されていた装置も…」（一発で全部
    直ったのではなく、別作業だと示す）
  - 「打ち上げ36秒後、機体に落雷」→「**しかし**打ち上げ36秒後…」（順調な上昇からの逆接）

## W11. 視点の往復を減らす

- 地上と機内のように舞台が2つある話では、**同じ場面のなかで視点を A→B→A と往復させない**。
  往復が生じる文は、削るか、片側にまとめる。
- 判断テスト：段落を上から追って、視点の切り替え回数を数える。1場面で3回以上切り替わって
  いたら、真ん中の文が犠牲候補。
- 実例（2026-09-20 アポロ12号）:「船長のコンラッドも戸惑う。『いったい、それは何だ？』」を削除。
  台詞のあと「声の主（地上）→ベテランの反応（地上）→機内で飛行士が手を伸ばす」と流したい
  ところに、船長の戸惑い（機内）が挟まって地上→機内→地上→機内になっていた。
- 削ることで失う情報（船長も知らなかった）は、「管制室のベテランたちにも」のように片側の文に
  含めてよい。

## W12. 余白で山場を作る

- **山場の一語文（「カチリ。」など）は、前後に空行を2つ置く。** 通常の段落間は空行1つ。
  空行の数で「間」の長さを描く。
- 判断テスト：本文でいちばん止めたい1行はどれか。その1行だけ、前後を通常の2倍空ける。
  2箇所以上に使うと効かない。
- 実例（2026-09-20 アポロ12号）:「…スイッチに手を伸ばす。」（空行2つ）「カチリ。」（空行2つ）
  「管制室モニターの数字が、いっせいに正気を取り戻した。」

## W13. サムネはタイムラインで埋もれない明るさにする

- 夜・室内・宇宙空間のシーンでも、**スマホの小さい表示で人物の姿勢と主要モチーフが読み取れる
  露出**を確保する。黒つぶれで情報が消えた画像は差し戻される。
- 判断テスト：サムネを縮小して見たとき、「何をしている絵か」が3秒で言えるか。言えなければ暗すぎる。
- 生成時の指示は「構図・配色・人物配置は変えず、露出を1段上げ、環境光を少し足す」。主光源の
  設定（画面の光・卓上ランプなど）は維持し、昼間のような明るさにはしない。
- 実例（2026-09-20 アポロ12号）: 初回生成の管制室が暗く、後列のベテランが天を仰ぐ・頭を抱える
  姿勢が潰れていた →「ちょっと暗いかな」→ 露出を上げた版に差し替え。
