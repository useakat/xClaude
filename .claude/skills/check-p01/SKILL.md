# check-p01

## 目的

- 受け取った X ワンポイント解説の本文を、brand.md の Writing Rules に基づく P01化チェックリスト6項目で 0〜10 に採点する
- 全項目8点以上になるまで、事実を変えず該当箇所のみ書き直す（最大5回ループ）
- 最終原稿とスコアサマリーテーブルを返す

## 手順

1. **ブランド定義の読み込み**
   **作業フォルダ（カレントディレクトリ）の `./brand.md`** を Read で読み込む。
   採点・書き直しに必要な材料（冒頭フック5軸の OK/NG 例・言い換え例・視点段落分け例・数値具体例・感覚語例・削る対象優先度リスト）は brand.md の Writing Rules 内で完結する。

2. **P01化スコアリングループ**
   brand.md の「Writing Rules（構成4段・文体・冒頭の日常接続・Do Not）」に基づく本文ルール5項目に **字数（項目6）** を加えた計6項目を **各 0〜10 の 10段階で採点**する。**全項目 8 点以上**なら合格。1項目でも 8 点未満なら該当箇所を書き直して再採点する。最大 **5 回** ループ。

   ### 採点基準

   項目1の冒頭フックは **5軸** で採点する。軸4（直感的比較数字）と軸5（パワーワード）が**両方揃わないと8点に届かない**（どちらか欠けると最大7点扱い）。

   | 項目 | 9〜10（優） | 7〜8（合格） | 5〜6（要改善） | 0〜4（不可） |
   |---|---|---|---|---|
   | 1. 冒頭フック | 全5軸（体接続動詞+読者代名詞+具体数字+直感的比較数字+パワーワード）が自然に揃う | 基本3軸＋軸4・5が**両方**揃う（専門単位なし＋パワーワードあり）← **8点の最低ライン** | 基本3軸は揃うが軸4か軸5のどちらかが欠ける（例: 専門単位のみ・パワーワードなし） | 抽象・受動・専門語のみ |
   | 2. 専門用語の言い換え | 全用語に自然な言い換え | ほぼ言い換え済、わずかに弱い箇所 | 半分くらい言い換えなし | 専門用語が裸で並ぶ |
   | 3. 視点対比の段落分け | 段落分け＋対比構文が明示的 | 段落分けあり、対比構文が弱い | 1文に圧縮 / 暗黙的切替 | 視点混在で読者が混乱 |
   | 4. 数値の具体性 | 全て具体、Before/After 明示 | ほぼ具体、わずかに曖昧 | 半分曖昧 | 曖昧表現多用 |
   | 5. 感覚語 | 動きの箇所に自然に効いている | 1つ以上、もう少し効かせられる | 感覚語が薄い | 専門的説明のみ |
   | 6. 字数 | 200〜260字（推奨レンジ中央） | 140〜300字（許容レンジ内） ← **8点の最低ライン** | 301〜350字 / 100〜139字 | 351字以上 / 99字以下 |

   ### ループ手順

   ```
   バージョン履歴 = [{"version": "V0", "text": V0, "scores": null, "total": null}]

   For i in 1..5:
       現行バージョン = 履歴の最後のバージョン
       現行バージョンの本文に対して 6項目を採点 → scores = [s1, s2, s3, s4, s5, s6]
       total = sum(scores)
       履歴の最後のバージョンに scores と total を記録

       If all(s >= 8 for s in scores):
           合格 → 現行バージョンの本文を 【最終原稿】 として確定
           ループ脱出

       Else:
           8 未満の項目を特定し、該当箇所のみ事実を変えずに書き直す
           新バージョン V{i} を履歴に追記
           ループ継続

   If ループが 5 回完走しても合格しなかった:
       履歴の中で total が最大のバージョンを 【最終原稿】 として採用
       警告フラグを立てる
   ```

   ### 書き直しルール

   - 事実は絶対に変えない（数値・固有名詞・因果関係）
   - 8 点未満の項目に関連する箇所のみピンポイントで修正
   - 既に 8 点以上の項目は触らない（破壊を防ぐ）
   - 項目6（字数）が8点未満の場合、brand.md の「削る対象優先度リスト（字数超過時）」に従って上から順に削る。既に8点以上の他項目を壊さないようピンポイントで削る

## 出力形式

```
[最終原稿]

（合格した／最高得点の本文）

[/最終原稿]

[スコアサマリー]

| P01化-項目1 | X/10 | （冒頭フックの観察ポイント） | 合格／要改善 |
| P01化-項目2 | X/10 | （専門用語の言い換え状況） | 合格／要改善 |
| P01化-項目3 | X/10 | （視点対比の段落分け状況） | 合格／要改善 |
| P01化-項目4 | X/10 | （数値の具体性） | 合格／要改善 |
| P01化-項目5 | X/10 | （感覚語の有無） | 合格／要改善 |
| P01化-項目6 | X/10 | （字数XXX字 / 削減回数N回） | 合格／要改善 |
| P01化-合計 | XX/60（N回目で合格 ／ 5回で不合格・最高得点版を採用） | — | 合格／不合格で採用（警告） |

[/スコアサマリー]
```

- スコアが初回から最終回で変化した項目は `X→Y/10` の形で記録する（例: `7→8/10`）。
- **5 回ループしても不合格だった場合は、ステータス列に必ず「不合格で採用（警告）」と明記し、出力の冒頭に警告行を入れる**：

  ```
  ⚠️ P01化チェック不合格（最高得点版を採用しました。人手レビュー推奨）
  ```

## 禁止事項

- 事実（数値・固有名詞・因果関係）を変えない。8点未満の項目に関連する箇所のみ書き直す
- 既に8点以上の項目を書き直して壊さない
- 採点根拠を示さずスコアだけ出さない
- 5回ループで不合格のときに警告を省略しない
