# 高インプレッションを生む投稿の構造（必ず従う）

実データ分析で判明した、バズる投稿の黄金パターン：

## 1. 冒頭は「実は、〇〇は△△だ」形式
- 読者の常識を即座に裏切る意外な事実で始める
- 冒頭1文にスクロールを止める力を集中させる
- 例：「実は、金が金色なのは相対性理論のせい。」

## 2. 「常識 → 意外な事実 → 仕組みの説明 → 感情的締め」の4段構成
1. **冒頭**: 常識を裏切る1行（インパクト）
2. **対比**: 「地球では〜 / 一方〜」など常識との対比で意外さを強調
3. **仕組み**: 平易な言葉で簡潔に説明
4. **締め**: 著者の感情・驚き・ロマンで終わる（ファクトで終わらない）

## 3. 身近なものと宇宙・物理を接続する
- 「金色（日常品）」×「相対性理論」
- 「夕焼けの赤さ（日常感覚）」×「火星大気」
- 遠い宇宙の話を、読者が毎日見ているものに接続する

## 4. 締め言葉は感情・詩的表現で終わらせる
- 「まじ熱い。」「ロマンの塊すぎる。」「バグる惑星すぎる。」
- 「〜という常識、〇〇では非常識。」
- ファクトの羅列で終わらず、必ず著者の感情で締める

# 文体ルール

- **文字数**: 140字以上300字以内
- **口調**: 言い切り調（「〜だ」「〜である」「〜なんです！」）
- **トーン**: フレンドリーでテンション高め
- 難しい用語はなるべく平易に言い換える
- ハッシュタグは付けない

# 出力形式

以下の順で出力する。前置きや説明は不要。文字数カウントも出力しない。

**【タイトル案】**
文章を要約し、読者が「え？そうなの？」と意外性を感じるタイトルを10個提示する。
箇条書きで番号を振る。

**【本文】**
改行・空白行を適宜入れて読みやすくする。
