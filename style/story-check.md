# 物語型推敲チェックリスト（story-check）

**版**: 1.0
**更新日**: 2026-07-11

物語型の書き物（W001 / W002 / Z01 の物語型ソース）が生成後に必ず通すチェックリスト。
各プロジェクトの `brand.md` 採点基準にある「物語の論理整合」項目は、本ファイルの5項目を判定基準として使う。

> 由来: 2026-07-11 の Z01 制作セッションで、ユーザー推敲により繰り返し指摘されたパターンを原則化したもの。

## チェック項目

1. **【時系列】** 出来事が因果の順（発端 → 内容 → 障害 → 不屈 → 帰結）に並んでいる。科学説明を挿入したことで、話の流れや因果の鎖の繋がりがわかりにくくなっていない。
2. **【行動とテーマの整合】** 主人公の行動描写がテーマと矛盾しない（例:「研究を離れた」という描写は「自分を信じ抜いた」というテーマと矛盾して読める）。
3. **【接続詞の受け先】** 「それでも」「だが」「しかし」の受け先が直前の文にある。間に別の話題（科学説明など）を挟まない。
4. **【史実帰属】** 史実人物の認識と現代の知識を混同しない。人物が当時知り得なかったこと（後年の発見・概念）を人物の考えとして書かない。現代知識はナレーション（地の文）として区別できる場合のみ使う。
5. **【結末の完結】** 読者が「で、どうなったの？」と思う欠落がない。ただし締めの余韻を食うほどの詳細は入れない（詳細より余韻を優先）。

## 採点への組み込み（/check-brand 向け）

- 5項目のうち **1つでも明確に該当したら、その採点項目は6点以下**とし、該当箇所を書き直す。
- 全項目クリアで8点以上（違和感が残るが明確な違反ではない場合は7〜8点）。
