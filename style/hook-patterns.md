## ① 逆説・常識覆し型（最安定・量産可）

**旧常識を「」で括って提示 → 否定・裏切りで返す。** よーんの「直感がひっくり返る面白さ」と直結する主力型。

| 構文テンプレート | 実例 | 物理・宇宙への応用例 |
|---|---|---|
| 「〇〇」——その常識が、〜覆された | 「Macはウイルスに強い」——その常識が覆されました | 「光より速いものはない」——その常識は、ある条件で崩れます |
| 「〇〇」が、〜書き換えられようとしています | 「哺乳類は四肢を再生できない」——その常識が書き換えられようとしています | 「真空は何もない空間」——その定義が書き換えられようとしています |
| 〇〇は「△△」だとずっと教わってきました。ところが〜 | 心臓病は「血管の詰まり」だと教わってきました。ところが〜 | 私たちは「原子は最小の粒」だと教わってきました。ところが〜 |
| 「△△」が通じない〇〇があります | 「甘いものは血糖値を上げる」が通じない果物があります | 「熱いものは冷める」が通じない天体があります |
| 〇〇は、単なる△△ではありません | バーボンの在庫問題は、単なる売れ残りではありません | ブラックホールは、単なる「穴」ではありません |
| 〇〇が△△なのは「□□」からではありません。〜からです | ハチミツが危険なのは菌を「殺せない」からではない。「増える」からです | 夜空が暗いのは、星が少ないからではありません |
| 〇〇って、実は△△だった | 自転車の変速って、実は使われていない機能だった | 「重さ」って、実は2種類あった |
| 「〇〇」。（引用符＋句点で止め予告だけ） | 「表面は滑らかなほど空気抵抗は減る」。 | 「時間は誰にとっても同じ速さで進む」。 |

## ② 知識提示型

**「あなた」を主語に、知らない事実を断定で突きつける。** 身近さへの接続が肝。

| 構文テンプレート | 実例 | 物理・宇宙への応用例 |
|---|---|---|
| あなたが毎日使っている「〇〇」が、〜 | あなたが毎日使っている「1秒」の定義が、63年ぶりに書き換えられます | あなたが毎日使っている「重さ」は、月では6分の1になります |
| あなたの〇〇には、いま△△が起きています | あなたの細胞の表面には、いま「砂糖の膜」が張り巡らされています | あなたの体には、いま毎秒1兆個のニュートリノが貫通しています |
| 〇〇しても、△△は□□しません | 配偶者が亡くなっても、義父母との関係は自動では切れません | 光源を止めても、その光は宇宙を進み続けます |
| 〇〇だということを、多くの人は知りません | 冷凍倉庫がマイナス25度だということを、多くの人は知りません | 宇宙にも「音」が存在することを、多くの人は知りません |
| 日本人の〇人に1人が、△△だと認識しています | 4人に1人が、刺身の短冊は海で泳いでいると認識しています | — |

## ③ ドラマ・場面描写型

**場所・時間・人物・動作だけ提示し、結末を伏せる。小説の一行目。** 科学者の物語起点と相性が良い。固有名詞・結論は冒頭で出さない。

| 構文テンプレート | 実例 | 物理・宇宙への応用例 |
|---|---|---|
| 〔時間〕の〔場所〕。〔人物〕が〔動作〕した。「〜」 | 早朝の金山駅。警察官が、男の顔を見て直感した。「あの顔、もしかして……」 | 1986年1月28日、フロリダ。技術者の一人だけが、打ち上げに反対していた |
| 〔人物〕が、〔状況〕した。（主語を絞り事実だけ） | 弁護士が、勾留中の依頼人に頼まれて自宅を訪問した | ある計算手が、惑星の軌道に1分のズレを見つけた |
| 〔数字〕、〔状態〕。（年齢・年数で人生を圧縮） | 53歳、日本を離れて25年 | 33年、たった一度の観測のために |
| 〔誰か〕にこう教わりました。（情報をゼロにして引く） | 先輩にこう教わりました | 恩師に、こう問われました |

## ④ 問いかけ型

**身近な対象＋「考えたことはありますか／ご存知ですか」で手を止めさせる。**

| 構文テンプレート | 実例 | 物理・宇宙への応用例 |
|---|---|---|
| 〇〇の理由、考えたことはありますか | 神社に馬がいる理由、考えたことはありますか | 夜空が暗い理由、考えたことはありますか |
| 〇〇を見たことはありませんか | 通路に縄で縛られた小石が置いてあるのを見たことはありませんか | 月がいつも同じ面を向けているのに気づいていましたか |
| 〇〇をご存知ですか／でしょうか | ラスベガスの「スフィア」をご存知ですか | 宇宙でいちばん丸い天体をご存知ですか |
| あなたは今日、〇〇していませんか | あなたは今日、右手でスマホを持っていませんか | あなたは今日、何度「重力」に逆らいましたか |
| なぜ〇〇なのに、△△なのでしょうか | 受信料が落ちているのに、なぜ督促は10倍に増えたのでしょうか | 真空なのに、なぜ宇宙は冷えないのでしょうか |
| 〔逆説的事実〕。この〇〇、考えたことはありますか | 雪は白いのに、古い氷は青い。この逆説、考えたことはありますか | 氷は水に浮く。この当たり前、なぜか考えたことはありますか |

## ⑤ 語りかけ・口火型（会話的なつかみ）

**読者に直接話しかけ、熱量と親密さで一気に引き込む口火。** 長文ストーリーの1文目に向く。1文目にこの口火を置き、2文目で「〇〇な話。」「〇〇の物語。」と主題を一目で伝える（writer 系スキルの「2文構成ルール」）。①〜④の IMP 帰納4型とは別系統の、語り口ストックとして使う。

- これ何度も言って悪いけど。
- これ炎上するなら燃えていいんですが、
- 月曜の夜だから言う。
- ちょっとこれは聞いてほしい！
- これ、ヤバすぎる話なんだけど聞いてくれ——
- 〜の話がヤバすぎる。
- ちょっと言い方キツイですけど、
- これ、勘違いしてた！
- 結論から言います。
- これ、かなり震える話なんだけど聞いてほしい。

## 横断技法（全型に効く）

1. **引用符「」で意外な一語を強調する** — 旧常識・キーワードを括ると視線が止まる
2. **数字で一気にスケールを提示する** — 「63年ぶり」「4人に1人」「毎秒1兆個」
3. **①逆説型 ×④問いかけ型は組み合わせ可** — 逆説的事実を提示してから問いかける構成が最も汎用性が高い（例：「雪は白いのに、古い氷は青い。考えたことはありますか。」）

## フック直後：本編冒頭の具体3点セット（長文ストーリー向け）

長文ストーリーでは、フック（2文）の直後に本編冒頭で **日付・地名・状況** の3要素を置き、読者を「物語が始まる場面」に一瞬で連れて行く。

- **日付**（年・月単位の具体）：「1990年4月」「2018年8月のある朝」
- **地名・場所**（具体）：「ヒューストンの管制室」「太平洋上空400km」
- **状況**（誰が・何をしていた）：「20人の技術者が画面を見つめていた」

実データ：SOHO（72,633 IMP）も「2026年に成功した衛星救出ミッション」のように年・主体・出来事が冒頭で立ち上がっていた。抽象から始まる物語（「むかし、ある研究者が…」型）はIMPが伸びにくい。

フック→本編冒頭の例：
> 返事は来なかった。それでもメッセージを送り続けた。
> 宇宙で凍りつき音信不通になった衛星を、遠い地球から救い出した、静かに熱い話。

## 避けるべき冒頭（IMPが伸びにくい）

- 抽象から始まる物語（「むかし、ある研究者が…」）
- 結論・固有名詞を先に出してしまう（種明かしが冒頭にあると続きを読む動機が消える）
- 日常への入り口が弱い、専門用語からの開始
