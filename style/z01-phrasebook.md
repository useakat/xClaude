# Z01 語彙の好み帳（phrasebook）

**版**: 1.1
**更新日**: 2026-08-06

よーんの推敲で確定した語彙・言い回しの好み。Z01 の writer は**生成前に本ファイルを Read** し、「好みの方向」に寄せ、「避ける」列に該当する表現を出さない。

## 運用ルール

- **目安100行**。場面カテゴリ別の見出しで整理する。
- 同じ場面の好みが更新されたら**追記でなく上書き**（最新を正とする）。
- 個別の語例が同カテゴリに3つ溜まったら**「原則」に昇格して圧縮**する（例: 個別の動詞置換が並んだら「達成は動きのある動詞で書く」の1行にまとめる）。
- **固定フレーズ集にしない**。同じ言い回し（特に締め句）の連続使用は避ける（量産感・既出感の防止。plan.md の Risks 参照）。
- 更新は対話セッションでよーんの修正が入ったとき、セッションの締めに差分を提示し、**承認を得て追記・commit** する。無人実行（routine）は読むだけで更新しない。

## 原則（個別例から昇格したもの）

- 対象を明瞭に：動詞だけで済ませず、何を曲げないのか・何に行き着いたのかを一語添える（「自説を曲げず」「計算結果に行き着いた」）。
