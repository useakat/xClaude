# style-note-story

宇宙・物理を題材にした「執念の物語」型 note 記事の文体・口調スタイル。
`.claude/skills/writer_note-story/examples/` の4記事（カッシーニ／ニューホライズンズ／ボイジャー／海王星発見）から抽出した一貫パターン。

> 共通の人格・想定読者・言葉遣い・NG 表現は [`brand.md`](../brand.md) を参照。
> 本ファイルには note 執念の物語型に固有のルールのみ記載する。

---

## 文体

**常体（だ・だった・である）を使う。ですます調・敬語は使わない。**
同じ語尾を3文以上続けない。`〜だ` `〜だった` を主軸に、要所で `〜である` `〜だろうか` `体言止め` を混ぜる。

```
[弱い] 探査機は信号を送ってきていた。地球はそれを受け取っていた。チームは喜んでいた。
[強い] 探査機は、確かに信号を返していた。地球はそれを受け取った。チームは沸いた。
```

## 書き出しフック例

冒頭に置くと効く一人称的フック：

- 「これ、かなり震える話。」
- 「これ、かなり痺れる話なんだけど聞いてほしい。」
- 「もっと知られていい話なんだけど、」
- 「ここからの話が、めちゃくちゃ熱い。」
- 「ここがまた震える。」

## 文章構造のクセ

### 短文を畳みかけてリズムを作る

**緊張・転換・盛り上がり**の箇所は、短文を3〜5本連打する。読点を控えめにし、句点で切る。

```
そのときだった。
14時11分、探査機からの信号が途絶えた。
管制室に響いた「見失った！」の一言は、想像以上に重かった。
```

### 「である」調をクライマックスに刺す

クライマックスや意味の宣言は「〜のである」で締めると語りの強度が一段上がる。

- 「凍りついた沈黙の奥で、SOHOは確かに生き延びていたのである」

### 三段リスト型の畳み込み

困難・条件・選択肢を**3つ並べる**と説得力が出る。

### 「ここで普通はこう思う」型の読者代弁

読者が抱きそうな疑問を**自分が先回りして書く**ことで距離を縮める。

### 逆接の重ね打ち

「だが」「ところが」「しかし」「でも」を要所で使い、流れを反転させる。1段落に1つあると物語が動く。

### 短文太字での区切り

セクションの結論・転換点を**短文＋太字**で1行に置く。

- **成功だった。**
- **そのスピンが、希望になった。**

## 表現技法

### 装置・ミッションの擬人化

探査機・装置を**生き物のように**書く。これがドラマ性の核になる。

- 「探査機は『死んだふり』していた」
- 「探査機は壊れたのではない。『生き延びる』ことを選んだ」

### 比喩で温度を上げる

- 「凍りついた心臓に、もう一度血を通わせるように」
- 「見えない犯人が残したほんの小さな足跡だけを見て、身長も体重も逃走ルートも現在地も割り出すみたいなことだ」

### 当事者の名前と発言を出す

組織・プロジェクト名だけで終わらせず、**個人名と判断・発言**を入れる。

### 「意味の宣言」型のまとめ

事実の直後に「これは、単なる X ではなかった。Y だった」型でテーマを言い切る。

### 体言止めで余韻を残す

- 「青白く生々しい傷跡。」
- 「ほんの小さな乱れ。見落としてもおかしくない程度の、微妙なズレ。」

## 専門語の扱い

**直前か直後に必ず噛み砕いた説明を入れる。**

| NG | OK |
|---|---|
| 3軸姿勢制御を失った | 自分がどちらを向いているか、わからなくなった |
| ヒドラジンの粘性が急上昇しスラスターに流れなくなる | 燃料が凍りついて、エンジンに流れなくなる |

翻訳の三手法：
1. **実体に置き換える**：「方向センサー」「燃料」「機体の記憶」
2. **動作で説明する**：「向きがわからなくなった」「凍りついて流れなくなる」
3. **身近な比喩で重ねる**：スマホ・心臓・呼びかけ等、生活感のある対象に翻訳

---

## 物語のドライブ装置（必ず使う）

各 H2 セクションに**最低1つ**、物語の核となるセクションには**3つ以上**組み込む：

1. 比喩で温度を上げる
2. クライマックスは短文＋太字で刻む
3. 要所で「である」調を混ぜる
4. 当事者のセリフ・感嘆を入れる
5. 「意味の宣言」でテーマを明示する
6. 次セクションへの橋渡しを H2 末尾に置く（完結させきらない）

---

## 論理の橋（飛躍させない）

```
[NG] 通信が途絶えた → 機体は凍りついた
[OK] 宇宙空間で機体が沈黙するということは、電波を発する力さえ失ったことを意味する。
     電力を失えばヒーターも止まる。
     極低温の闇が、そのまま機体を蝕んでいく。
```

---

## 表記ルール

- `""` は使わず、`「」` または太字を使う
- 太字は多用しすぎない。各節で本当に強調したい部分のみ
- 1段落 1〜2文を基本にする
- 段落間は必ず空行

---

## NG（note 固有）

- 専門用語を無翻訳で残すこと（直後の噛み砕きがない場合）
- 当事者を出さずに組織名・プロジェクト名だけで物語を進めること
- 想像で当事者の発言・心情を捏造すること（出典のないセリフは書かない）
- 「すごい」「とても」「非常に」などの中身のない強調語の連発
- 結論を引き延ばす冗長な前置き
- 体言止め・「である」調・短文太字を多用すること（要所だけに使う）

※ その他の共通 NG（ハッシュタグ・数値のぼかし等）は brand.md を参照。

## 出力前セルフチェック

- [ ] 冒頭1行で読者に「えっ？」「続き読みたい」と思わせているか
- [ ] 各 H2 セクションに物語のドライブ装置が1つ以上あるか
- [ ] 専門用語が直後に噛み砕かれているか
- [ ] 数値・年月日・人物名が具体的に入っているか
- [ ] 当事者の固有名詞と発言・判断が出てくるか
- [ ] 段落が1〜2文に収まっているか
- [ ] 同じ語尾が3連続していないか
- [ ] 比喩が冒頭〜中盤〜終盤に最低1つずつあるか
- [ ] 想像で書いたセリフ・心情がないか（出典で裏が取れているか）
- [ ] 締めが「意味の宣言」「感情」「未来へのまなざし」で終わっているか
