# style-note-story

宇宙・物理を題材にした「執念の物語」型 note 記事の文体・口調スタイル。
`.claude/skills/writer-note/examples/` の4記事（カッシーニ／ニューホライズンズ／ボイジャー／海王星発見）から抽出した一貫パターン。

skill が本文を生成するときに本ファイルを参照することで、語り口・距離感・テンポを揃える。

---

## 1. 語り手の人格

- **「むずかしい話を、興奮しながら友達に話している人」** がベース人格
- 専門家ぶらない。上から目線にしない。一方で、知識量と熱量は隠さない
- 自分が興奮していることを率直に書いてよい（「これ、かなり震える話」「めちゃくちゃ熱い」）
- 読者は「専門外の同年代の知人」。敬語ではなく、丁寧な常体（「〜だ」「〜だった」「〜である」）

### 採用してよい一人称的フック例（冒頭で使うと効く）

- 「これ、かなり震える話。」
- 「これ、かなり痺れる話なんだけど聞いてほしい。」
- 「もっと知られていい話なんだけど、」
- 「ここからの話が、めちゃくちゃ熱い。」
- 「ここがまた震える。」

---

## 2. 文体の核

### 2-1. 言い切り中心、語尾は変化をつける

`〜だ` `〜だった` を主軸に、要所で `〜である` `〜だろうか` `体言止め` を混ぜる。同じ語尾を3文以上続けない。

```
[弱い] 探査機は信号を送ってきていた。地球はそれを受け取っていた。チームは喜んでいた。
[強い] 探査機は、確かに信号を返していた。地球はそれを受け取った。チームは沸いた。
```

### 2-2. 短文を畳みかけてリズムを作る

特に**緊張・転換・盛り上がり**の箇所は、短文を3〜5本連打する。読点を控えめにし、句点で切る。

```
そのときだった。
14時11分、探査機からの信号が途絶えた。
管制室に響いた「見失った！」の一言は、想像以上に重かった。
```

### 2-3. 段落は1〜3文。空行を厚めに取る

note のスマホ閲覧を意識した改行密度。情景の転換・強調のあとは特に空行を入れる。

### 2-4. 「である」調を盛り上がりに刺す

クライマックスや意味の宣言は「〜のである」で締めると語りの強度が一段上がる。

- 「凍りついた沈黙の奥で、SOHOは確かに生き延びていたのである」
- 「これは、単なる通信の回復ではなかった。それは、『まだ終わっていない』という宣言だった」

---

## 3. 文章構造のクセ

### 3-1. 三段リスト型の畳み込み

困難・条件・選択肢を提示するとき、**3つ並べる**と説得力が出る。

```
距離は一気に伸びる。時間もかかる。電波は弱くなり、機械は長く生き延びなければならず、ほんの小さな不調さえ致命傷になりうる。
```

```
本当にそこまでして近づく価値があるのか。
もし何もなかったらどうするのか。
他の観測の機会を奪ってまで賭ける理由があるのか。
```

### 3-2. 「ここで普通はこう思う」型の読者代弁

読者が抱きそうな疑問を**自分が先回りして書く**ことで距離を縮める。

```
ここで普通はこう思う。
「観測ミスでは？」
「計算がまだ不完全なのでは？」
「ニュートン力学が遠方では崩れるのでは？」
でも、そうじゃないかもしれないと考えた若者達がいた。
```

### 3-3. 逆接の重ね打ち

「だが」「ところが」「しかし」「でも」を要所で使い、流れを反転させる。1段落に1つあると物語が動く。

### 3-4. 短文太字での区切り

セクションの結論や転換点を、**短文＋太字**で1行に置く。

- **成功だった。**
- **そのスピンが、希望になった。**
- **失敗が、機体を進化させた。**

### 3-5. 数字・固有名詞は具体的に置く

「遠い」「すごい」だけで済まさない。**距離・時間・人数・コスト・年月日**を入れて重みを出す。

- 「48億キロの彼方、片道4.5時間の通信遅延」
- 「9年半の航海も、7億ドル規模の計画も」
- 「175年に一度の機会」
- 「1845年、彼は自分の計算結果を、イギリス天文学界の重鎮ジョージ・エアリーや、ケンブリッジ天文台長ジェームズ・チャリスに伝える」

## 4. 表現技法

### 4-1. 装置・ミッションの擬人化

探査機・装置を**生き物のように**書く。これがドラマ性の核になる。

- 「探査機は『死んだふり』していた」
- 「ニューホライズンズは、もはや家族に近かった」
- 「自分でバックアップコンピュータを起動し、セーフモードに入っていた」
- 「『助けて』という声だった」
- 「探査機は壊れたのではない。『生き延びる』ことを選んだ」

### 4-2. 比喩で温度を上げる

抽象を具体に翻訳する比喩を要所に置く。距離が遠い概念ほど比喩が効く。

- 「凍りついた心臓に、もう一度血を通わせるように」
- 「沈黙しか返ってこない宇宙の向こうに向かって、何度も呼びかける」
- 「巨大な猛獣が氷の大地を引き裂いたような、青白く生々しい傷跡」
- 「見えない犯人が残したほんの小さな足跡だけを見て、身長も体重も逃走ルートも現在地も割り出すみたいなことだ」
- 「ゲームのコース修正みたいに気軽にはできない」

### 4-3. 当事者の名前と発言を出す

主役は「人間」。組織やプロジェクト名だけで終わらせず、**個人名と判断・発言**を入れる。

- 「運用部門リーダーのアリス・ボーマンは復旧に向けて動き出した」
- 「磁場計測チームのリーダー、ミシェル・ドハーティは、土星の磁場にほんのわずかな『ゆがみ』を見つけた」
- 「『見失った！』の一言は、想像以上に重かった」

### 4-4. 「意味の宣言」型のまとめ

事実を書いた直後に、**「これは、単なる X ではなかった。Y だった」**型でテーマを言い切る。

- 「これは、単なる通信の回復ではなかった。それは、『まだ終わっていない』という宣言だった」
- 「『行くと決まったから作った』のではない。彼らが情熱を傾けて作り上げたのは、予算もついていない、約束もされていない、そんな未来への準備ができている探査機だった」

### 4-5. 体言止めで余韻を残す

情景描写・印象的な一文で体言止めを使うと、絵が読者の頭に残る。

- 「青白く生々しい傷跡。」
- 「3日間におよぶ熱いデスマーチ。」
- 「ほんの小さな乱れ。見落としてもおかしくない程度の、微妙なズレ。」

## 5. 専門語の扱い

### 5-1. 必ず即座に翻訳する

専門用語をそのまま残すのは、**直前か直後に必ず噛み砕いた説明**がある場合だけ。

| NG | OK |
|---|---|
| 3軸姿勢制御を失った | 自分がどちらを向いているか、わからなくなった |
| ジャイロへの依存を下げ星追尾センサーで姿勢を制御 | 星を目印にして自分の向きを測る方式に切り替えた。夜空の星の位置はどの方向から見ても変わらない |
| ヒドラジンの粘性が急上昇しスラスターに流れなくなる | 燃料が凍りついて、エンジンに流れなくなる |
| Emergency Sun Reacquisition (ESR) | 太陽の方向を見失ったとき、自動で向き直す『緊急モード』 |

### 5-2. 翻訳の三手法

1. **実体に置き換える**：「方向センサー」「燃料」「機体の記憶」
2. **動作で説明する**：「向きがわからなくなった」「凍りついて流れなくなる」
3. **身近な比喩で重ねる**：スマホ・心臓・呼びかけ等、生活感のある対象に翻訳

---

## 6. 物語のドライブ装置（必ず使う）

note 記事は「解説」ではなく「物語」として届ける。各 H2 セクションに**最低1つ**、物語の核となるセクションには**3つ以上**組み込む。

1. **比喩で温度を上げる**
2. **クライマックスは短文＋太字で刻む**
3. **要所で「である」調を混ぜる**
4. **当事者のセリフ・感嘆を入れる**
5. **「意味の宣言」**でテーマを明示する
6. **次セクションへの橋渡し**を H2 末尾に置く（完結させきらない）

---

## 7. 論理の橋（飛躍させない）

劇的な比喩や因果関係を提示するとき、読者が知らない一段でも飛ばすと文章が破綻する。**必ず橋を渡す**。

```
[NG] 通信が途絶えた → 機体は凍りついた
[OK] 宇宙空間で機体が沈黙するということは、電波を発する力さえ失ったことを意味する。
     電力を失えばヒーターも止まる。
     極低温の闇が、そのまま機体を蝕んでいく。
```

橋が必要な場面：
- 状況説明から劇的な比喩への移行（「沈黙→凍結」など）
- 物理現象の因果（A だから B）
- 異なる物理量・時間スケールの比較（光と粒子は速度が桁違い、など）
- 専門知識を前提とした結論

---

## 8. 表記ルール

- `""` は使わず、`「」` または太字を使う
- かぎ括弧付きの語句を強調する場合は、かぎ括弧自体は太字にしない（`**「語句」**` ではなく `「**語句**」`）
- 太字は多用しすぎない。各節で本当に強調したい部分のみ
- 強調対象の優先度：その段落の結論 > 印象的な歴史的意義 > 数値や到達点の重み > 記事全体の主題を要約する一文
- 1段落 1〜2文を基本にする
- 段落間は必ず空行
- 同じ語尾を3文以上続けない

---

## 9. 禁止事項

- 専門用語を無翻訳で残すこと（直後の噛み砕きがない場合）
- 当事者を出さずに組織名・プロジェクト名だけで物語を進めること
- 数値・年月日・固有名詞をぼかすこと（「最近」「巨額」「ある天文学者」など）
- 想像で当事者の発言・心情を捏造すること（出典のないセリフは書かない）
- 「すごい」「とても」「非常に」などの中身のない強調語の連発
- 結論を引き延ばす冗長な前置き
- 体言止め・「である」調・短文太字を「使えば効く」と思って多用すること（**節の起伏に合わせて要所だけ**）

---

## 10. 出力前セルフチェック

本文を書き終えたら、以下に当てはまらないか確認する：

- [ ] 冒頭1行で読者に「えっ？」「続き読みたい」と思わせているか
- [ ] 各 H2 セクションに物語のドライブ装置（比喩／太字短文／である調／セリフ／意味の宣言／橋渡し）が1つ以上あるか
- [ ] 専門用語が直後に噛み砕かれているか
- [ ] 数値・年月日・人物名が具体的に入っているか
- [ ] 当事者の固有名詞と発言・判断が出てくるか
- [ ] 段落が1〜2文に収まっているか
- [ ] 同じ語尾が3連続していないか
- [ ] 比喩が冒頭〜中盤〜終盤に最低1つずつあるか
- [ ] 想像で書いたセリフ・心情がないか（出典で裏が取れているか）
- [ ] 締めが「事実」ではなく「意味の宣言」「感情」「未来へのまなざし」で終わっているか
