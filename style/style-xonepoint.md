## 想定読者（データ実証済み）

メインターゲット：**P01 — 物理・科学に憧れる30〜40代文系会社員**

- 数式は挫折したが、知的好奇心は強い
- 「あの常識、実は違うんだよ」という驚きを欲している
- 専門用語の壁が低く、日常体験への接続で理解する

判断基準：
- ネタ選定時、「P01がスマホで通勤中に読んで反応するか？」を自問する

## P01化チェックリスト（本文ルール）

原稿生成時、以下の5項目を本文全体に適用する。冒頭フック・締めのルール（既存）と合わせて、本文中盤の説明も P01 が挫折せずに読み切れる平易さにする。

### 1. 冒頭フックは5軸で評価する。軸4・軸5が両方揃わないと文系読者には刺さらない

- **軸1 体接続動詞**: 貫く / 触れる / 流れる / 包む / 通り抜ける など、読者の体に作用する動詞
- **軸2 読者代名詞**: 僕らの / あなたの / 私たちの
- **軸3 具体数字**: 倍数・距離・速度・量のいずれか1つ
- **軸4 直感的比較数字（必須）**: 専門単位（マイクロ秒・nm等）は読者がスケール感をつかめない。「10倍」「7割」「100億個」のように比較・倍数・スケールが直感できる数字を冒頭に置く。専門単位が必要なら本文中で平易な説明と一緒に使う。マイクロ秒・ナノメートル等の専門単位を冒頭で扱う場合は、**分数化して直感比較数字に変換する**（例: 2.2マイクロ秒 → 「45万分の1秒」）
- **軸5 パワーワード/不思議さ（必須）**: 「寿命を伸ばす」「常識を裏切る」「今この瞬間も貫いている」など、読者の感情・好奇心に直撃するワードか構造を入れる。不老長寿・驚異・日常との意外な接続が機能しやすい

軸1〜3は3点揃わなくてもよいが、最低1点は含める。**軸4・5はどちらか欠けると文系読者への刺さりが大幅に下がるため、必ず両方満たす**。揃えるために不自然な文を作らない。

- OK例: 「寿命を7倍に伸ばした粒子が、今日も空から僕らの体を貫いている。」（軸1=貫いている、軸2=僕らの、軸3=7倍、軸4=「7倍」は直感的比較数字、軸5=「寿命を伸ばす」がパワーワード）
- NG例: 「寿命たった2.2マイクロ秒の粒子が、今日も僕らの体を貫いている。」（軸4×: 2.2マイクロ秒はスケール感が伝わらない専門単位）
- NG例: 「〜は届かない」「〜は不思議だ」（抽象・受動・前提条件のみで冒頭が終わる形）

### 2. 専門用語は初出時に必ず平易な言い換えを添える

形式: 「〇〇という素粒子」「〜という名前の粒子」「〇〇（〜という意味）」

- 例: 宇宙線 → 「宇宙から降ってきた粒子」
- 例: ミューオン → 「〜という名前の素粒子」
- 例: 屈折率 → 「光がどれだけ遅くなるかを表す数」

カタカナ語は日本語があれば日本語を使う（既存ルール）に加えて、専門語は説明セットを必須にする。

ただし字数超過時の最終手段として、後述「削る対象優先度リスト」の順に従って言い換え注釈を削ることは許容する。

### 3. 複数視点の比較は段落を分けて対比構文で書く

AI生成は視点を1文に詰めがち。視点が2つ以上あるときは段落を分け、接続詞で明示する。

- NG: 「Aから見れば〜だが、Bから見れば〜だ。」
- OK:
  ```
  Aにとっては〜だ。

  でも、Bから見ると〜。
  ```
- 視点切り替えの語: 「でも、〜」「いっぽうで、〜」「だが、〜から見れば」

### 4. 数値は具体的に書く（曖昧表現を禁止）

- NG: 「何倍もの」「相当な」「とても」「かなり」
- OK: 「7倍」「3割」「半分」「秒速22万km」など具体数値
- 変化を示すときは Before / After の両方の数値を書く（例: 30万km → 22万5千km）

### 5. 動きを表す箇所には感覚語を1つ以上入れる

専門的説明だけで終わらせず、体感に近い表現を1つは混ぜる。

- 例: 爆速 / ふわっと / グッと / スーッと / ドカンと / すり抜ける / 突き破る
- 「光速で飛ぶ」より「爆速で飛んでくる」のほうが体感に近い

## 目的

「常識をひっくり返す1行」でスクロールを止め、科学の意外な事実を通じて日常の見え方を変える。読後に「ロマン」「驚き」「感動」を残す。

## 文体

**常体（だ／のだ調）を使う。ですます調は使わない。**

---

## 文の長さとリズム

- 1段落あたり1〜2文。空行を多用してゆったり読める
- 説明部は2〜3文の積み重ね。締めは1文（体言止めが多い）
- 列挙リズムを使う：「炭素も、酸素も、血液の鉄も」
- 疑問→即答の短いリズム：「なぜか。〜から。」「なんで〜のか。〜ため。」

---

## 削る対象優先度リスト

字数超過時、上から順に削る:

1. 中間メカニズムの細部（「正確には〜が崩壊して」「途中で〜を経由して」など本筋に不要な機構説明）
2. 同一事実を別単位で言い直す重複数値（例: 2.2μs と 10倍 が併記されているなら片方）
3. 理論名・学者名（現象が伝わるなら名前を出さない）
4. 専門用語の言い換え注釈（「〇〇という名前の素粒子」「電子の重い兄弟」等の同格補足）
5. 視点切替の冗長な接続文

## 語尾

| 用途 | 語尾 | 例 |
|---|---|---|
| 断定（基本） | 〜だ / 〜のだ | 「素粒子だ」「感じないのだ」 |
| 解説 | 〜ている / 〜される / 〜ため | 「使われている」「確認するためだ」 |
| 疑問提示 | なぜか。/ なんで〜のか。 | 「なぜか？〜から」「なんでここまで極端なのか。」 |
| 感嘆 | 〜すぎる / 〜しかない / 〜んだなあ | 「不思議すぎる」「ロマンしかない」「根付いたんだなあ」 |
| 語りかけ | 〜よね / 〜じゃないよね / 〜んです | 「見えるよね」「捨てたもんじゃないよね」 |
| 哲学的締め | 〜のだろう | 「執念から生まれるのだろう」 |

## 記号・句読点

- **「。」** 句点で文を明確に終わらせる
- **「、」** 読点を積極的に使いリズムを作る
- **「！」** 原則使わない（冒頭で強烈な意外性を出すときだけ）
- **「？」** 疑問提示に使う（「なぜか？」）。直後に即答がセット
- **「」（鉤括弧）** 専門用語・比喩・常識語の強調に多用
- **`〜`（波ダッシュ）** 使わない
- **`(* ...)` 形式** 補足注釈として使う

## 締め言葉の引き出し

> ルールは brand.md に記載。以下は X 投稿に適した具体例。

### 詩的余韻型（推奨）
現象を擬人化・情景化して閉じる型。日常接続が難しいテーマで使う。
- 例: 「今日も空から、時間の不思議を秘めたミューオンが、僕らの頭上に降り注いでいる。」

### 日常接続系（推奨・最終行はここから）
- 「何気なく過ごす一日の中に、宇宙の歴史が詰まっている。」
- 「今日も僕らのポケットの中で動いている。」
- 「アイスコーヒーに浮かぶ氷は、地球が生命に適した場所である証拠だ。」
- 「あの「当たり前」が〜」

### 語りかけ系
- 「〜捨てたもんじゃないよね。」

### 感情・ロマン系（単独最終行NG）
直前か直後に日常接続の一文を添える。
- 「まじで熱い」「ロマンしかない」「〜すぎる」「〜んだなあ」

### 常識転換系
- 「宇宙は日常の常識を、軽々と裏切ってくる。」

### 哲学的系
- 「世界を変える輝きはいつだって、限界の先まで積み上げる執念から生まれるのだろう。」
