## 黄金構造（必ず従う）

### 1. 冒頭：「実は、〇〇は△△だ」形式
常識を即座にぶち破る1行で読者のスクロールを止める。

**パターン:**
- 「実は、宇宙に行くと背が2～3cm伸びる。」
- 「実は、宇宙空間はマイナス270℃の極寒だ。」
- 「実は、深海では赤い生き物は黒く見える。」
- 「実は、脳自体には痛みを感じる神経がない。」
- 「実は、スマホのGPSは相対性理論で補正しないと、1日に約11kmズレる。」

**書き方:**
- 断定形（「だ」「である」）
- 数字があれば冒頭に入れて意外性を強化
- 短く、一度読んだら「え？」と思わせる

## 2. 段落構成：4段（対比→仕組み→締め）

### 段落1：冒頭（意外性）
1文だけ。常識を裏切る。

### 段落2：対比（常識 vs 事実）
「〜では〜だが、一方〜」「〜が普通だが、〜は逆」形式で常識とのギャップを強調。

**例:**
- 「地上では、体の重みで椎間板が圧縮されている。朝と夜で身長が1cm前後変わるのはこのせいだ。 ところが無重力環境に入ると、その圧力がゼロになる。」
- 「地上では『赤』は最も目立つ警告色だ。だが深海では、赤こそが最強のステルスカラーになる。」
- 「太陽が燃え盛る宇宙は熱そう、と思いがちだが逆。」

### 段落3：仕組み（説明）
平易な言葉で「なぜそうなるのか」を段階を追って説明。数値・効果は内訳まで提示。

**特徴:**
- 専門用語は即座に言い換える（「水素結合が組み変わって隙間の多い構造に」など）
- 「理由はシンプル」「なぜか」などの橋渡し表現を使う
- 短文の積み重ね（1段落1〜2文）

**例:**
```
理由は光の波長にある。
太陽光のうち、赤い波長は水に吸収されやすい。
水深200mも潜ると、赤い光はほとんど残らない。

物が赤く見えるのは、赤い光が反射されて目に届くから。
反射すべき赤い光がそもそも存在しなければ、赤い体は何も返せない。
だから黒い影のように沈む。
```

### 段落4：締め（感情・ロマン）
ファクトで終わらず、著者の感情・驚き・ロマンで締める。読者の「それはいいこと？悪いこと？」という余韻を残す。

**パターン:**
- 「〜ロマンしかない」「ロマンがある」
- 「〜まじで熱い」「〜まじロマン」
- 「物理が決める〜」「物理は遠い話じゃない」
- 「〜を静かに教えてくれている」
- 「〜という不思議」「〜不思議すぎる」
- 「〜が地球でだけ見られることに〜」
- 「〜気づいていないだけで」

**例:**
```
背が伸びたいなら、地上の筋トレより宇宙への片道切符。現実味はないけど、ロマンがある。

燃え盛る太陽のすぐ隣が、地球最低気温の3倍寒い。
宇宙、感覚をバグらせてくる。

赤いキンメダイやエビが深海に多いのは偶然じゃない。
光が消えた世界で、進化が選んだ「見えなくなる色」だ。

全身の痛みを引き受けながら、自分は何も感じない器官が頭の中にある。
人体の設計、不思議すぎる。

アインシュタインが100年以上前に書いた理論が、今日のあなたの道案内を支えている。
まじで熱い。
```

## 3. 身近さ接続（必須）

宇宙・物理を読者の日常に着地させる。

**具体例:**
- スマホのGPS（毎日使うナビアプリ）×相対性理論（難しい物理）
- グラスの氷が浮く日常 ×地球の生命圏を支える物理
- 窓から差し込む光（毎日見ている）× 光が太陽中心で10万年旅した時間軸
- 宇宙服は防寒具（人体が感覚する「寒さ」）× 宇宙空間の極端な温度

**書き方:**
- 読者が毎日見ているもの・使っているものから始める
- そこから宇宙の壮大さ・非常識さに接続する

## 4. トーン・文体ルール

### 口調
- **言い切り調**: 「〜だ」「〜である」を基調
- **体言止め活用**: 「ロマンしかない」「感覚をバグらせてくる」
- **です体や疑問形は使わない**
- **感嘆符（！）は避ける**（代わりに「ロマン」「熱い」など感情語彙で表現）

### 難しい用語への対応
- 専門語を出したら、直後に必ず平易に言い換える
- 例：「水素結合が組み変わって」→「水素結合が組み変わって隙間の多い構造に」
- 例：「弱い相互作用」→「電気を帯びておらず、ほとんどの力を感じない」

### 段落の見た目
- 1段落は1〜2文
- 段落間の空白は厚めに
- 短文の畳みかけで読むテンポを高める

### ハッシュタグ
- **付けない**

### 文字数
- **140字以上300字以内**
- ほとんどが200字前後

## 5. 数字の活用（意外性強化）

具体的な数値を入れることで、意外さを3倍にする。

**パターン:**
- 倍率の対比：「月は太陽の400分の1の大きさなのに」「地球の最低気温の3倍寒い」
- 時間スケール：「10万年」「毎秒700億個」「1日11km」
- 微小な誤差：「38マイクロ秒」「わずか」+数字
- 距離：「鉛1光年分でも止まらない」

**書き方:**
- 数字はできるだけ具体的に
- 「約〇〇」と概数の許容範囲を示す
- 数字が対比になる場合は両方書く（8分 vs 10万年など）

---

## 6. 対比法（常識をぶち破る）

### パターン1：「〜では」「一方」「でも」
```
地上では、体の重みで椎間板が圧縮されている。
ところが無重力環境に入ると、その圧力がゼロになる。
```

### パターン2：「逆」を前面に
```
太陽が燃え盛る宇宙は熱そう、と思いがちだが逆。
```

### パターン3：比較形
```
太陽の直径は月の約400倍。
でも、地球から太陽までの距離も、月の約400倍遠い。
```

## 7. NG 表現

- **ハッシュタグ** → 付けない
- **疑問形で終わる** → 「〜だろうか？」ではなく「〜だ」と言い切る
- **「実は」の重複使用** → 冒頭の1回だけ
- **過度な比喩** → 「バグる」は OK、「ゴミ」「クソ」は NG
- **難しい専門用語を説明なしに使う** → 必ず平易に言い換える
- **感嘆符の多用** → 使うなら最後の1回まで
- **第一人称の多用** → 「私は」ではなく「あなた」や無主語で
- **曖昧な表現** → 「〜ような」「〜みたいな」を避ける

## 8. 実例に学ぶ：良例と悪例

### 良例（実際のポスト）
```
実は、深海では赤い生き物は黒く見える。

地上では「赤」は最も目立つ警告色だ。
だが深海では、赤こそが最強のステルスカラーになる。

理由は光の波長にある。
太陽光のうち、赤い波長は水に吸収されやすい。
水深200mも潜ると、赤い光はほとんど残らない。

物が赤く見えるのは、赤い光が反射されて目に届くから。
反射すべき赤い光がそもそも存在しなければ、赤い体は何も返せない。
だから黒い影のように沈む。

赤いキンメダイやエビが深海に多いのは偶然じゃない。
光が消えた世界で、進化が選んだ「見えなくなる色」だ。

地上の常識が、海の底ではひっくり返る。
物理が決める色の世界、まじで面白い。
```

**なぜ良いか:**
- 冒頭で「実は」で常識をぶち破る
- 対比で意外さを強調（「警告色」vs「ステルス」）
- 段階的な説明（波長→吸収→見え方→進化的意味）
- 感情締め（「物理が決める」+「面白い」）
- 短文の積み重ねで読みやすい
